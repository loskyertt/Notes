# 1 物理层的定位与接口规范

物理层位于协议栈最底层，负责在物理介质上**传输和接收比特流**。它不解释数据含义，也不负责 MAC/IP 寻址、帧校验或路由选择。

## 1.1 物理层解决什么问题

| 问题 | 物理层规定 | 示例 |
| :--- | :--- | :--- |
| 信号长什么样 | 电平、光强、无线载波、调制方式 | 高低电平、光脉冲 |
| 接口怎么连接 | 接口形状、引脚、连接器 | RJ-45、光纤接口 |
| 比特如何计时 | 时钟、码元周期、同步方式 | 曼彻斯特编码 |
| 介质如何使用 | 频率范围、传输速率、功率和传播规范 | 双绞线、光纤、无线电波 |

## 1.2 四类接口特性

| 特性 | 规定内容 |
| :--- | :--- |
| **机械特性** | 接口形状、引脚数量与排列 |
| **电气特性** | 电压、电流、阻抗、信号速率 |
| **功能特性** | 各引脚或信号状态的含义 |
| **规程特性** | 信号出现的顺序、时序和操作过程 |

# 2 数据通信基础

## 2.1 数据、信号与信道

- **数据**：信息的数字化表示，例如比特串 `101101`。
- **信号**：数据在介质中的表现形式，例如电压变化、光脉冲或无线电波。
- **信道**：信号传输所经过的路径，可以是有线介质，也可以是无线介质。
- **模拟信号**：连续变化的信号。
- **数字信号**：离散电平或离散状态表示的信号。

> [!tip] 记忆
> 数据是“要表达的内容”，信号是“承载内容的波形”，信道是“信号经过的路径”。

## 2.2 码元、比特、波特率与比特率

**码元**是信号传输中的基本符号，一个码元占据一个固定的时间区间。码元可以有多个离散状态，因此一个码元不一定只表示一个比特。

若一个码元有 $M$ 种可能状态，则每个码元最多承载：

$$
\log_2M\text{ bit}
$$

| 概念 | 含义 | 单位 |
| :--- | :--- | :--- |
| **码元** | 一个固定时长的信号符号 | — |
| **码元速率/波特率** $R_s$ | 每秒传输的码元数 | Baud |
| **比特率** $R_b$ | 每秒传输的比特数 | bit/s |

关系式为：

$$
\boxed{R_b=R_s\log_2M}
$$

例如，码元速率为 $1000$ Baud、每个码元有 $8$ 种状态：

$$
R_b=1000\times\log_2 8=3000\text{ bit/s}
$$

> [!warning] 易错点
> 只有二进制码元（$M=2$）时，波特率和比特率的数值才相等；二者的单位和含义仍然不同。

## 2.3 发送时延、传播时延与总时延

### 发送时延

发送时延是发送端把一个完整帧的全部比特推入链路所需的时间：

$$
\boxed{T_s=\frac{L}{R}}
$$

其中 $L$ 为数据长度（bit），$R$ 为链路数据率（bit/s）。

### 传播时延

传播时延是信号从链路一端传播到另一端所需的时间：

$$
\boxed{T_p=\frac{D}{V}}
$$

其中 $D$ 为链路长度，$V$ 为信号在介质中的传播速度。

若暂不考虑排队和处理，整个帧从发送端开始发送到接收端完整收到的时间为：

$$
\boxed{T_s+T_p}
$$

| 对比 | 发送时延 | 传播时延 |
| :--- | :--- | :--- |
| 关注对象 | 帧的全部比特被送上链路 | 信号在介质中走完链路 |
| 主要取决于 | 帧长、数据率 | 距离、传播速度 |
| 公式 | $L/R$ | $D/V$ |

> [!warning] 不能混淆
> 提高带宽会缩短发送时延，但不会直接提高信号在介质中的传播速度；缩短链路距离会降低传播时延，但不会自动提高数据率。

### 时延带宽积

时延带宽积（BDP）表示一个传播时延内链路中理论上能够容纳的在途数据量：

$$
\boxed{\text{BDP}=R\times T_p}
$$

单位是 bit。若题目给的是 RTT，应明确计算的是往返时间内的数据量：

$$
R\times RTT=R\times 2T_p
$$

它与单向链路在途数据量不是同一个量。

## 2.4 半双工与全双工

| 模式 | 含义 | 典型场景 |
| :--- | :--- | :--- |
| **半双工** | 双方都能发送和接收，但同一时刻只能一个方向传输 | 共享式以太网、对讲机 |
| **全双工** | 双方可以同时发送和接收 | 交换式以太网、电话 |

传统共享式以太网使用半双工，需要 CSMA/CD 处理碰撞；现代交换式全双工以太网没有共享冲突信道，通常不再使用 CSMA/CD，详见 [[02_数据链路层#3 介质访问与链路协议]]。

# 3 信号编码与同步

编码的目标是把比特映射为适合介质传输的信号，并让接收方能够恢复比特边界和时钟。

## 3.1 常见线路编码

| 编码 | 基本规则 | 同步能力 | 主要特点 |
| :--- | :--- | :--- | :--- |
| **NRZ** | 用高/低电平直接表示数据 | 较差 | 连续相同比特可能长期无跳变 |
| **NRZI** | 用是否发生跳变表示某一比特 | 取决于规则和数据 | 对极性变化更有适应性 |
| **RZ** | 每个码元中途回到零电平 | 较好 | 跳变多，效率较低 |
| **曼彻斯特** | 每个码元中间必有一次跳变，跳变方向表示数据 | 好 | 同步性强，但频带开销较大 |
| **差分曼彻斯特** | 中间必跳变，码元开始是否跳变表示数据 | 好 | 对信号极性反转更鲁棒 |
| **4B/5B** | 4 位数据映射为 5 位码组 | 好 | 通过受限码组保证足够跳变 |

不同教材对曼彻斯特中“0/1 对应上升沿还是下降沿”的约定可能相反，但**中间必然跳变**这一性质不变。

## 3.2 曼彻斯特与差分曼彻斯特

- 曼彻斯特编码根据码元中间的跳变方向解码。
- 差分曼彻斯特编码根据码元开始处是否发生跳变解码，码元中间的跳变只用于同步。
- 两者都具有自同步能力，但需要更高的信号变化速率，频带利用率低于简单的 NRZ。

> [!tip] 记忆
> 曼彻斯特看“中间跳变的方向”；差分曼彻斯特看“开始处有没有跳变”。

# 4 信道容量与传输速率

## 4.1 奈奎斯特定理

理想、无噪声、带宽为 $W$ 的低通信道，若信号有 $N$ 个离散电平，最大码元速率为 $2W$，最大数据率为：

$$
\boxed{R_{\max}=2W\log_2N}
$$

它说明带宽和码元状态数会限制理想信道的最高数据率。

## 4.2 香农定理

有噪声信道的理论信道容量为：

$$
\boxed{C=W\log_2(1+S/N)}
$$

其中 $W$ 为带宽，$S/N$ 为线性信噪比；如果题目给出 dB，需要先转换为线性值。

| 因素 | 主要影响 |
| :--- | :--- |
| 带宽 $W$ | 可用频率范围，影响容量 |
| 信噪比 $S/N$ | 抵抗噪声的能力，影响容量 |
| 码元速率 | 单位时间传输的码元数，影响比特率 |
| 信号传播速度 | 主要影响传播时延，不直接决定数据率 |

> [!warning] 三种量要分开
> 数据传输速率单位是 bit/s，信号传播速度单位是 m/s，传播时延单位是 s。传播速度变快通常只会让信号更早到达，不代表每秒能编码更多比特。

# 5 传输介质

| 介质 | 特点 | 典型应用 |
| :--- | :--- | :--- |
| 双绞线 | 成本低、部署方便，易受电磁干扰 | 局域网接入 |
| 同轴电缆 | 屏蔽性较好，早期共享式局域网常用 | 有线电视、旧式网络 |
| 光纤 | 带宽高、距离长、抗电磁干扰 | 骨干网、数据中心 |
| 无线电波 | 无需布线，但共享介质且受干扰 | Wi-Fi、移动通信 |

# 6 物理层设备与域

| 设备 | 工作层级 | 作用 | 冲突域/广播域 |
| :--- | :--- | :--- | :--- |
| 中继器 | 物理层 | 信号整形、再生 | 不隔离 |
| 集线器 | 物理层 | 多端口中继，广播式转发 | 不隔离冲突域和广播域 |
| 二层交换机 | 数据链路层 | 基于 MAC 学习和转发 | 通常每端口一个冲突域，同 VLAN 广播域不隔离 |
| 路由器 | 网络层 | 基于 IP 路由和转发 | 隔离广播域 |

> [!important] 两个域的区别
> **冲突域**是可能发生介质争用的范围；**广播域**是广播帧能够到达的范围。交换机主要隔离冲突域，路由器和 VLAN 隔离广播域。

> [!summary] 本篇核心
> 1. 物理层只规定比特如何变成信号并通过介质传输。
> 2. 码元是信号符号，波特率数码元，比特率数比特，$R_b=R_s\log_2M$。
> 3. 发送时延看帧长和带宽，传播时延看距离和传播速度，BDP 为 $R\times T_p$。
> 4. 奈奎斯特处理理想信道，香农处理有噪声信道。
> 5. 曼彻斯特和差分曼彻斯特依靠跳变实现同步；集线器共享冲突域，交换机和路由器分别承担不同的隔离职责。
