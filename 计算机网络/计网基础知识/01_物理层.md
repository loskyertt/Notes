物理层是唯一真正"接触介质"的层次，它只做一件事：**把比特流可靠地送到相邻设备的网卡**。本篇只收录与上层协同密切相关的部分，作为 [[02_数据链路层]] 的前置背景。

# 1 物理层的定位与四大特性

物理层**不关心数据含义、不关心寻址**，只规定如何在传输介质上收发比特。

| 特性 | 规定内容 |
| :--- | :--- |
| **机械特性** | 接口形状、引脚数量与排列（如 RJ-45） |
| **电气特性** | 电压范围、传输速率、阻抗匹配（如 RS-232 的 ±3~15V） |
| **功能特性** | 各引脚的电平含义（某线上出现某电平代表 0/1） |
| **过程特性**（规程特性） | 各信号线的工作时序与步骤 |

# 2 数据通信基础

| 概念 | 定义 | 关系 |
| :--- | :--- | :--- |
| **码元** | 承载信息的信号波形单元 | — |
| **波特率（Baud）** | 每秒传输的码元数 | 波特率 × 每码元比特数 = 比特率 |
| **比特率（bps）** | 每秒传输的比特数 | 奈奎斯特 / 香农公式给出理论上限 |
| **带宽** | 信道可承载的频率范围 | 与最大比特率正相关 |

**常见编码方式**：

| 编码 | 特点 | 自同步能力 |
| :--- | :--- | :--- |
| 不归零（NRZ） | 高/低电平表示 1/0 | 无（长串相同比特会失去时钟） |
| 曼彻斯特编码 | 每比特中间必有一次跳变 | **有**（以太网 10BASE-T 使用） |
| 差分曼彻斯特 | 用"是否跳变"表示 0/1 | 有，抗干扰更强 |
| 4B/5B | 4 位数据映射为 5 位符号 | 有（100BASE-FX 使用） |

> [!note] 为什么以太网编码要关注自同步
> 接收方没有独立的时钟线，必须从信号跳变中恢复时钟。缺少跳变的比特流会让接收方"数不清"比特边界 —— 这直接决定了链路能传输多长时间的全 0 或全 1。

# 3 传输介质

| 介质 | 典型标准 | 最大距离 | 特点 |
| :--- | :--- | :--- | :--- |
| 双绞线（Cat5e/Cat6） | 1000BASE-T | 100 m | 便宜、易部署、抗干扰一般 |
| 多模光纤 | 1000BASE-SX | 550 m | 成本适中，机房内中距离 |
| 单模光纤 | 1000BASE-LX | 数公里以上 | 长距离骨干，成本高 |
| 无线（Wi-Fi） | 802.11ax | 视环境 | 共享介质、半双工、受干扰影响大 |

# 4 物理层设备：中继器与集线器

| 设备 | 功能 | 端口关系 | 冲突域 |
| :--- | :--- | :--- | :--- |
| **中继器（Repeater）** | 信号整形、放大、再生（不是简单放大） | 2 端口 | 两端属于**同一个**冲突域 |
| **集线器（Hub）** | 多端口中继器 | 多端口 | 全部端口共享**一个**冲突域 |

**集线器的三个致命缺陷**：

```text
+--------------------------------------------------+
| 1. 共享带宽：10Mbps 由所有端口平分
| 2. 共享冲突域：同一时刻只能一台设备发送，靠 CSMA/CD 仲裁
| 3. 广播式转发：发给 A 的帧，所有端口都能收到（无隐私）
+--------------------------------------------------+
```

> [!important] 冲突域 vs 广播域
> - **冲突域**：会发生介质争用的范围，由**交换机**隔离（每端口一个）
> - **广播域**：广播帧能到达的范围，由**路由器 / VLAN** 隔离
> - 集线器：既隔离不了冲突域，也隔离不了广播域 → 已被交换机完全取代
> 交换机如何基于 MAC 表定向转发，见 [[02_数据链路层#3 交换机工作原理]]。

# 5 与数据链路层的边界

| 事项 | 物理层负责 | 数据链路层负责 |
| :--- | :--- | :--- |
| 单位 | 比特（Bit） | 帧（Frame） |
| 关注 | 电/光信号能否被正确识别 | 帧边界、地址、差错检测 |
| 典型问题 | 信号衰减、串扰、时钟漂移 | FCS 校验失败、MAC 冲突、帧长度错误 |
| 设备 | 中继器、集线器 | 网桥、二层交换机、网卡（MAC 部分） |

> [!summary] 本篇核心
> 1. 物理层只传输比特流，用**四大特性**描述接口规范，不做任何寻址
> 2. 编码方式决定**自同步能力**，曼彻斯特编码是经典答案
> 3. 集线器 = 多端口中继器，共享带宽与冲突域，已被交换机取代
> 4. **冲突域由交换机隔离，广播域由路由器/VLAN 隔离** —— 这两个概念是链路层一切问题的起点
