# 1 背景

**Windows 虚拟桌面**（Task View）默认快捷键为 `Win + Ctrl + 左/右方向键`，而 **GNOME 桌面** 原生支持 `Win + 鼠标滚轮` 切换工作区。对于双系统或多系统用户，两种操作习惯的割裂降低了切换效率。

> [!info]
> Windows 系统默认不提供 `Win + 滚轮` 切换虚拟桌面的功能，需要通过第三方方案实现。

---

# 2 核心思路

将 `Win + WheelUp/Down` 操作映射为系统原生的 `Win + Ctrl + Left/Right` 快捷键。实现方式分为两类：

| 方案 | 原理 | 适用场景 |
|---|---|---|
| AutoHotkey 脚本 | 全局热键劫持 + 模拟按键 | 通用场景，无需额外硬件 |
| 鼠标驱动宏 | 驱动层按键映射 | 已使用高端游戏/办公鼠标 |

---

# 3 方案一：AutoHotkey 脚本（推荐）

## 3.1 安装与配置

1. 下载安装 [AutoHotkey v2](https://www.autohotkey.com/download/)
2. 新建文本文件，重命名为 `WorkspaceSwitch.ahk`
3. 写入以下脚本：

```autohotkey
#Requires AutoHotkey v2.0

; Win + 滚轮向上 → 切换到上一个虚拟桌面
#WheelUp:: {
    Send "^#{Left}"
}

; Win + 滚轮向下 → 切换到下一个虚拟桌面
#WheelDown:: {
    Send "^#{Right}"
}
```

4. 双击运行该文件即可生效

> [!tip]
> AHK 中 `#` 代表 `Win` 键，`^` 代表 `Ctrl` 键。`Send "^#{Left}"` 模拟按下 `Ctrl + Win + Left`。

## 3.2 开机自启

```powershell
Win + R → 输入 shell:startup → 回车
→ 将 WorkspaceSwitch.ahk（或其快捷方式）粘贴到打开的文件夹
```

> [!warning]
> 若 AHK 脚本未以管理员权限运行，某些以管理员身份启动的应用（如部分游戏）中热键可能失效。可在脚本属性 → 兼容性 → 勾选"以管理员身份运行"解决。

---

# 4 方案二：鼠标驱动宏

## 4.1 适用条件

拥有 Logitech、Razer 等品牌的可编程鼠标，且已安装对应驱动软件（Logitech Options+、Razer Synapse 等）。

## 4.2 配置步骤

1. 打开鼠标驱动管理软件
2. 选择目标按键（滚轮左右倾斜 / 侧键 / G-Shift 键等）
3. 将按键功能设置为"键盘快捷键"
4. 录入以下映射：

| 操作 | 映射按键 |
|---|---|
| 切换到左侧桌面 | `Win + Ctrl + Left` |
| 切换到右侧桌面 | `Win + Ctrl + Right` |

---

# 5 方案对比

| 维度 | AutoHotkey | 鼠标驱动 |
|---|---|---|
| 成本 | 免费 | 需硬件投入 |
| 通用性 | 任意键盘鼠标均可 | 仅限特定品牌鼠标 |
| 延迟 | 极低（~1ms） | 取决于驱动实现 |
| 可定制性 | 高（可扩展其他快捷键） | 低（仅限驱动支持的功能） |
| 学习成本 | 需写简单脚本 | 图形界面操作 |

---

# 6 扩展建议

## 6.1 增强版 AHK 脚本

```autohotkey
#Requires AutoHotkey v2.0

; 桌面切换
#WheelUp:: Send "^#{Left}"
#WheelDown:: Send "^#{Right}"

; 直接在左右桌面间跳转（按编号）
#1:: Send "^#{1}"
#2:: Send "^#{2}"
#3:: Send "^#{3}"
#4:: Send "^#{4}"

; 打开任务视图
#Tab:: Send "#{Tab}"
```

## 6.2 配合虚拟桌面增强工具

- **VDesk** — 命令行创建 / 切换虚拟桌面
- **ExplorerPatcher** — 恢复 Windows 10 任务栏样式，配合桌面切换更顺手

---

> [!summary]
> **最推荐方案**：AutoHotkey v2 脚本 + 开机自启，零成本、低延迟、高可定制，一次配置长期受益。
