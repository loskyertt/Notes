# 1. 文件与目录的创建

## 1.1 touch 命令

`touch` 的主要功能是**更新文件的时间戳**（访问时间和修改时间为当前时间）。当目标文件不存在时，会创建一个空文件，这也是日常中最常见的用法。

```bash
# 创建单个文件
touch <filename>

# 同时创建多个文件
touch file1.txt file2.txt file3.txt

# 更新已有文件的时间戳（文件内容不变）
touch existing_file.txt
```

## 1.2 mkdir 命令

`mkdir`（make directory）用于创建目录。

```bash
# 创建单个目录
mkdir <dirname>

# 同时创建多个目录
mkdir dir1 dir2 dir3

# 递归创建多级目录（当父目录不存在时自动创建）
mkdir -p <dir1>/<dir2>/<dir3>
```

`-p`（`--parents`）选项：路径中任意一级目录不存在时自动创建，若目录已存在也不报错。

# 2. 文件与目录的查看

## 2.1 ls 命令

`ls`（list）用于列出目录内容。

```bash
# 列出当前目录的文件和目录
ls

# 列出指定路径
ls /path/to/directory

# 长格式：显示权限、所有者、大小、修改时间等详细信息
ls -l

# 显示隐藏文件（以 . 开头的文件）
ls -a

# 以人类可读格式显示文件大小（配合 -l 使用）
ls -lh

# 按修改时间排序（最新的在前）
ls -lt

# 递归列出所有子目录内容
ls -R
```

`ls -l` 输出格式说明：

```
-rwxr-xr-- 1 alice dev 4096 Jan 1 12:00 script.sh
│           │ │     │   │              └── 文件名
│           │ │     │   └────────────── 文件大小（字节）
│           │ │     └────────────────── 所属组
│           │ └──────────────────────── 所有者
│           └────────────────────────── 硬链接数
└────────────────────────────────────── 文件类型与权限
```

## 2.2 cat 命令

`cat`（concatenate）用于显示文件内容，适合查看内容较短的文件。

```bash
# 显示文件内容
cat <filename>

# 显示多个文件内容（按顺序拼接输出）
cat file1.txt file2.txt

# 显示行号
cat -n <filename>

# 显示内容并写入新文件（覆盖）
cat file1.txt > output.txt

# 追加内容到文件末尾
cat file1.txt >> output.txt
```

## 2.3 more 和 less 命令

`cat` 会一次性输出全部内容，文件较大时不便阅读，应使用 `more` 或 `less` 分页查看。

```bash
# more：向下翻页查看（不支持向上滚动）
more <filename>

# less：可上下翻页，功能更强（推荐）
less <filename>
```

`less` 常用快捷键：

| 按键 | 作用 |
|---|---|
| `Space` / `f` | 向下翻一页 |
| `b` | 向上翻一页 |
| `j` / `↓` | 向下一行 |
| `k` / `↑` | 向上一行 |
| `g` | 跳到文件开头 |
| `G` | 跳到文件末尾 |
| `/<pattern>` | 向下搜索 |
| `?<pattern>` | 向上搜索 |
| `n` | 跳到下一个匹配项 |
| `q` | 退出 |

## 2.4 head 和 tail 命令

用于只查看文件的开头或末尾部分，默认显示 10 行。

```bash
# 查看文件前 10 行
head <filename>

# 查看文件前 N 行
head -n 20 <filename>

# 查看文件后 10 行
tail <filename>

# 查看文件后 N 行
tail -n 20 <filename>

# 实时追踪文件末尾的新增内容（常用于监控日志）
tail -f <filename>
```

# 3. 文件与目录的复制、移动和重命名

## 3.1 cp 命令

`cp`（copy）用于复制文件或目录。

```bash
# 复制文件
cp <source_file> <dest_file>

# 复制文件到指定目录
cp <source_file> /path/to/dest_dir/

# 复制目录（必须加 -r，递归复制）
cp -r <source_dir> <dest_dir>

# 复制时保留文件的权限、时间戳、所有者等属性
cp -p <source_file> <dest_file>

# 保留所有属性（等同于 -dR --preserve=all，常用于备份）
cp -a <source_dir> <dest_dir>

# 覆盖前提示确认
cp -i <source_file> <dest_file>
```

## 3.2 mv 命令

`mv`（move）用于移动文件/目录，或对其重命名。

```bash
# 重命名文件（目标文件不存在时为重命名，存在时为覆盖）
mv old_name.txt new_name.txt

# 移动文件到指定目录
mv /path/to/file.txt ~/temp/

# 移动目录
mv <source_dir> <dest_dir>

# 移动多个文件到同一目录
mv file1.txt file2.txt /path/to/dest_dir/

# 覆盖前提示确认
mv -i <source> <dest>
```

`mv` 操作**无需 `-r` 选项**，对目录和文件的操作方式相同。

**`cp`、`mv`、`rm` 的 `-r` 选项对比**：

| 命令 | 对文件 | 对目录 |
|---|---|---|
| `cp` | 直接操作 | **必须加 `-r`** |
| `mv` | 直接操作 | 直接操作，**无需 `-r`** |
| `rm` | 直接操作 | **必须加 `-r`** |

# 4. 文件与目录的删除

## 4.1 rm 命令

`rm`（remove）用于删除文件或目录。**该操作不可撤销**，执行前务必确认。

```bash
# 删除单个文件
rm <filename>

# 同时删除多个文件
rm file1.txt file2.txt

# 删除前提示确认（推荐在删除重要文件时使用）
rm -i <filename>

# 递归删除目录及其所有子文件（会对每个文件提示确认）
rm -r <dirname>

# 递归强制删除目录及其所有内容，不提示（谨慎使用）
rm -rf <dirname>

# 删除当前目录的所有文件和目录（极度危险，确认后再执行）
rm -rf *
```

**`-r` 与 `-f` 的区别**：

| 选项 | 含义 |
|---|---|
| `-r` / `--recursive` | 递归删除目录及其内容；若文件有多个硬链接，会给出警告 |
| `-f` / `--force` | 强制删除，忽略不存在的文件和所有警告，不提示 |
| `-rf` | 两者结合：递归且不提示，是最危险的组合 |

> **警告**：`rm -rf /` 或 `rm -rf /*` 会删除整个系统，现代系统对此有保护机制，但仍应极度谨慎，**绝不**在 root 权限下执行通配符删除。

## 4.2 rmdir 命令

`rmdir` 只能删除**空目录**，目录中有文件时会报错，比 `rm -r` 更安全。

```bash
# 删除空目录
rmdir <dirname>

# 递归删除空的父目录（若父目录因此变为空则一并删除）
rmdir -p <dir1>/<dir2>/<dir3>
```

# 5. 文件查找

## 5.1 find 命令

`find` 在目录树中递归搜索文件，功能强大，支持多种条件组合。

**基本语法**：

```bash
find [路径] [条件选项] [执行动作]
```

**按文件名查找**：

```bash
# 精确匹配文件名（区分大小写）
find /path/to/dir -name "filename.txt"

# 不区分大小写匹配
find /path/to/dir -iname "filename.txt"

# 通配符匹配所有 .txt 文件
find /path/to/dir -name "*.txt"
```

**按文件类型查找**：

```bash
# 查找普通文件
find /path/to/dir -type f

# 查找目录
find /path/to/dir -type d

# 查找符号链接
find /path/to/dir -type l
```

**按文件大小查找**：

```bash
# 查找大于 1MB 的文件（+ 表示大于，- 表示小于，不加符号表示精确匹配）
find /path/to/dir -size +1M

# 查找小于 500KB 的文件
find /path/to/dir -size -500k

# 查找大小在 1MB 到 10MB 之间的文件
find /path/to/dir -size +1M -size -10M
```

**按时间查找**（单位为"天"，`-n` 表示 n 天以内，`+n` 表示 n 天以前）：

```bash
# 查找最近 7 天内修改过的文件（mtime = modification time）
find /path/to/dir -mtime -7

# 查找 30 天前修改过的文件
find /path/to/dir -mtime +30

# 按访问时间查找（atime = access time）
find /path/to/dir -atime -7

# 按状态改变时间查找（ctime = change time，包括权限、所有者变化）
find /path/to/dir -ctime -7
```

**按权限和所有者查找**：

```bash
# 查找属于指定用户的文件
find /path/to/dir -user alice

# 查找属于指定组的文件
find /path/to/dir -group dev

# 查找权限为 755 的文件
find /path/to/dir -perm 755

# 查找所有人都有写权限的文件（安全审计常用）
find /path/to/dir -perm -o+w
```

**组合多个条件**：

```bash
# AND（默认，条件并列即为 AND）：查找所有 .txt 且大于 1MB 的文件
find /path/to/dir -name "*.txt" -size +1M

# OR（-o）：查找 .txt 或 .log 文件
find /path/to/dir -name "*.txt" -o -name "*.log"

# NOT（!）：查找不是 .txt 的普通文件
find /path/to/dir -type f ! -name "*.txt"
```

**对结果执行动作**：

```bash
# -ls：列出找到文件的详细信息
find /path/to/dir -name "*.txt" -ls

# -exec：对每个找到的文件执行命令，{} 代表文件路径，\; 表示结束
find /path/to/dir -name "*.log" -exec rm {} \;

# -exec ... + ：将所有结果一次性传递给命令（效率高于 \;）
find /path/to/dir -type d -name "cache" -exec rm -rf {} +

# -delete：直接删除找到的文件（比 -exec rm 效率更高）
find /path/to/dir -name "*.tmp" -delete

# -print0 配合 xargs -0：安全处理含空格的文件名
find /path/to/dir -name "*.txt" -print0 | xargs -0 grep "keyword"
```

## 5.2 locate 命令

`locate` 通过查询预先建立的数据库来查找文件，速度远快于 `find`，但结果不是实时的。

```bash
# 查找包含关键词的文件路径
locate filename.txt

# 不区分大小写
locate -i filename.txt

# 限制输出结果数量
locate -n 10 filename.txt

# 使用前更新数据库（需要 root 权限）
sudo updatedb
```

> `locate` 依赖的数据库通常每天由系统定时任务自动更新，对于刚创建的文件，需要手动执行 `sudo updatedb` 后才能被 `locate` 找到。

## 5.3 which 和 whereis 命令

```bash
# which：在 PATH 环境变量的路径中查找可执行文件的位置
which python3
which git

# whereis：查找可执行文件、源代码及手册页的位置
whereis python3
```

> [!note] 获取更详细的路径信息
> 使用 `which -a <可执行文件名称>` 或 `type -a <可执行文件名称>`。

# 6. 查看文件大小与磁盘使用情况

## 6.1 du 命令

`du`（disk usage）统计文件或目录实际占用的磁盘空间。

```bash
# 显示指定目录的总大小（-s 仅显示总计，-h 人类可读）
du -sh /path/to/directory

# 显示目录下每个子项的大小
du -h /path/to/directory

# 只显示一级子目录的大小（--max-depth 控制递归深度）
du -h --max-depth=1 /path/to/directory

# 按大小排序（从小到大）
du -h /path/to/directory | sort -h

# 按大小排序（从大到小），显示最大的 10 项
du -h /path/to/directory | sort -rh | head -10
```

## 6.2 df 命令

`df`（disk free）显示整个文件系统的磁盘空间使用情况（总量、已用、可用），而 `du` 统计的是具体文件/目录的占用量。

```bash
# 显示所有已挂载文件系统的磁盘使用情况
df -h

# 显示指定路径所在文件系统的使用情况
df -h /home

# 显示 inode 使用情况（inode 耗尽同样会导致无法创建文件）
df -i
```

## 6.3 ls 命令查看文件大小

`ls -lh` 可以在列出目录内容时显示各文件的大小，但对目录显示的是目录项本身的元数据大小，而非目录内文件的总大小，如需目录真实占用量应使用 `du`。

```bash
ls -lh /path/to/directory
```

# 7. 查看文件详细信息

## 7.1 stat 命令

`stat` 显示文件或目录的完整元数据，包括大小、权限、inode 号、时间戳等。

```bash
stat <filename>
```

输出示例：

```
  File: example.txt
  Size: 1234            Blocks: 8          IO Block: 4096   regular file
Device: 802h/2050d      Inode: 131073      Links: 1
Access: (0644/-rw-r--r--)  Uid: ( 1000/  alice)   Gid: ( 1000/  alice)
Access: 2024-01-01 10:00:00.000000000 +0800    ← 最后访问时间（atime）
Modify: 2024-01-01 09:00:00.000000000 +0800    ← 最后修改内容时间（mtime）
Change: 2024-01-01 09:00:00.000000000 +0800    ← 最后修改元数据时间（ctime）
 Birth: 2024-01-01 08:00:00.000000000 +0800    ← 文件创建时间（需文件系统支持）
```

**三种时间戳的区别**：

| 时间戳 | 全称 | 触发条件 |
|---|---|---|
| `atime` | Access Time | 读取文件内容时更新 |
| `mtime` | Modify Time | 修改文件内容时更新 |
| `ctime` | Change Time | 修改文件内容**或**元数据（权限、所有者等）时更新 |
| `Birth` | Birth Time | 文件创建时记录（需 ext4 等支持，旧文件系统可能显示 `-`） |

> `find` 命令中的 `-mtime`、`-atime`、`-ctime` 对应的正是这三个时间戳。

## 7.2 file 命令

`file` 通过读取文件内容的魔数（magic number）来判断文件的真实类型，而非依赖扩展名。

```bash
file <filename>

# 示例输出
file image.png    # image.png: PNG image data, 800 x 600, 8-bit/color RGBA
file script.sh    # script.sh: Bourne-Again shell script, ASCII text executable
file /bin/ls      # /bin/ls: ELF 64-bit LSB pie executable, x86-64
```

## 7.3 debugfs 命令

`debugfs` 是 ext 系列文件系统（ext2 / ext3 / ext4）的底层调试工具，可以查看 `stat` 无法显示的底层信息（如在不支持 Birth time 的旧内核上查看创建时间）。

```bash
# 先获取文件的 inode 号
stat <filename>

# 使用 debugfs 查看指定 inode 的详细信息
sudo debugfs -R 'stat <inode_number>' /dev/sdXn
# 将 <inode_number> 替换为实际 inode 号，/dev/sdXn 替换为文件所在分区
```

> `debugfs` 仅适用于 ext 文件系统；XFS 可用 `xfs_db`，Btrfs 可用 `btrfs inspect-internal`。
