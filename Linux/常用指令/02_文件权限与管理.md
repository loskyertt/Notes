# 1. 文件权限结构总览

执行 `ls -l` 或 `ls -la` 输出示例：

```bash
drwxr-xr-x  8 sky  sky  4096  1月 4日 17:28 cpp
````

**字段拆解**：

| 位置 | 示例          | 含义           |
| -- | ----------- | ------------ |
| 1  | drwxr-xr-x  | 文件类型 + 权限    |
| 2  | 8           | 硬链接数量        |
| 3  | sky         | 所有者（user）    |
| 4  | sky         | 所属用户组（group） |
| 5  | 4096        | 文件大小（字节）     |
| 6  | 1月 4日 17:28 | 最后修改时间       |
| 7  | cpp         | 文件名          |

> [!info] 结构记忆法
> 类型 + 权限 → 链接数 → 所有者 → 组 → 大小 → 时间 → 名称

---

# 2. 权限字段结构

权限字段：`drwxr-xr-x`

拆解：

```
d | rwx | r-x | r-x
    用户  组   其他用户
```

| 区域     | 位数 | 含义             |
| ------ | -- | -------------- |
| 第1位    | 1位 | 文件类型           |
| 第2-4位  | 3位 | 所有者权限（user）    |
| 第5-7位  | 3位 | 组权限（group）     |
| 第8-10位 | 3位 | 其他用户权限（others） |

---

# 3. 文件类型（第1位）

| 符号 | 类型   | 说明           |
| -- | ---- | ------------ |
| d  | 目录   | directory    |
| -  | 普通文件 | regular file |
| l  | 符号链接 | 类似快捷方式       |
| c  | 字符设备 | 如终端          |
| b  | 块设备  | 如磁盘          |
| p  | 管道   | 进程通信         |
| s  | 套接字  | 网络通信         |

---

# 4. 权限位详解

## 4.1 普通文件权限

| 权限 | 含义       |
| -- | -------- |
| r  | 读取文件内容   |
| w  | 修改文件内容   |
| x  | 执行文件（程序） |

## 4.2 目录权限

| 权限 | 含义         |
| -- | ---------- |
| r  | 查看目录内容（ls） |
| w  | 创建/删除文件    |
| x  | 进入目录（cd）   |

> [!warning] 关键理解
>
> * ==没有 x 权限，无法 cd 进入目录==
> * ==只有 r 没有 x，也无法查看目录内容（ls 会失败）==
> * w 权限通常需要配合 x 才有意义

# 5. 权限数字表示法（八进制）

**权限映射**：

| 权限  | 二进制 | 八进制 |
| --- | --- | --- |
| rwx | 111 | 7   |
| rw- | 110 | 6   |
| r-x | 101 | 5   |
| r-- | 100 | 4   |
| -wx | 011 | 3   |
| -w- | 010 | 2   |
| --x | 001 | 1   |
| --- | 000 | 0   |

**常见示例**：

| 权限字符串      | 数字  |
| ---------- | --- |
| drwxr-xr-x | 755 |
| -rw-r--r-- | 644 |
| -rwxr-xr-x | 755 |
| -rw------- | 600 |

> [!tip] 快速记忆
> ==r=4，w=2，x=1 → 相加得到数字==

# 6. 权限修改（chmod）

## 6.1 数字方式

```bash
chmod 755 file
```

## 6.2 符号方式

```bash
chmod u=rwx,g=rx,o=rx file  # 覆盖旧权限
chmod u+x script.sh  # 给所有者增加执行权限
chmod g-w file  # 禁止所属组的成员修改该文件
chmod o+r file  # 允许系统中的其他任何用户读取该文件
```

**角色拆解 (Who)**：

| 符号 | 含义           |
| -- | ------------ |
| u  | user（文件所有者）    |
| g  | group（文件所属的用户组）     |
| o  | others（其他用户：既不是所有者，也不在所属组内的用户） |
| a  | all（所有人，相当于 `u+g+o`）     |

**操作符 (Operator)**：

| 符号 | 含义           |
| -- | ------------ |
| `+`  | 增加权限    |
| `-`  | 移除权限   |
| `=`  | 精确设置权限（覆盖旧权限） |

> [!info] 注意
> 不指定对象（如 u/g/o）时，默认是 ==a（所有人）==

## 6.4 递归修改

```bash
chmod -R 755 example_dir
```

## 6.5 精细控制（只改文件/目录）

```bash
# 只修改文件
find /path -type f -exec chmod 644 {} +

# 只修改目录
find /path -type d -exec chmod 755 {} +
```

> [!tip] 实战建议
> ==目录通常用755，文件通常用644==

# 7. 所有者与用户组管理

## 7.1 修改所有者（chown）

```bash
chown user file
chown user:group file
```

## 7.2 修改用户组

```bash
chgrp group file
```

## 7.3 递归修改

```bash
chown -R user:group example_dir
```

```bash
chown -R $USER:$(id -gn) example_dir
```

> [!info] 补充
> `$(id -gn)` 表示当前用户所属组

# 8. 特殊权限位

| 权限         | 符号 | 作用         |
| ---------- | -- | ---------- |
| SUID       | s  | 以文件所有者身份执行 |
| SGID       | s  | 以组身份执行     |
| Sticky Bit | t  | 仅文件所有者可删除  |

示例：

```bash
-rwsr-xr-x  # SUID
drwxrwsr-x  # SGID
drwxrwxrwt  # Sticky Bit
```

> [!warning] 高频考点
> `/tmp` 目录权限通常为 ==1777==（带 Sticky Bit）

# 9. umask（默认权限机制）

查看：

```bash
umask
# 示例输出：022
```

**默认权限计算规则**：

| 类型 | 计算方式        |
| -- | ----------- |
| 文件 | $666 - umask$ |
| 目录 | $777 - umask$ |

示例：

```bash
umask = 022
```

| 类型 | 结果  |
| -- | --- |
| 文件 | 644 |
| 目录 | 755 |

> [!warning] 关键点
> 文件默认没有执行权限（不会出现777）

---

# 10. 权限检查顺序（访问机制）

当用户访问文件时：

1. 是否为所有者 → 使用 user 权限
2. 是否属于组 → 使用 group 权限
3. 否则 → 使用 others 权限

> [!info] 核心原则
> 只匹配一类权限，不会叠加

# 11. 常见权限配置

| 场景     | 权限   | 说明         |
| ------ | ---- | ---------- |
| 普通文件   | 644  | 所有者可写，其他只读 |
| 可执行文件  | 755  | 所有人可执行     |
| 私密文件   | 600  | 仅自己可读写     |
| 公共目录   | 755  | 所有人可访问     |
| 私有目录   | 700  | 仅自己访问      |
| /tmp目录 | 1777 | 公共写 + 防删除  |
