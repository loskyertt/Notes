# 1. 打包与压缩的概念

在 Linux 中，**打包**和**压缩**是两个独立的概念，经常被混淆：

| 概念 | 说明 | 常用工具 |
|---|---|---|
| **打包（归档）** | 将多个文件/目录合并为一个文件，**不压缩**，大小基本不变 | `tar`（不带压缩选项） |
| **压缩** | 通过算法减小单个文件的体积 | `gzip`、`bzip2`、`xz`、`zip` |
| **打包 + 压缩** | 先打包再压缩，是最常见的操作 | `tar` 配合 `-z`/`-j`/`-J` 选项 |

**常见压缩格式对比**：

| 格式 | 扩展名 | 压缩工具 | 压缩率 | 速度 | 说明 |
|---|---|---|---|---|---|
| gzip | `.tar.gz` / `.tgz` | gzip | 中 | 快 | 最常用，兼容性最好 |
| bzip2 | `.tar.bz2` / `.tbz2` | bzip2 | 较高 | 较慢 | 压缩率优于 gzip |
| xz | `.tar.xz` | xz | 高 | 慢 | 压缩率最高，耗时最长 |
| zip | `.zip` | zip | 中 | 快 | 跨平台（Windows 兼容） |

# 2. tar 命令

`tar`（Tape Archive）是 Linux 中最核心的打包工具，可以单独打包，也可以配合压缩算法一步完成"打包+压缩"。

## 2.1 常用选项

**操作模式选项**（三选一，必须指定）：

| 选项 | 说明 |
|---|---|
| `-c` | 创建（create）新的归档文件 |
| `-x` | 解包（extract）归档文件 |
| `-t` | 列出（list）归档文件中的内容，不解包 |
| `-u` | 更新（update）归档，将比归档中更新的文件追加进去 |
| `-r` | 追加（append）文件到已有归档末尾（仅未压缩的 `.tar` 支持） |

**压缩算法选项**（可选）：

| 选项 | 压缩工具 | 适用格式 |
|---|---|---|
| `-z` | gzip | `.tar.gz`、`.tgz` |
| `-j` | bzip2 | `.tar.bz2`、`.tbz2` |
| `-J` | xz | `.tar.xz` |

**通用辅助选项**：

| 选项 | 说明 |
|---|---|
| `-f <文件名>` | 指定归档文件名，**必须紧跟文件名**，通常放在选项最后 |
| `-v` | 显示详细过程，列出正在处理的文件名 |
| `-C <目录>` | 指定解包的目标目录 |
| `-p` | 保留文件的原始权限和属主信息（备份时常用） |
| `--exclude=<pattern>` | 排除匹配的文件或目录 |
| `--exclude-vcs` | 排除版本控制目录（`.git`、`.svn` 等） |

## 2.2 打包与压缩

```bash
# 打包为 .tar（不压缩）
tar -cvf archive.tar file1 file2 dir1

# 打包并用 gzip 压缩（最常用）
tar -czvf archive.tar.gz dir1

# 打包并用 bzip2 压缩（压缩率更高）
tar -cjvf archive.tar.bz2 dir1

# 打包并用 xz 压缩（压缩率最高）
tar -cJvf archive.tar.xz dir1

# 打包时排除指定目录（如排除 .git 和 node_modules）
tar -czvf archive.tar.gz project/ --exclude=".git" --exclude="node_modules"

# 打包时保留文件权限（用于备份）
tar -czvpf backup.tar.gz /etc
```

## 2.3 查看归档内容

解包前先查看归档内容是一个好习惯，避免文件被解压到意外位置。

```bash
# 列出归档内容（不解包）
tar -tvf archive.tar

# 列出 gzip 压缩归档的内容
tar -tzvf archive.tar.gz

# 列出 bzip2 压缩归档的内容
tar -tjvf archive.tar.bz2
```

## 2.4 解包与解压

```bash
# 解压 .tar.gz 到当前目录
tar -xzvf archive.tar.gz

# 解压 .tar.bz2 到当前目录
tar -xjvf archive.tar.bz2

# 解压 .tar.xz 到当前目录
tar -xJvf archive.tar.xz

# 解压 .tar（仅打包，无压缩）到当前目录
tar -xvf archive.tar

# 解压到指定目录（目录须预先存在）
tar -xzvf archive.tar.gz -C /path/to/dest

# 只解压归档中的特定文件
tar -xzvf archive.tar.gz path/inside/archive/file.txt

# 自动识别压缩格式（tar 较新版本支持，省去 -z/-j/-J）
tar -xvf archive.tar.gz
```

> **关于 `-f` 的位置**：`-f` 选项必须紧跟归档文件名，不能写成 `tar -fxzv archive.tar.gz`。习惯上将 `-f` 放在选项串最后，如 `-xzvf`。

## 2.5 常用命令速查

| 操作 | 命令 |
|---|---|
| 创建 `.tar.gz` | `tar -czvf out.tar.gz <源文件/目录>` |
| 创建 `.tar.bz2` | `tar -cjvf out.tar.bz2 <源文件/目录>` |
| 创建 `.tar.xz` | `tar -cJvf out.tar.xz <源文件/目录>` |
| 查看内容 | `tar -tvf archive.tar.gz` |
| 解压到当前目录 | `tar -xvf archive.tar.gz` |
| 解压到指定目录 | `tar -xvf archive.tar.gz -C /dest` |

# 3. gzip / gunzip 命令

`gzip` 只能压缩**单个文件**，压缩后原文件默认被替换为 `.gz` 文件。若要压缩多个文件，需先用 `tar` 打包。

```bash
# 压缩单个文件（原文件被替换为 file.txt.gz）
gzip file.txt

# 压缩并保留原文件
gzip -k file.txt

# 设置压缩级别（1=最快/最低压缩率，9=最慢/最高压缩率，默认 6）
gzip -9 file.txt

# 解压（以下三种等价）
gunzip file.txt.gz
gzip -d file.txt.gz
gzip --decompress file.txt.gz

# 查看压缩文件信息（大小、压缩率）而不解压
gzip -l file.txt.gz

# 查看 .gz 文件内容而不解压（相当于 cat）
zcat file.txt.gz

# 在 .gz 文件中搜索（相当于 grep）
zgrep "keyword" file.txt.gz
```

---

# 4. bzip2 / bunzip2 命令

`bzip2` 的压缩率通常优于 `gzip`，但速度较慢。用法与 `gzip` 基本相同。

```bash
# 压缩单个文件（原文件被替换为 file.txt.bz2）
bzip2 file.txt

# 压缩并保留原文件
bzip2 -k file.txt

# 设置压缩级别（1-9，默认 9）
bzip2 -1 file.txt

# 解压（以下三种等价）
bunzip2 file.txt.bz2
bzip2 -d file.txt.bz2

# 查看 .bz2 文件内容而不解压
bzcat file.txt.bz2

# 在 .bz2 文件中搜索
bzgrep "keyword" file.txt.bz2
```

---

# 5. xz / unxz 命令

`xz` 提供最高的压缩率，但压缩速度最慢，适合对体积要求严格的场景（如发布安装包）。

```bash
# 压缩单个文件（原文件被替换为 file.txt.xz）
xz file.txt

# 压缩并保留原文件
xz -k file.txt

# 设置压缩级别（0=最快，9=最慢/最高压缩率，默认 6）
xz -9 file.txt

# 解压（以下三种等价）
unxz file.txt.xz
xz -d file.txt.xz

# 查看 .xz 文件内容而不解压
xzcat file.txt.xz

# 查看压缩文件信息
xz -l file.txt.xz
```

# 6. zip / unzip 命令

`zip` 格式在 Windows 和 macOS 上原生支持，是跨平台共享文件时的首选格式。与 `tar` 不同，`zip` 可以直接对多个文件进行打包并压缩，无需分两步。

```bash
# 将多个文件压缩为 .zip
zip archive.zip file1.txt file2.txt

# 递归压缩整个目录
zip -r archive.zip dir1

# 设置压缩级别（0=仅打包不压缩，9=最高压缩率，默认 6）
zip -9 -r archive.zip dir1

# 向已有 .zip 添加文件
zip archive.zip newfile.txt

# 查看 .zip 内容（不解压）
unzip -l archive.zip

# 解压到当前目录
unzip archive.zip

# 解压到指定目录
unzip archive.zip -d /path/to/dest

# 只解压指定文件
unzip archive.zip specific_file.txt

# 静默解压（不显示文件列表）
unzip -q archive.zip

# 解压时跳过已存在的文件
unzip -n archive.zip

# 解压时覆盖已存在的文件（不提示）
unzip -o archive.zip
```

# 7. 各工具命令速查

| 操作 | gzip | bzip2 | xz | zip |
|---|---|---|---|---|
| 压缩 | `gzip file` | `bzip2 file` | `xz file` | `zip out.zip file` |
| 压缩并保留原文件 | `gzip -k file` | `bzip2 -k file` | `xz -k file` | （默认保留） |
| 解压 | `gunzip file.gz` | `bunzip2 file.bz2` | `unxz file.xz` | `unzip file.zip` |
| 查看内容不解压 | `zcat file.gz` | `bzcat file.bz2` | `xzcat file.xz` | `unzip -l file.zip` |
| 在压缩文件中搜索 | `zgrep` | `bzgrep` | — | — |
| 多文件/目录 | 需先 `tar` 打包 | 需先 `tar` 打包 | 需先 `tar` 打包 | 直接支持 |
