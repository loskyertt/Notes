# 1. 权限模型总览

Linux 文件权限由 **文件类型**、**所有者**、**所属组** 和 **三组权限位**共同决定。

```bash
ls -l
```

示例输出：

```text
drwxr-xr-x  8 sky  sky  4096  Jan 4 17:28 cpp
```

| 字段 | 示例 | 含义 |
|---|---|---|
| 1 | `drwxr-xr-x` | 文件类型与权限 |
| 2 | `8` | 硬链接数量 |
| 3 | `sky` | 所有者 |
| 4 | `sky` | 所属组 |
| 5 | `4096` | 文件大小，单位字节 |
| 6 | `Jan 4 17:28` | 最后修改时间 |
| 7 | `cpp` | 文件名 |

> [!tip]
> 记忆顺序：**类型权限 → 链接数 → 所有者 → 组 → 大小 → 时间 → 名称**。

# 2. 权限字段结构

权限字段 `drwxr-xr-x` 可拆成四段：

```text
d | rwx | r-x | r-x
│   │     │     └── others：其他用户
│   │     └──────── group：所属组
│   └────────────── user：所有者
└────────────────── 文件类型
```

| 区域 | 位数 | 含义 |
|---|---|---|
| 第 1 位 | 1 | 文件类型 |
| 第 2-4 位 | 3 | 所有者权限 |
| 第 5-7 位 | 3 | 所属组权限 |
| 第 8-10 位 | 3 | 其他用户权限 |

# 3. 文件类型

| 符号 | 类型 | 说明 |
|---|---|---|
| `-` | 普通文件 | 文本、二进制、图片等 |
| `d` | 目录 | directory |
| `l` | 符号链接 | 类似快捷方式 |
| `c` | 字符设备 | 终端等字符流设备 |
| `b` | 块设备 | 磁盘等块设备 |
| `p` | 管道 | 进程间通信 |
| `s` | 套接字 | 本地进程通信或网络通信 |

# 4. 权限位含义

## 4.1 普通文件权限

| 权限 | 数值 | 含义 |
|---|---:|---|
| `r` | 4 | 读取文件内容 |
| `w` | 2 | 修改文件内容 |
| `x` | 1 | 执行文件 |

## 4.2 目录权限

| 权限 | 含义 |
|---|---|
| `r` | 查看目录中的文件名 |
| `w` | 在目录内创建、删除、重命名文件 |
| `x` | 进入目录，并访问目录内对象 |

> [!warning]
> 对目录来说，==`x` 是访问入口权限==。只有 `r` 没有 `x`，通常无法正常 `ls`；只有 `w` 没有 `x`，也无法有效创建或删除文件。

# 5. 数字权限表示法

每组权限按 `r=4`、`w=2`、`x=1` 相加。

| 权限 | 二进制 | 八进制 |
|---|---|---:|
| `rwx` | `111` | 7 |
| `rw-` | `110` | 6 |
| `r-x` | `101` | 5 |
| `r--` | `100` | 4 |
| `-wx` | `011` | 3 |
| `-w-` | `010` | 2 |
| `--x` | `001` | 1 |
| `---` | `000` | 0 |

常见组合：

| 权限字符串 | 数字 | 场景 |
|---|---:|---|
| `-rw-r--r--` | 644 | 普通文件 |
| `-rwxr-xr-x` | 755 | 可执行文件 |
| `drwxr-xr-x` | 755 | 普通目录 |
| `-rw-------` | 600 | 私钥、敏感文件 |
| `drwx------` | 700 | 私有目录 |

# 6. 修改权限

## 6.1 数字方式

```bash
# 设置普通文件权限
chmod 644 file.txt

# 设置脚本可执行
chmod 755 script.sh

# 递归修改目录及其所有内容
chmod -R 755 example_dir
```

## 6.2 符号方式

```bash
# 精确设置
chmod u=rwx,g=rx,o=rx file

# 增加执行权限
chmod u+x script.sh

# 移除组写权限
chmod g-w file

# 允许其他用户读取
chmod o+r file

# 所有人增加执行权限
chmod a+x script.sh
```

| 符号 | 类型 | 含义 |
|---|---|---|
| `u` | 对象 | 所有者 |
| `g` | 对象 | 所属组 |
| `o` | 对象 | 其他用户 |
| `a` | 对象 | 所有人 |
| `+` | 操作 | 增加权限 |
| `-` | 操作 | 移除权限 |
| `=` | 操作 | 精确设置权限 |

## 6.3 文件与目录分开修改

递归 `chmod -R` 容易把普通文件也改成可执行。更稳妥的方式是用 `find` 分开处理。

```bash
# 只修改普通文件
find /path -type f -exec chmod 644 {} +

# 只修改目录
find /path -type d -exec chmod 755 {} +
```

> [!tip]
> 常见默认实践：普通文件 `644`，目录 `755`，私钥 `600`，私有目录 `700`。

# 7. 修改所有者与所属组

## 7.1 `chown`

```bash
# 修改所有者
sudo chown user file

# 同时修改所有者和所属组
sudo chown user:group file

# 递归修改目录
sudo chown -R user:group example_dir
```

## 7.2 `chgrp`

```bash
# 修改所属组
sudo chgrp group file

# 递归修改所属组
sudo chgrp -R group example_dir
```

## 7.3 当前用户常用写法

```bash
# 改为当前用户和当前主组
sudo chown -R "$USER:$(id -gn)" example_dir
```

# 8. 特殊权限位

| 权限 | 数字前缀 | 符号 | 作用 |
|---|---:|---|---|
| SUID | 4 | `s` | 执行文件时临时拥有文件所有者身份 |
| SGID | 2 | `s` | 执行文件时临时拥有文件所属组身份；目录中新文件继承组 |
| Sticky Bit | 1 | `t` | 公共目录中只有文件所有者、目录所有者或 root 可删除文件 |

示例：

```bash
# /tmp 常见权限
drwxrwxrwt  root root /tmp

# 设置 sticky bit
chmod 1777 /shared/tmp

# 设置目录 SGID
chmod 2775 /shared/project
```

> [!warning]
> SUID 风险较高，尤其是归 root 所有的可执行文件。生产环境要定期审计异常 SUID 文件。

# 9. umask 默认权限

`umask` 决定新建文件和目录时默认扣除哪些权限。

```bash
umask
# 常见输出：0022
```

默认计算规则：

| 类型 | 基础权限 | 示例 umask `022` 后结果 |
|---|---:|---:|
| 文件 | 666 | 644 |
| 目录 | 777 | 755 |

> [!info]
> 普通文件默认不会带执行权限，所以基础权限是 `666`，不是 `777`。

# 10. 权限匹配顺序

当用户访问文件时，Linux 只选择一组权限，不会叠加：

1. 如果用户是文件所有者，使用 `user` 权限。
2. 否则如果用户属于文件所属组，使用 `group` 权限。
3. 否则使用 `others` 权限。

> [!summary]
> 权限判断不是“把用户、组、其他权限加起来”，而是命中哪一类就只看哪一类。

# 11. 运维常见权限配置

| 场景 | 建议权限 | 说明 |
|---|---:|---|
| 普通配置文件 | 644 | 所有者可写，其他只读 |
| 可执行脚本 | 755 | 所有人可执行，只有所有者可写 |
| 私钥文件 | 600 | 仅所有者可读写 |
| 用户家目录 | 700 或 755 | 视是否允许其他用户访问 |
| Web 静态目录 | 755 | Web 进程需要进入目录 |
| 临时公共目录 | 1777 | 允许写入，但防止互删 |

# 12. 排查清单

> [!summary]
> 本篇核心：先看 `ls -l`，再判断用户身份，最后检查目录链路上的 `x` 权限。

- 当前用户是谁：`id`。
- 文件属于谁：`ls -l file`。
- 父目录是否允许进入：`namei -l /path/to/file`。
- 权限是否被 ACL 扩展控制：`getfacl file`。
- 服务运行用户是否正确：`ps -eo user,pid,cmd | grep service`。
- 修改权限时优先精确到文件或目录，避免粗暴 `chmod -R 777`。
