# 1. 挂载 U 盘

> 首先，确保 U 盘已经插入计算机。

## 1.1 查看设备信息

使用 `lsblk` 或 `fdisk -l` 命令来列出系统中所有的存储设备：

```bash
lsblk
```

加上 `-f` 参数可以显示磁盘的 UUID。

或者使用（显示更详细）：

```bash
sudo fdisk -l
```

## 1.2 挂载

假设你的 U 盘设备是 `/dev/sdb1`：

```bash
sudo mount --mkdir /dev/sdb1 /mnt/usb
```

> [!info] 挂载点说明
> 挂载点是一个空目录，用于访问 U 盘中的文件。参数 `--mkdir` 表示创建 `/mnt/usb` 目录。也可以选择其他路径，例如 `/media/usb` 或 `/home/sky/usb`。

如果挂载成功，使用 `ls /mnt/usb` 或 `lsblk` 可以看到 U 盘的内容。

## 1.3 查看挂载情况

```bash
df -h
```

或者：

```bash
lsblk
```

## 1.4 卸载 U 盘

完成操作后，安全卸载：

```bash
sudo umount /mnt/usb
```

如果出现"设备忙"的错误，可以强制卸载：

```bash
sudo umount -l /mnt/usb
```

> [!tip] 总结
> - 使用 `lsblk` 或 `fdisk -l` 查找 U 盘设备路径
> - 创建空目录作为挂载点
> - 使用 `sudo mount /dev/sdb1 /mnt/usb` 挂载
> - 使用 `sudo umount /mnt/usb` 卸载
>
> 如果 U 盘有特定格式（如 NTFS、FAT32 等），可能需要安装特定的工具来支持，如 `ntfs-3g`。

# 2. 挂载磁盘设备（扩容）

> [!note] 挂载子目录方式
> 该方式是挂载子目录（更简单，但不改变根分区大小），如果不想用 LVM，可以将新磁盘挂载到某个子目录下，比如 `/home`、`/var` 等。

## 2.1 分区与格式化

```bash
sudo fdisk /dev/sdb
```

- 创建新分区（`n`）
- 保存并退出（`w`）

> [!tip] 交互式分区
> 也可以使用 `sudo cfdisk /dev/sdb`，是交互式 CLI 命令，操作更简单。

格式化：

```bash
sudo mkfs.ext4 [-L new_p] /dev/sdb1
```

`mkfs.ext4` 等价于 `mkfs -t ext4`。`-L new_p` 表示将该分区的标签设为 `new_p`（可选）。

## 2.2 挂载新磁盘

临时挂载到 `/mnt/sdb1`：

```bash
sudo mkdir -p /mnt/sdb1
sudo mount /dev/sdb1 /mnt/sdb1
```

如果希望将其永久挂载到 `/home`：

1. 先临时挂载到 `/mnt/sdb1`：

```bash
sudo mkdir -p /mnt/sdb1
sudo mount /dev/sdb1 /mnt/sdb1
```

2. 备份 `/home` 数据：

```bash
sudo rsync -a /home/ /mnt/sdb1/
```

3. 获取 UUID：

```bash
blkid /dev/sdb1
```

4. 编辑 `/etc/fstab`：

```ini
UUID=xxxxx  /home  ext4  defaults  0  2
```

5. 重新挂载：

```bash
sudo rm /home/$USER/ -rf
sudo umount /mnt/sdb1
sudo mount -a
```

> [!warning] 挂载会遮盖原有内容
> 当你将磁盘挂载到 `/home` 目录时，挂载操作会暂时遮盖掉 `/home` 目录中的现有内容。这些文件并没有被删除，只是暂时隐藏。你可以通过卸载磁盘（`sudo umount /home`）查看这些原始文件。如果希望保留原来的内容，建议先备份。

然后重启系统。

## 2.3 检查挂载

```bash
df -h /home
```

# 3. 挂载 Windows 的磁盘分区（双系统）

> [!note] 相关笔记
> 双系统引导问题参见 [[Grub_配置#4.1 双系统引导]]，双系统时间问题参见 [[Grub_配置#4.2 双系统时间不同步]]。

## 3.1 确认 Windows 分区信息

从 `lsblk -f` 输出中，可以看到 Windows 磁盘的 NTFS 分区。

## 3.2 安装 NTFS 支持工具

```bash
sudo pacman -S ntfs-3g
```

## 3.3 创建挂载点

```bash
sudo mkdir -p /mnt/windows_system
sudo mkdir -p /mnt/windows_software
```

## 3.4 挂载分区

### 3.4.1 手动挂载（临时）

```bash
sudo mount -t ntfs3 /dev/nvme1n1p3 /mnt/windows_system
sudo mount -t ntfs3 /dev/nvme1n1p4 /mnt/windows_software
```

验证挂载情况：

```bash
lsblk -f
```

### 3.4.2 自动挂载（持久化）

编辑 `/etc/fstab`，添加以下内容：

```ini
UUID=95519C376F55F65F  /mnt/windows_system  ntfs3  defaults  0  0
UUID=321ABC035AB41F42  /mnt/windows_software ntfs3  defaults  0  0
```

生效配置：

```bash
sudo mount -a
```

## 3.5 解决 Windows 快速启动问题

> [!bug] Windows 休眠导致挂载失败
> 如果挂载时遇到 **"Windows is hibernated"** 错误，是因为 Windows 开启了**快速启动**，需要关闭。

**关闭 Windows 快速启动：**

在 Windows 中：
1. **控制面板** → **电源选项** → **选择电源按钮的功能**
2. 取消勾选 **启用快速启动（推荐）**
3. 重新启动 Windows 并进入 Linux

**或者强制挂载（不推荐）：**

```bash
sudo mount -t ntfs3 -o remove_hiberfile /dev/nvme1n1p3 /mnt/windows_system
```

## 3.6 断开挂载

```bash
sudo umount /mnt/windows_system
sudo umount /mnt/windows_software
```

# 4. `/etc/fstab` 文件说明

## 4.1 示例

```ini
# /etc/fstab: static file system information.
#
# <file system>             <mount point>  <type>  <options>  <dump>  <pass>
UUID=06E8-25E3                            /boot/efi      vfat    defaults,umask=0077 0 2
UUID=e83e2160-e994-4d15-b38a-0b26d5927762 /              ext4    defaults,noatime 0 1
tmpfs                                     /tmp           tmpfs   defaults,noatime,mode=1777 0 0
```

## 4.2 字段说明

每一行包含 6 个字段：

| # | 字段 | 说明 |
|---|---|---|
| 1 | 设备或 UUID | 磁盘或分区 |
| 2 | 挂载点 | 文件夹路径 |
| 3 | 文件系统类型 | 如 `ext4`, `vfat`, `tmpfs` 等 |
| 4 | 挂载选项 | 如 `defaults`, `noatime`, `umask` 等 |
| 5 | 转储选项 | 用于备份，`0` 表示不需要备份 |
| 6 | 文件系统检查顺序 | 通常是 `1` 或 `2` |

> [!info] 常用挂载选项
> - **`noatime`**：不更新文件的访问时间（`atime`），提升性能，特别是在频繁读写场景下
> - **`umask=0077`**：默认权限为 700，即只有文件所有者有读写执行权限，其他用户没有任何权限
>   - 计算方式：从默认权限（文件 `666`，目录 `777`）中减去掩码值
>   - 例如：`666 - 077 = 600`，文件只有所有者可以读写
