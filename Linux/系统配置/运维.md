# 1. CPU 监控

> [!info] /proc 文件系统
> Linux 将所有的硬件和系统信息以"伪文件"的形式存放在 `/proc` 目录下。

## 1.1 查看 CPU 频率

### 从 `/proc/cpuinfo` 查看

获取每一个核心的实时频率：

```bash
grep -E "processor|cpu MHz" /proc/cpuinfo
```

`lscpu` 命令也可以清晰地列出每个 CPU 的当前频率：

```bash
lscpu -e=cpu,mhz
```

> [!warning] 静态快照
> 这两种方式是静态快照。由于现代 CPU 有睿频和节能技术，频率变化极快，你看到的只是执行命令那一瞬间的数值。

### 使用交互式工具

利用 `watch` 命令每秒刷新一次：

```bash
watch -n 1 "grep 'cpu MHz' /proc/cpuinfo"
```

也可以安装 `btop` 或者 `htop` 实时查看。

## 1.2 查看 CPU 温度

安装 `lm_sensors`：

```bash
sudo pacman -S lm_sensors
```

检测传感器：

```bash
sudo sensors-detect
```

查看温度：

```bash
sensors
```

# 2. 内存监控

查看内存使用情况：

```bash
free -h
```

实时监控：

```bash
watch -n 1 free -h
```

> [!tip] 推荐工具
> `btop` 和 `htop` 都可以实时查看内存使用情况，比 `free` 更直观。

# 3. 磁盘监控

查看磁盘使用情况：

```bash
df -h
```

查看目录大小：

```bash
du -sh /path/to/dir
```

查看 IO 情况：

```bash
iostat -x 1
```

> [!info] 需要安装 `sysstat`：`sudo pacman -S sysstat`

# 4. 系统服务管理

查看所有服务状态：

```bash
systemctl list-units --type=service
```

查看失败的服务：

```bash
systemctl --failed
```

查看系统日志：

```bash
journalctl -b
```

> [!tip] 常用 journalctl 参数
> - `journalctl -b`：查看本次启动的日志
> - `journalctl -b -1`：查看上一次启动的日志
> - `journalctl -f`：实时跟踪日志
> - `journalctl -u docker`：查看指定服务的日志

# 5. 推荐监控工具

| 工具 | 安装命令 | 说明 |
|---|---|---|
| **btop** | `sudo pacman -S btop` | 综合系统监控（CPU/内存/磁盘/网络），界面美观 |
| **htop** | `sudo pacman -S htop` | 经典进程查看器，比 top 更友好 |
| **ncdu** | `sudo pacman -S ncdu` | 交互式磁盘使用分析 |
| **iotop** | `sudo pacman -S iotop` | 监控磁盘 IO 使用情况 |
