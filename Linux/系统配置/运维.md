# 1. 查看 cpu 频率

> Linux 将所有的硬件和系统信息以“伪文件”的形式存放在 `/proc` 目录下。

## 1.1 从 `/proc/cpuinfo` 查看

可以通过读取 `/proc/cpuinfo` 来获取每一个核心的实时频率：

```bash
grep -E "processor|cpu MHz" /proc/cpuinfo
```

`lscpu` 命令也可以非常清晰地列出每个 CPU 的当前频率：

```bash
lscpu -e=cpu,mhz
```

> 这两种方式是静态快照。由于现代 CPU 有睿频和节能技术，频率变化极快，你看到的只是执行 `cat` 命令那一瞬间的数值。

## 1.2 使用交互式工具

利用 `watch` 命令每秒刷新一次：

```bash
watch -n 1 "grep 'cpu MHz' /proc/cpuinfo"
```

也可以安装 `btop` 或者 `htop` 实时查看。
