## 2.2 Linux

> 从大一下学期开始，我第一次接触 Linux，从 Ubuntu -> Manjaro -> EndeavourOS -> Arco -> Arch -> NixOS。

网上对 Linux 的桌面发行版有很多说法，最常见的是：
- “普通人还是老老实实用 Windows ......”
- “Linux 不稳定了啊......”
- “输入法很难配置啊......”
- “到最后还是会回到 Windows ......”
- “折腾 Linux 就是浪费时间 ......”
......

个人认为，到现在 Linux 的桌面发行版是非常稳定的，那怕是在网上被人调侃极易“滚挂”的 Arch Linux，在使用得当的情况下，也是非常稳定的，更何况还有 snapper 这种快照工具，只要不把系统的引导搞坏，都能轻松修复系统。再者，大部分技术大佬都是从普通人过来的。对于普通小白，有时间想折腾就去折腾呗，折腾既是一种乐趣，也是一种学习过程，反正现在 Linux 的教程更丰富了，桌面环境也更完善，学习成本不是很高，觉得不适合还可以装双系统。

> - 一键送达 [NixOS 安装教程](Linux/NixOS/01_安装_NixOS.md)。
