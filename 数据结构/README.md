# 2. 推荐复习路径

```mermaid
flowchart LR
    A[01 线性表] --> B[02 栈和队列]
    B --> C[03 树和二叉树]
    C --> D[04 图]
    D --> E[05 查找]
    E --> F[06 排序]
```

1. 先掌握线性表的逻辑结构、顺序存储和链式存储。
2. 再学习栈、队列、数组等受限线性结构，并熟悉递归与栈的关系。
3. 然后掌握树的表示、遍历、哈夫曼树和各种查找树。
4. 在图中综合使用队列、栈、贪心、动态规划和并查集。
5. 最后用查找和排序的复杂度、稳定性与适用场景做综合比较。
