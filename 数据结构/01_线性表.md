# 1. 线性表基础

## 1.1 数据结构与算法

数据结构是相互之间存在一种或多种特定关系的数据元素集合。数据结构包含三个方面：

- **逻辑结构**：数据元素之间的关系，如线性结构、树形结构和图结构。
- **存储结构**：数据及其关系在计算机中的表示，如顺序存储和链式存储。
- **数据运算**：查找、插入、删除、遍历等操作及其实现。

算法具有五个基本特性：有穷性、确定性、输入、输出和可行性。

常见复杂度记号：

- $O(1)$ 表示操作次数与问题规模无关。
- $O(n)$ 表示需要遍历规模为 $n$ 的数据。
- $O(\log n)$ 常见于折半查找。
- $O(n^2)$ 常见于两层嵌套遍历或顺序表的大量移动。

## 1.2 线性表的定义

线性表是具有相同数据类型的 $n$ 个数据元素的有限序列，通常记为：

$$
L=(a_1,a_2,\ldots,a_n)
$$

其中 $a_i$ 是第 $i$ 个元素，元素位序从 **1** 开始。空表不含任何元素。

> [!warning] 位序与下标
> 线性表的位序通常从 1 开始，C/C++ 数组下标从 0 开始。做题时先确认题目使用的是位序还是数组下标。

# 2. 顺序表

顺序表使用一段地址连续的存储空间依次存放线性表元素。设首地址为 `LOC(a[0])`，每个元素占 $l$ 个存储单元，则：

$$
LOC(a[i])=LOC(a[0])+i\times l
$$

顺序表适合随机访问，按下标访问的时间复杂度为 $O(1)$。插入和删除通常需要移动元素，平均时间复杂度为 $O(n)$。

## 2.1 插入与删除

在含有 $n$ 个元素的顺序表中：

- 插入有 $n+1$ 个可能位置，若各位置等概率，平均移动元素数为

$$
\frac{0+1+\cdots+n}{n+1}=\frac n2
$$

- 删除有 $n$ 个可能位置，若各位置等概率，平均移动元素数为

$$
\frac{0+1+\cdots+(n-1)}n=\frac{n-1}{2}
$$

插入位置越靠前，移动元素越多。删除末尾元素不需要移动其他元素。

## 2.2 顺序表的优缺点

| 特点 | 说明 |
|---|---|
| 随机访问 | 根据下标直接定位，$O(1)$ |
| 插入删除 | 中间位置需要移动元素，平均 $O(n)$ |
| 存储空间 | 连续，可能需要预留容量或扩容 |
| 局部性 | 元素连续存储，适合缓存访问 |

# 3. 链表

链表通过指针把分散的结点连接起来。单链表结点可以表示为：

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};
```

## 3.1 头指针与头结点

- **头指针**指向链表的第一个结点。带头结点时，它指向头结点。
- **头结点**是位于首元结点之前的附加结点，通常不存储有效数据。
- 设置头结点可以统一首元结点和普通结点的插入、删除逻辑，减少对空表和首结点的特殊判断。

不带头结点的单链表：

```text
head
 |
[1] → [2] → [3] → nullptr
```

带头结点的单链表：

```text
head
 |
[X] → [1] → [2] → [3] → nullptr
```

> [!warning] 头结点不等于头指针
> 头结点是一个实际的附加结点，头指针是指向某个结点的指针。无论是否设置头结点，头指针都表示链表入口。

## 3.2 链表的基本操作

若已经知道待插入位置的前驱结点，单链表插入只需修改有限个指针，时间复杂度为 $O(1)$。按位查找前驱需要从头遍历，时间复杂度为 $O(n)$。

```cpp
// 在 prev 之后插入 node
node->next = prev->next;
prev->next = node;
```

删除 `prev` 后的结点：

```cpp
ListNode* removed = prev->next;
prev->next = removed->next;
delete removed;
```

双链表的结点同时保存前驱和后继指针，删除已定位的结点更方便，但每个结点需要额外存储一个指针。

## 3.3 循环链表

循环单链表的尾结点指向头结点。对于带头结点的循环单链表，空表条件为：

```cpp
L->next == L
```

循环链表适合需要反复从表尾回到表头的场景。若只保存尾指针 `rear`，可以在 $O(1)$ 时间内访问头结点 `rear->next` 和尾结点 `rear`。

# 4. 存储结构对比

| 操作 | 顺序表 | 单链表 |
|---|---:|---:|
| 按位访问 | $O(1)$ | $O(n)$ |
| 已知位置插入 | $O(n)$ | $O(1)$ |
| 已知位置删除 | $O(n)$ | $O(1)$ |
| 查找指定值 | $O(n)$ | $O(n)$ |
| 空间连续性 | 要求连续 | 不要求连续 |

选择顺序表还是链表，主要看是否需要频繁随机访问、插入删除是否已知位置，以及存储空间是否容易连续分配。

# 5. 易错点

1. 线性表元素的位序从 1 开始，数组下标通常从 0 开始。
2. 头结点不存储有效数据，但仍然占用一个结点空间。
3. 头指针可以指向头结点，也可以在不带头结点时直接指向首元结点。
4. 链表插入和删除的 $O(1)$ 结论要求已经定位到相关结点，不能把查找位置的时间忽略掉。
5. 顺序表插入时移动的是插入位置及其后的元素，删除时移动的是被删元素之后的元素。
