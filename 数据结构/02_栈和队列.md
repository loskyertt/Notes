# 1. 栈

栈是一种只允许在一端进行插入和删除的线性表，插入和删除的一端称为栈顶，另一端称为栈底。栈遵循 **后进先出（LIFO）**。

常见操作：

- `push`：入栈。
- `pop`：出栈。
- `top`：读取栈顶元素。
- 判空：栈中没有元素。

栈常用于函数调用、递归、表达式求值、括号匹配、深度优先搜索和回溯。

## 1.1 卡特兰数与出栈序列

当 $n$ 个不同元素依次入栈时，不同出栈排列的数量为第 $n$ 个卡特兰数：

$$
C_n=\frac{1}{n+1}\binom{2n}{n}
$$

并不是所有 $n!$ 种排列都能通过一个栈得到。判断具体序列时，需要满足任意时刻出栈数量不超过已入栈数量。

# 2. 队列

队列只允许在队尾插入，在队头删除，遵循 **先进先出（FIFO）**。

- `enqueue`：入队。
- `dequeue`：出队。
- `front`：读取队头元素。

队列常用于层序遍历、广度优先搜索、任务调度和缓冲区。

## 2.1 循环队列

假设数组长度为 `MaxSize`，`front` 指向队头元素，`rear` 指向队尾元素的下一个位置。

### 预留一个空间的实现

| 状态 | 条件 |
|---|---|
| 队空 | `front == rear` |
| 队满 | `(rear + 1) % MaxSize == front` |
| 元素个数 | `(rear - front + MaxSize) % MaxSize` |
| 出队后 | `front = (front + 1) % MaxSize` |
| 入队后 | `rear = (rear + 1) % MaxSize` |

队满时必须预留一个数组单元，否则队空和队满都会表现为 `front == rear`，无法区分。此实现最多存储 `MaxSize - 1` 个元素。

```text
队空：
[_, _, _, _, _]
 ↑
front == rear

队满：
[_, A, B, C, D]
 ↑           ↑
front       rear
```

### 记录 `size` 的实现

如果额外维护元素个数 `size`，则可以使用全部数组空间：

- 队空：`size == 0`
- 队满：`size == MaxSize`

> [!warning] 先确认 `rear` 的语义
> 有的题目规定 `rear` 指向队尾元素，有的实现规定 `rear` 指向下一次入队位置。队满公式和指针移动必须按照题目约定使用。

# 3. 数组

## 3.1 地址计算

设数组元素占 $l$ 个存储单元。

一维数组：

$$
LOC(a[i])=LOC(a[start])+(i-start)\times l
$$

二维数组若有 $n$ 列、$m$ 行：

- **行优先**：

$$
LOC(a[i][j])=LOC(a[0][0])+(i\times n+j)\times l
$$

- **列优先**：

$$
LOC(a[i][j])=LOC(a[0][0])+(j\times m+i)\times l
$$

公式中的 `0` 是起始下标。若题目给出其他起始下标，需要先换算相对偏移量。

## 3.2 多维数组

$n$ 维数组可以看作元素为 $(n-1)$ 维数组的一维数组。地址计算本质上是按存储顺序计算线性偏移量。

## 3.3 特殊矩阵的压缩存储

- 对称矩阵只需保存上三角或下三角的一半元素。
- 行优先存储上三角矩阵时，按行累计每一行实际保存的元素数。
- 列优先存储下三角矩阵时，按列累计每一列实际保存的元素数。
- 三对角矩阵只保存主对角线及其相邻的两条对角线。

三对角矩阵示例：

```text
| a  b  0  0  0 |
| c  d  e  0  0 |
| 0  f  g  h  0 |
| 0  0  i  j  k |
| 0  0  0  l  m |
```

稀疏矩阵常见表示：

- 三元组顺序表：只保存 `(行下标, 列下标, 值)`。
- 行链式存储：每一行维护非零元素链表。
- 十字链表：同时维护行、列方向的链接。

# 4. 广义表

广义表是元素可以是原子或子表的有限序列。

- **表头**：广义表的第一个元素。
- **表尾**：除表头外其余元素组成的表，表尾不是最后一个元素。
- **深度**：广义表中括号嵌套的最大层数，原子通常深度为 0。

例如：

```text
A = (a, (b, c), d)
```

`a` 是表头，`((b, c), d)` 是表尾，`(b, c)` 是一个子表。

# 5. 结构选择与易错点

1. 栈关注后进先出，队列关注先进先出。
2. 循环队列的模运算是为了让指针到达数组末尾后回到数组开头。
3. 循环队列队满时是否浪费一个空间，取决于是否额外记录 `size` 或标志位。
4. 数组地址公式必须区分行优先与列优先，也必须确认元素大小和下标起点。
5. 广义表的表尾是一个表，不能把表尾理解成最后一个原子元素。
