# 1. 构造函数的初始化方式

> 构造函数是理解类生命周期的起点，C++ 提供了多种初始化对象的语法，它们在底层有着细微但重要的区别。

以 `Entity` 类为例：

```cpp
class Entity {
 public:
  string name;
  int data;

 public:
  void print() { std::cout << "Hello" << "\n"; }
};
```

## 1.1 括号初始化 (Direct Initialization)

```cpp
Entity e1("Name", 10);
```

- **特点**：最传统的 C++ 方式，明确调用匹配的构造函数。

## 1.2 赋值初始化 (Copy Initialization)

```cpp
Entity e2 = "Name"; // 仅当构造函数接受单个参数且未声明为 explicit 时
```

- **底层**：编译器尝试将右侧隐式转换为左侧类型。

## 1.3 列表初始化 (Uniform Initialization / Curly Braces)

```cpp
Entity e3{"Name", 10};
Entity e4 = {"Name", 10};
```

- **特点**：C++11 引入，被称为“统一初始化”。
    
- **区别**：它不允许 **窄化转换**（比如你不能把 `double` 传给要求 `int` 的构造函数），安全性最高。

# 2. 成员初始化列表 (Member Initializer List)

这是构造函数中 **最推荐** 的初始化成员变量的方式。

```cpp
class Entity {
private:
    std::string m_name;
    int m_score;

public:
    // 冒号后面的部分就是初始化列表
    Entity(const std::string& name, int score) 
        : m_name(name), m_score(score) 
    {
        // 构造函数体
    }
};
```

> 为什么建议使用初始化列表？

1. **效率更高**：在进入构造函数大括号 `{}` 之前，成员已经被创建。如果在 `{}` 里用 `m_name = name;`，其实是先调用了 `m_name` 的默认构造函数，再调用了赋值运算符。**初始化列表则是一步到位。**
    
2. **强制性场景**：以下三类成员**必须**在初始化列表中初始化，不能在 `{}` 里赋值：
    - **`const` 成员**。
    - **引用类型成员 (`&`)**。
    - **没有默认构造函数的类对象成员**。

# 3. 常见构造函数类型

1. **默认构造函数 (Default Constructor)**：没有参数，或者所有参数都有默认值。如果你不写任何构造函数，编译器会为你生成一个。

2. **有参构造函数 (Parameterized Constructor)**：接收参数来设置对象的初始状态。

3. **拷贝构造函数 (Copy Constructor)**：使用同类型对象来初始化新对象（涉及深浅拷贝，我们在前文讨论过）。
	```cpp
	Entity(const Entity& other);
	```

4. **移动构造函数 (Move Constructor)**：C++11 引入，用于转移资源所有权（如堆内存），避免昂贵的深拷贝。
	```cpp
	Entity(Entity&& other) noexcept;
	```

> [!Info] 重点
> 如果你自己定义了任何构造函数，编译器就不再自动生成默认构造函数。

```cpp
struct Entity {
    int x, y;
    Entity(int x, int y) : x(x), y(y) {}  // 定义了有参构造函数
};

Entity e;           // ❌ 编译报错：没有默认构造函数
Entity e(10, 20);   // ✅ 正常
```

如果你两个都想要，那手动补上默认构造函数即可：

```cpp
struct Entity {
    int x, y;
    Entity() = default;                     // 显式要回默认构造函数
    Entity(int x, int y) : x(x), y(y) {}    // 有参构造函数
};

Entity e;                 // ✅ 正常
Entity e(10, 20);         // ✅ 正常
Entity *e = new Entity(); // ✅ 正常
```

`= default` 的意思就是显式生成一个默认的（析构函数也可以这样指定）。

> 注：`Entity *e = new Entity();` 和 `Entity *e = new Entity;` 是等价的，都是调用**默认构造函数**，两者**没有实际区别**，加括号 `()` 更明确地表达"我在调用构造函数"，因此很多人更倾向于前者写法。

# 4. 特殊场景与关键字

## 4.1 `explicit` 关键字

用于防止隐式转换。如果构造函数只有一个参数，建议默认加上 `explicit`。

```cpp
class Entity {
    explicit Entity(int age) { ... }
};

// Entity e = 10; // ❌ 报错，不能隐式转换
Entity e(10);     // ✅ 只能显式调用
```

## 4.2 委托构造函数 (Delegating Constructor)

一个构造函数可以调用同一个类中的另一个构造函数，减少代码重复。

```cpp
Entity() : Entity("Unknown", 0) {} // 调用下面的主构造函数
Entity(std::string name, int score) : m_name(name), m_score(score) {}
```

## 4.3 默认/禁用构造函数 (`default` / `delete`)

```cpp
Entity() = default;           // 强制编译器生成默认构造函数
Entity(const Entity&) = delete; // 禁用拷贝构造函数（如智能指针常用）
```

---

# 5. 总结

构造函数的使用准则：
1. **首选初始化列表**：它比在构造函数体内赋值更快、更安全。
2. **注意顺序**：成员变量的初始化顺序是**声明顺序**，而不是初始化列表中的顺序。
3. **遵循“三/五法则”**：如果你手动写了析构函数释放资源，通常也需要写拷贝构造和拷贝赋值。
4. **默认 explicit**：单参数构造函数除非有特殊理由，否则应加上 `explicit`。
