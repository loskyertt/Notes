# 1. 基础语法

## 1.1 点操作符

点操作符 `.` 用于通过对象或引用访问成员。

```cpp
struct Entity
{
    int x = 0;
    void print() const {}
};

Entity e;
e.x = 1;
e.print();
```

## 1.2 箭头操作符

箭头操作符 `->` 用于通过指针访问成员。

```cpp
Entity e;
Entity* p = &e;

p->x = 1;
p->print();
```

对原生指针而言：

```cpp
p->member
```

等价于：

```cpp
(*p).member
```

括号不可省略，因为 `.` 的优先级高于 `*`。

> [!summary]
> `.` 的左侧是对象或引用；`->` 的左侧是指针，或者是重载了 `operator->` 的类对象。

---

# 2. 底层语义

## 2.1 成员访问是偏移访问

对象成员通常位于对象起始地址之后的固定偏移处。

```cpp
struct Vector3
{
    float x;
    float y;
    float z;
};
```

在常见平台上，`z` 的偏移量是 8：

```text
Vector3 对象起始地址
  |
  v
+---------+---------+---------+
| x (4B)  | y (4B)  | z (4B)  |
+---------+---------+---------+
偏移 0     偏移 4    偏移 8
```

成员访问可以理解为“对象起始地址 + 成员偏移”，但编译器会同时处理类型、访问控制、对齐和优化。

## 2.2 空指针不能访问成员

```cpp
Entity* p = nullptr;
// p->print(); // 未定义行为
```

即使成员函数内部没有显式访问数据成员，通过空指针调用非静态成员函数也不应依赖。非静态成员函数需要隐式 `this` 指针，空 `this` 不是有效对象。

# 3. 重载 `operator->`

## 3.1 基本规则

类可以重载 `operator->`，让包装类型表现得像指针。

```cpp
class ScopePtr
{
public:
    explicit ScopePtr(Entity* p) : ptr_(p) {}
    ~ScopePtr() { delete ptr_; }

    Entity* operator->()
    {
        return ptr_;
    }

    const Entity* operator->() const
    {
        return ptr_;
    }

private:
    Entity* ptr_;
};
```

使用方式：

```cpp
ScopePtr p(new Entity{});
p->print();
```

编译器会转换为：

```cpp
(p.operator->())->print();
```

## 3.2 递归规则

`operator->` 的返回值必须是：

1. 原生指针；或
2. 另一个重载了 `operator->` 的对象。

若返回的是第二类对象，编译器会继续调用它的 `operator->`，直到最终得到原生指针。

## 3.3 工程用途

重载 `->` 的价值不是省略语法，而是在成员访问前后注入资源管理逻辑：

| 用途 | 示例 |
|---|---|
| 所有权管理 | `std::unique_ptr<T>` |
| 共享所有权 | `std::shared_ptr<T>` |
| 迭代器访问 | `iterator->member` |
| 延迟加载 | 首次访问时加载对象 |
| 检查与代理 | 访问前做空值检查或锁保护 |

> [!warning]
> 自己实现智能指针时，还需要处理拷贝/移动语义、异常安全和所有权规则。示例中的 `ScopePtr` 只用于说明 `operator->`。

# 4. 成员偏移量

## 4.1 使用 `offsetof`

获取标准布局类型成员偏移量，应使用标准库宏 `offsetof`。

```cpp
#include <cstddef>
#include <iostream>

struct Vector3
{
    float x;
    float y;
    float z;
};

int main()
{
    std::size_t offset = offsetof(Vector3, z);
    std::cout << offset << '\n';
}
```

`offsetof(Vector3, z)` 表示成员 `z` 相对对象起始地址的字节偏移。

## 4.2 避免空指针技巧

旧代码中可能看到这种写法：

```cpp
auto offset = reinterpret_cast<std::uintptr_t>(&((Vector3*)nullptr)->z);
```

它试图把对象起始地址假设为 0，再取成员地址作为偏移量。现代 C++ 中应避免这种技巧：

- 可读性差。
- 容易涉及空指针成员访问的未定义行为。
- 对非标准布局类型不可靠。
- 标准库已有 `offsetof`。

> [!info]
> `offsetof` 主要适用于标准布局类型。含虚函数、复杂继承或非标准布局的类型，不应依赖固定 C 风格内存布局。

---

# 5. 易错点

1. **写成 `*p.member`**：应写 `(*p).member`，因为 `.` 优先级高于 `*`。
2. **空指针调用成员函数**：即使偶尔能运行，也属于不可靠行为。
3. **只提供非 const `operator->`**：`const` 包装对象无法访问成员，应补充 const 重载。
4. **滥用偏移量技巧**：优先使用 `offsetof`，并确认类型满足标准布局要求。
5. **误以为 `operator->` 只能返回原生指针**：它也可以返回另一个支持 `->` 的代理对象。

---

# 6. 总结

| 表达式 | 左侧要求 | 含义 |
|---|---|---|
| `obj.member` | 对象或引用 | 直接访问成员 |
| `ptr->member` | 指针 | 等价于 `(*ptr).member` |
| `wrapper->member` | 重载 `operator->` 的对象 | 调用 `operator->` 后继续成员访问 |
| `offsetof(T, m)` | 标准布局类型 | 获取成员字节偏移 |

> [!summary]
> 箭头操作符把“指针解引用 + 成员访问”合成一个表达式；重载 `operator->` 则让 RAII 包装器、迭代器和代理对象能够自然地参与成员访问。
