# 1. 基本语法

## 1.1 函数指针的声明

函数指针的声明必须包含函数的**返回类型**和**参数列表**，因为这两者共同构成了函数的"类型签名"——只有类型匹配的函数才能被赋值给该指针。

```cpp
// 声明语法：返回类型 (*指针名)(参数列表)
void (*funcPtr)(int);           // 指向"返回 void，接受一个 int"的函数
int  (*calcPtr)(int, int);      // 指向"返回 int，接受两个 int"的函数
bool (*predPtr)(const char*);   // 指向"返回 bool，接受一个 const char*"的函数
```

**括号不可省略**：`void *funcPtr(int)` 是一个**返回 `void*` 的普通函数声明**，而非函数指针。

## 1.2 赋值与调用

```cpp
void HelloWorld(int a) {
    std::cout << "Hello Value: " << a << std::endl;
}

int main() {
    // 赋值：函数名即函数地址，可以带 & 也可以不带（两者等价）
    void (*ptr)(int) = HelloWorld;   // 隐式取地址
    void (*ptr)(int) = &HelloWorld;  // 显式取地址，效果相同

    // 调用：两种写法等价
    ptr(10);     // 现代写法（推荐）
    (*ptr)(10);  // 传统解引用写法

    // 安全检查：调用前判断指针是否为空
    if (ptr) {
        ptr(10);
    }

    // 重置为空
    ptr = nullptr;
}
```

## 1.3 使用别名简化声明

原始函数指针的语法晦涩难读，尤其在作为参数或返回值时。可以使用 `typedef` 或 `using` 为其定义别名：

```cpp
// C 风格 typedef
typedef void (*Callback)(int);

// C++11 using（推荐，语义更清晰：Callback 是一个类型）
using Callback = void(*)(int);

// 有了别名，声明和使用都清晰很多
void ForEach(const std::vector<int>& values, Callback func) {
    for (int val : values) func(val);
}

Callback ptr = HelloWorld;   // 与 void (*ptr)(int) = HelloWorld 完全等价
ptr(10);
```

## 1.4 函数指针数组

当需要根据索引或状态分派到不同函数时，函数指针数组比 `if-else` / `switch` 更简洁高效：

```cpp
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }
int mul(int a, int b) { return a * b; }
int div(int a, int b) { return a / b; }

int main() {
    // 声明函数指针数组
    int (*ops[4])(int, int) = { add, sub, mul, div };

    // 使用别名更易读
    using BinaryOp = int(*)(int, int);
    BinaryOp ops2[4] = { add, sub, mul, div };

    for (int i = 0; i < 4; ++i) {
        std::cout << ops[i](10, 3) << "\n";  // 输出: 13  7  30  3
    }
}
```

## 1.5 成员函数指针

普通函数指针**不能**直接指向类的非静态成员函数，因为成员函数隐含了 `this` 指针，语法和调用方式都不同：

```cpp
class Calculator {
public:
    int add(int a, int b) { return a + b; }
    static int mul(int a, int b) { return a * b; }  // 静态成员函数
};

int main() {
    // 非静态成员函数指针：类型中需要包含类名
    int (Calculator::*memberPtr)(int, int) = &Calculator::add;

    Calculator calc;
    // 调用时必须绑定对象实例
    int result = (calc.*memberPtr)(3, 4);    // 通过对象调用
    
    Calculator* pCalc = &calc;
    result = (pCalc->*memberPtr)(3, 4);      // 通过指针调用

    // 静态成员函数：与普通函数指针相同，无需绑定实例
    int (*staticPtr)(int, int) = &Calculator::mul;
    result = staticPtr(3, 4);
}
```

# 2. 回调函数

## 2.1 核心概念

**回调函数（Callback）** 是指将一个函数作为参数传递给另一个函数，由后者在合适的时机调用。

```
普通调用：调用方  ──────────────►  被调用函数
            你主动调用

回调调用：调用方  ◄──────────────  框架/库
            你把函数交出去，框架决定何时调用
```

回调的本质是**控制反转（Inversion of Control）**：框架负责流程，你只负责填入具体逻辑。这也是策略模式、观察者模式等设计模式的底层思想。

## 2.2 基础示例

```cpp
#include <iostream>

void onTaskDone(int result) {
    std::cout << "任务完成，结果：" << result << "\n";
}

// 框架函数：接受一个函数指针，在适当时机调用它
void doTask(void (*callback)(int)) {
    std::cout << "正在执行任务...\n";
    int result = 42;
    callback(result);   // 回调：把结果交给调用方提供的函数
}

int main() {
    doTask(onTaskDone);
}
```

输出：

```
正在执行任务...
任务完成，结果：42
```

`doTask` 完全不知道 `onTaskDone` 的存在，只知道"它会在完成时调用某个符合签名的函数"——这实现了框架与业务逻辑的**解耦**。

## 2.3 遍历与过滤

函数指针最典型的应用是编写通用遍历/过滤逻辑，由调用方注入具体行为：

```cpp
#include <vector>
#include <iostream>

// ForEach：通用遍历，具体对每个元素做什么由调用方决定
void ForEach(const std::vector<int>& values, void(*func)(int)) {
    for (int val : values) {
        func(val);
    }
}

void PrintValue(int val) {
    std::cout << "Value: " << val << "\n";
}

void DoubleValue(int val) {
    std::cout << "Double: " << val * 2 << "\n";
}

int main() {
    std::vector<int> nums = {1, 2, 3, 4, 5};

    ForEach(nums, PrintValue);   // 注入"打印"逻辑
    ForEach(nums, DoubleValue);  // 注入"翻倍"逻辑
}
```

## 2.4 标准库中的回调

C++ 标准库大量使用回调来分离算法框架与比较/判断逻辑：

```cpp
#include <vector>
#include <algorithm>
#include <iostream>

bool greaterThan3(int x) { return x > 3; }
bool descending(int a, int b) { return a > b; }

int main() {
    std::vector<int> v = {1, 5, 2, 4, 3};

    // std::sort 接受比较回调，由你决定排序规则
    std::sort(v.begin(), v.end(), descending);
    // v: {5, 4, 3, 2, 1}

    // std::count_if 接受谓词回调，由你决定"满足条件"的定义
    int count = std::count_if(v.begin(), v.end(), greaterThan3);
    std::cout << "大于 3 的有 " << count << " 个\n";  // 输出: 2

    // std::find_if 找到第一个满足条件的元素
    auto it = std::find_if(v.begin(), v.end(), greaterThan3);
    if (it != v.end()) {
        std::cout << "第一个大于 3 的元素：" << *it << "\n";
    }
}
```

# 3. 使用场景

## 3.1 策略模式：动态切换行为

用函数指针数组根据状态切换行为，避免冗长的 `if-else` 链：

```cpp
// 游戏中的武器攻击逻辑
void swordAttack()  { std::cout << "挥剑！\n"; }
void bowAttack()    { std::cout << "射箭！\n"; }
void magicAttack()  { std::cout << "施法！\n"; }

enum class Weapon { Sword, Bow, Magic };

int main() {
    using AttackFn = void(*)();
    AttackFn attacks[] = { swordAttack, bowAttack, magicAttack };

    Weapon current = Weapon::Bow;
    attacks[static_cast<int>(current)]();  // 输出：射箭！
}
```

## 3.2 C 语言库接口对接

在 C 语言编写的底层库（如 `pthread`、`sqlite3`、`qsort`）中，函数指针是唯一的回调机制：

```cpp
#include <cstdlib>   // qsort
#include <cstring>   // strcmp

// qsort 的比较回调必须符合 C 接口签名
int compareInts(const void* a, const void* b) {
    return (*(int*)a - *(int*)b);
}

int main() {
    int arr[] = {5, 3, 1, 4, 2};
    qsort(arr, 5, sizeof(int), compareInts);
    // arr: {1, 2, 3, 4, 5}
}
```

# 4. 现代 C++ 的替代方案

原始函数指针有两个主要局限：

1. **无法捕获状态**：只能指向全局函数或静态成员函数，无法携带局部变量（闭包）。
2. **语法晦涩**：嵌套声明时可读性极差。

C++11 提供了三种更现代的替代方案。

## 4.1 Lambda 表达式（首选）

Lambda 是定义在函数内部的匿名函数，可以**捕获局部变量**，语法简洁，易于内联优化：

```cpp
#include <vector>
#include <algorithm>
#include <iostream>

int main() {
    std::vector<int> nums = {1, 2, 3, 4, 5};

    int threshold = 3;

    // Lambda 捕获了局部变量 threshold（原始函数指针做不到这点）
    auto count = std::count_if(nums.begin(), nums.end(),
        [threshold](int val) {
            return val > threshold;
        }
    );
    std::cout << "大于 " << threshold << " 的有 " << count << " 个\n";

    // 也可以直接传给之前的 ForEach
    ForEach(nums, [](int val) {
        std::cout << val << "\n";
    });
}
```

**Lambda 捕获方式**：

| 捕获语法 | 含义 |
|---|---|
| `[]` | 不捕获任何外部变量 |
| `[x]` | 按值捕获变量 `x` |
| `[&x]` | 按引用捕获变量 `x` |
| `[=]` | 按值捕获所有用到的外部变量 |
| `[&]` | 按引用捕获所有用到的外部变量 |
| `[=, &x]` | 默认按值，但 `x` 按引用 |

> **注意**：不捕获任何变量的 Lambda（`[]` 捕获列表为空）可以**隐式转换为对应的函数指针**，其余带捕获的 Lambda 不能转换为普通函数指针，需要用 `std::function` 或模板接收。

## 4.2 `std::function`（灵活存储）

`std::function` 是一个"万能包装器"，可以统一存储和传递**任何可调用对象**：函数指针、Lambda、成员函数（配合 `std::bind`）等。

```cpp
#include <functional>
#include <iostream>

// 参数类型声明为 std::function，可以接受任何匹配签名的可调用对象
void doTask(std::function<void(int)> callback) {
    callback(42);
}

void myFunc(int val) { std::cout << "函数指针：" << val << "\n"; }

int main() {
    // 传普通函数指针
    doTask(myFunc);

    // 传 Lambda（即使有捕获也能传）
    int multiplier = 2;
    doTask([multiplier](int val) {
        std::cout << "Lambda：" << val * multiplier << "\n";
    });

    // 作为成员变量存储回调（函数指针做不到这点）
    std::function<void(int)> stored = myFunc;
    stored(10);
    stored = [](int val) { std::cout << "切换：" << val << "\n"; };
    stored(10);
}
```

> **性能注意**：`std::function` 内部涉及类型擦除，可能触发堆分配，有一定运行时开销。在性能敏感的热路径上，优先使用模板方案。

## 4.3 模板（最高性能）

通过模板参数接受可调用对象，编译器可在编译期将逻辑**内联（Inline）** 到调用处，性能最优，是标准库算法（`std::sort` 等）的实现方式：

```cpp
#include <vector>
#include <iostream>

// F 可以是函数指针、Lambda、std::function，或任何重载了 operator() 的对象
template<typename F>
void ForEach(const std::vector<int>& values, F func) {
    for (int val : values) {
        func(val);
    }
}

int main() {
    std::vector<int> nums = {1, 2, 3};

    // 传函数指针
    ForEach(nums, [](int val) { std::cout << val << "\n"; });

    // 传带捕获的 Lambda，编译器自动推导类型
    int factor = 10;
    ForEach(nums, [factor](int val) {
        std::cout << val * factor << "\n";
    });
}
```

C++20 引入了**概念（Concepts）**，可以对模板参数增加类型约束，提供更友好的编译错误信息：

```cpp
#include <concepts>

// 要求 F 必须是一个接受 int 参数的可调用对象
template<std::invocable<int> F>
void ForEach(const std::vector<int>& values, F func) {
    for (int val : values) func(val);
}
```

# 5. 对比总结

## 5.1 四种回调方式对比

| | **原始函数指针** | **`std::function`** | **Lambda** | **模板** |
|---|---|---|---|---|
| **运行时开销** | 极低（仅指针跳转） | 较高（类型擦除、可能堆分配） | 极低（易内联） | 零（编译期展开） |
| **能否捕获状态** | ❌ | ✅ | ✅ | ✅ |
| **能否存为成员变量** | ✅（类型固定） | ✅（类型统一） | 需配合 `auto` 或 `std::function` | ❌（模板不能直接存储） |
| **语法可读性** | 差 | 优 | 优 | 优 |
| **适用场景** | 对接 C 接口 | 存储/传递复杂可调用对象 | 局部一次性逻辑（首选） | 高性能通用算法 |

## 5.2 选型建议

```
需要对接 C 语言库（pthread、qsort 等）？
    └─► 使用原始函数指针

需要在类成员中存储回调，或统一接受多种可调用对象？
    └─► 使用 std::function

只是临时注入一段逻辑，不需要存储？
    └─► 使用 Lambda（首选）

编写通用算法库，对性能要求高？
    └─► 使用模板（+ C++20 Concepts 约束）
```
