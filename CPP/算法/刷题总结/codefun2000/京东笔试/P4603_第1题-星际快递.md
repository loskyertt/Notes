# 1. 题目

星际快递公司有 $N$ 个包裹需要派送，每个包裹有两种派送方式：

1. 常规派送（消耗较多燃料）
2. 虫洞派送（使用一个虫洞通行证，可以消耗较少燃料的情况下完成派送）

当前快递飞船携带了 $X$ 单位的燃料和 $Y$ 张虫洞通行证。

星际快递公司想要计算，在优先派送尽可能多包裹的情况下，最小的燃料消耗是多少，请你帮助他们计算一下。

- **输入描述**：
  - 第一行三个整数 $N, X, Y$，分别表示包裹数量，携带燃料量以及通行证数量。
  - 接下来 $N$ 行，每行两个整数，表示各个包裹常规派送和虫洞派送分别需要的燃料量。
  - 数据范围：
    - $1 \leq N \leq 100$
    - $1 \leq X \leq 5000$
    - $1 \leq Y \leq 50$
    - 每个包裹常规派送和虫洞派送的燃料消耗均介于 $[1, 50]$ 之间。

- **输出描述**：一行，两个整数，空格分开，表示最多可派送的包裹数量及对应的最小燃料消耗。

示例1

```
输入：
3 20 1
8 5
7 4
10 6

输出：
2 12
```

示例2

```
输入：
4 25 2
10 6
8 5
12 7
9 6

输出：
3 20
```

# 2. 题解

## 2.1 题意与输入输出解析

本题属于典型的**带双约束的组合优化问题**。核心目标具有优先级：
1. **第一优先级**：在燃料 $X$ 与通行证 $Y$ 的限制下，尽可能多地完成包裹派送（最大化派送数量）。
2. **第二优先级**：在达到最大派送数量的所有可行方案中，选择总燃料消耗最小的方案（最小化燃料消耗）。

**输入描述解读**：
- 首行 `N X Y`：`N` 为包裹总数，`X` 为飞船初始燃料总量，`Y` 为虫洞通行证总量。
- 后续 `N` 行：每行两个整数 `a b`，分别表示该包裹采用**常规派送**所需的燃料 `a`，以及采用**虫洞派送**所需的燃料 `b`（虫洞派送会额外消耗 1 张通行证）。

**输出描述解读**：
- 输出两个整数，以空格分隔。第一个整数为**最大可派送包裹数**，第二个整数为在该数量下的**最小燃料消耗**。
- 若燃料极少导致无法派送任何包裹，则输出 `0 0`。

**示例演算（以示例1为例）**：
`N=3, X=20, Y=1`，包裹成本分别为 `(8,5)`, `(7,4)`, `(10,6)`。
- 若尝试派送 3 个包裹：最多使用 1 张通行证。最优策略是将通行证用于燃料节省最多的包裹，但即使如此，最小总燃料为 `5+7+10=22`（或 `8+4+10=22` 等），均超过 $X=20$，故 3 个不可行。
- 尝试派送 2 个包裹：枚举所有组合并合理使用通行证。
  - 选包裹1、2：常规+常规=`15`；1虫+2常=`12`；1常+2虫=`12`。最小为 `12`（≤20）。
  - 选其他组合的最小燃料均大于 `12`。
- 因此最大数量为 `2`，对应最小燃料为 `12`。输出 `2 12` 与样例一致。

## 2.2 解题思路（动态规划）

该问题可抽象为**0-1 背包问题的二维变体**。我们需要同时记录“已派送包裹数量”与“已使用通行证数量”，并在状态转移中维护最小燃料消耗。

### 2.2.1 状态定义
设 `dp[i][j]` 表示：**派送恰好 `i` 个包裹，且消耗恰好 `j` 张虫洞通行证时，所需的最小燃料总量**。
- 维度范围：`i ∈ [0, N]`，`j ∈ [0, Y]`。
- 初始状态：`dp[0][0] = 0`，其余状态初始化为无穷大（表示不可达）。

### 2.2.2 状态转移

遍历每一个包裹（设其常规消耗为 `cost_reg`，虫洞消耗为 `cost_worm`），更新 DP 表。为避免同一包裹被重复选取，需采用**逆序枚举**（类似 0-1 背包的空间优化技巧）：

```text
对于 包裹 k (cost_reg, cost_worm):
    对于 i 从 N-1 递减到 0:
        对于 j 从 Y 递减到 0:
            若 dp[i][j] 不可达，跳过
            // 选择常规派送
            dp[i+1][j] = min(dp[i+1][j], dp[i][j] + cost_reg)
            // 选择虫洞派送（需通行证未超限）
            若 j+1 ≤ Y:
                dp[i+1][j+1] = min(dp[i+1][j+1], dp[i][j] + cost_worm)
```

### 2.2.3 结果提取

所有包裹处理完毕后，从 `i = N` 向下遍历至 `0`：
- 计算当前 `i` 对应的最小燃料：`min_fuel = min{ dp[i][0], dp[i][1], ..., dp[i][Y] }`。
- 若 `min_fuel ≤ X`，则说明在当前燃料限制下最多可派送 `i` 个包裹。由于是倒序查找，首次满足条件的 `i` 即为全局最大值，直接输出 `i` 与 `min_fuel` 并终止程序即可。此步骤天然契合“优先最大化数量，其次最小化燃料”的题意要求。

#### 4. 复杂度评估
- **时间复杂度**：$O(N^2 \cdot Y)$。外层遍历 $N$ 个包裹，内层两层循环分别至多 $N$ 和 $Y$ 次。代入上限 $N=100, Y=50$，运算量约 $5 \times 10^5$，远低于常规时限（$10^8$ 次/秒）。
- **空间复杂度**：$O(N \cdot Y)$。仅需维护二维 DP 数组，内存消耗极小（约 $100 \times 50 \times 4 \text{ Bytes} \approx 20 \text{ KB}$）。

## 2.3 代码实现

```cpp
#include <algorithm>
#include <ios>
#include <iostream>
#include <vector>

using ll = long long;

void solve() {
  int N, X, Y;  // 分别表示包裹数量，携带燃料量以及通行证数量
  std::cin >> N >> X >> Y;

  const int INF = 1e9;  // 足够大的初始值，大于最可能燃料消耗 5000

  // 初始化 dp 表
  // dp[i][j] 表示恰好派送 i 个包里，使用 j 张通行证时的最小燃料消耗
  std::vector<std::vector<int>> dp(N + 1, std::vector<int>(Y + 1, INF));
  dp[0][0] = 0;
  for (int k = 0; k < N; ++k) {
    int regular_cost, wormhole_cost;
    std::cin >> regular_cost >> wormhole_cost;

    // 逆序枚举已派送包里数，防止同一包里在同一次决策中被重复使用
    for (int i = N; i >= 1; --i) {
      for (int j = Y; j >= 0; --j) {
        // 策略 1：使用常规派送（不消耗通行证）
        if (dp[i - 1][j] != INF) {
          dp[i][j] = std::min(dp[i][j], dp[i - 1][j] + regular_cost);
        }

        // 策略 2：使用虫洞派送（消耗 1 张通行证）
        if (j > 0 && dp[i - 1][j - 1] != INF) {
          dp[i][j] = std::min(dp[i][j], dp[i - 1][j - 1] + wormhole_cost);
        }
      }
    }
  }

  int max_packages = 0;
  int min_fuel = 0;

  // 逆序查找最大可派送包里数
  for (int i = N; i >= 0; --i) {
    int current_min = INF;
    for (int j = 0; j <= Y; ++j) {
      if (dp[i][j] <= X) {
        current_min = std::min(current_min, dp[i][j]);
      }
    }

    // 若存在合法方案，由于 i 从大到小枚举，首次命中即为最大包里数
    if (current_min != INF) {
      max_packages = i;
      min_fuel = current_min;
      break;
    }
  }

  std::cout << max_packages << " " << min_fuel << "\n";
}

int main() {
  std::ios::sync_with_stdio(false);
  std::cin.tie(nullptr);

  solve();
}
```

## 2.4 关键注意事项

1. **逆序遍历的必要性**：内层 `i` 与 `j` 必须从大到小枚举。若正序枚举，会导致当前包裹在本次循环中更新出的状态（如 `dp[i+1][j]`）被后续更大的 `i` 再次引用，从而违背“每个包裹仅能选择一种派送方式”的约束。
2. **无穷大取值**：`0x3f3f3f3f` 是竞赛中常用的安全无穷大值，其值约为 $10^9$，既不会在加法中溢出 `int`，又能保证 `min` 操作的正确性。
3. **边界处理**：当 $X$ 极小导致无法派送任何包裹时，循环最终会落在 `i=0`，此时 `dp[0][0]=0 ≤ X`，程序将正确输出 `0 0`。

此方案严格遵循题目优先级约束，时间与空间复杂度均处于最优量级，可稳定通过全部测试数据。
