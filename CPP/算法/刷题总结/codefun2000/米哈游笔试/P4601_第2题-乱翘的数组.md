# 1. 题目

对于给定的长度为 $n$ 的数组 $a$，定义**翘数**为同时严格大于或小于左右相邻数的数字。

形式化讲，对于第 $i$ 个整数 $a_i$，它是翘数当且仅当满足 $a_i > a_{i-1}$ 且 $a_i > a_{i+1}$，或者 $a_i < a_{i-1}$ 且 $a_i < a_{i+1}$。

如果一个数组中所有满足边界条件的数字均为翘数，且任意相邻元素不相等，则称该数组为**乱翘的数组**。

计算最少需要从原数组中删除的数字个数，使得剩余数字按原相对顺序拼接成乱翘的数组。

- **输入描述**：第一行输入一个整数 $n$。第二行输入 $n$ 个整数，表示数组 $a$。
- **输出描述**：输出一个整数，表示最少需要删除的数字个数。

### 示例 1

```
输入：
7
1 3 1 4 5 2 0

输出：
2
```

**说明**：其中一种最优的方案是删除数组中的第**五**、**七**个数字。

### 示例 2

```
输入：
3
2 2 2

输出：
2
```

# 2. 题解

## 2.1 题意解析

这题的关键在于把“乱翘”的定义抽象成一个**序列形态约束问题**，然后转化为**最长子序列**问题来做。

一个数组是“乱翘的数组”，满足：

1. 条件 1：**相邻元素不相等**

```text
a[i] != a[i+1]
```

2. 条件 2：**所有“有左右邻居”的点都是翘数**

也就是对所有：$1 \le i \le k-2$

必须满足：$(a_i - a_{i-1}) \times (a_i - a_{i+1}) > 0$

> [!tip] 核心转化
> 把原数组变成一个“合法序列”，并且：**删除最少 = 保留最多**
> 所以问题变成：**求最长“乱翘子序列”**。

## 2.2 关键性质（非常关键）

一个“乱翘数组”一定满足：**相邻差值（即：$nums[i] - nums[i-1]$）符号交替**

> [!example] 举例
> 
> 合法序列：
> 
> ```
> 1 3 1 4 2
> ```
> 
> 差值：
> 
> ```
> +  -  +  -
> ```
> 
> 再看：
> 
> ```
> 1 2 3 4
> ```
> 
> 差值：
> 
> ```
> + + +   ❌ 不合法
> ```

## 2.3 算法思路：贪心最优解

维护：
- `prev_diff`：前一个差值的符号
- `cur_diff`：当前差值

当满足：

```text
cur_diff > 0 && prev_diff <= 0
或
cur_diff < 0 && prev_diff >= 0
```

就说明发生了“摆动”，可以加入答案。

**初始化**：
- 第一个元素一定选
- 从第二个开始判断

题目要求：**相邻元素不能相等**

所以：

```text
cur_diff == 0 → 直接跳过
```

## 2.4 示例推演

```
1 3 1 4 5 2 0
```

差值：

```
+ - + + - -
```

选取过程：

```
1 → 3 → 1 → 4 → 2
```

长度 = 5

原长度 = 7

删除：

```
7 - 5 = 2
```

## 2.5 代码实现

```cpp
#include <cstddef>
#include <ios>
#include <iostream>
#include <vector>

using ll = long long;

void solve() {
  int n;  // 数组元素个数
  std::cin >> n;

  if (n <= 0) {
    std::cout << 0 << "\n";
    return;
  }

  std::vector<int> nums(n);
  for (size_t i = 0; i < n; ++i) {
    std::cin >> nums[i];
  }

  int count = 1;  // 至少选 1 个
  ll prev_diff = 0;
  for (size_t i = 1; i < n; ++i) {
    ll curr_diff = nums[i] - nums[i - 1];
    if (curr_diff > 0 && prev_diff <= 0) {
      count++;
      prev_diff = curr_diff;
    } else if (curr_diff < 0 && prev_diff >= 0) {
      count++;
      prev_diff = curr_diff;
    }
    // curr_diff == 0，跳过
  }

  std::cout << (n - count) << "\n";
}

int main() {
  std::ios::sync_with_stdio(false);
  std::cin.tie(nullptr);

  solve();
}
```
