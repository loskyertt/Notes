# 1. 题目

米小游给定了一个长度为 $n$ 的整数序列 $a_1, a_2, \ldots, a_n$，请你统计有多少对 $(i, j)$ 满足：

- $1 \leq i < j \leq n$
- $|a_i - a_j| = 1$
- 在 $a_i$ 和 $a_j$ 之间（不包括 $a_i$ 和 $a_j$）的所有数字都严格大于 $\max(a_i, a_j)$

- **输入描述**：
  - 每个测试文件均包含多组测试数据。第一行输入一个整数 $T$（$1 \leq T \leq 10^4$）代表数据组数，每组测试数据描述如下：
    - 第一行一个整数 $n$（$1 \leq n \leq 2 \times 10^5$），表示序列 $a$ 的长度。
    - 第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$1 \leq a_i \leq 10^9$），表示数字序列。
  - 除此之外，保证单个测试文件的 $n$ 之和不超过 $3 \times 10^5$。

- **输出描述**：对于每组测试数据，输出一个整数表示满足条件的对数。

示例1

```
输入：
2
5
1 3 2 4 1
4
2 2 2 2

输出：
3
0
```

> **说明**：
> 第一组数据：
> - (1, 2): $|1 - 3| = 2$ 不满足
> - (1, 3): $|1 - 2| = 1$，中间 $3 > 2$ 满足
> - (1, 5): $|1 - 1| = 0$ 不满足
> - (2, 3): $|3 - 2| = 1$，无中间数字 满足
> - (2, 4): $|3 - 4| = 1$，中间 $2 < 4$ 不满足
> - (3, 4): $|2 - 4| = 2$ 不满足
> - (3, 5): $|2 - 1| = 1$，中间 $4 > 2$ 满足
> 
> 共 3 对满足。
> 
> 第二组数据：
> 所有数字相同，没有满足条件的对。

---

# 2. 题解

这道题是一道非常巧妙的单调栈（Monotonic Stack）应用题。题目给出的条件看似复杂，但如果将其转化为几何图形，逻辑就会非常清晰。

## 2.1 题意解析

我们要寻找满足以下三个条件的数对 $(a_i, a_j)$：

1. **数值相邻**：它们的差绝对值为 1（例如 1 和 2，或者 3 和 4）。
2. **中间阻隔**：在它们两个数中间的数（如果有的话），必须全部**严格大于**它们中的较大者。
3. **顺序要求**：$i < j$。

示例 1 模拟分析：`1 3 2 4 1`
- **数对 (1, 3)**：数值为 $1$ 和 $2$。中间有一个数 $3$。因为 $3 > \max(1, 2)$，所以**满足**。
- **数对 (2, 3)**：数值为 $3$ 和 $2$。中间没有数，默认**满足**。
- **数对 (2, 4)**：数值为 $3$ 和 $4$。中间有一个数 $2$。因为 $2 < \max(3, 4)$，所以**不满足**。
- **数对 (3, 5)**：数值为 $2$ 和 $1$。中间有一个数 $4$。因为 $4 > \max(2, 1)$，所以**满足**。

## 2.2 解题思路：单调栈

如果我们要满足“中间所有数都大于两端”，这意味着 $a_i$ 和 $a_j$ 必须是彼此离得最近的、且不被比它们小的数“挡住”的数。这正是单调栈的用武之地。

### 2.2.1 核心观察

对于序列中的任何一个数 $x$：
1. 它可能作为左端点 $a_i$ 与右侧某个 $x \pm 1$ 匹配。
2. 为了满足“中间数严格大于端点”，当我们从左往右遍历时，如果遇到一个**比栈顶元素小**的数，那么栈顶元素与当前数之间就可能构成符合条件的对。

### 2.2.2 具体步骤

1. **维护一个单调递增栈**：栈内存储元素的数值及其下标。
2. **遍历序列**：
    - 当当前数 $a_j$ **小于** 栈顶元素时：
        - 栈顶元素 $a_{top}$ 与当前数 $a_j$ 之间没有比它们小的数。
        - 检查是否满足 $|a_{top} - a_j| = 1$。如果满足，答案加 1。
        - 将 $a_j$ 压入栈。
    - 当当前数 $a_j$ **等于** 栈顶元素时：
        - 因为题目要求中间的数必须“严格大于”，所以两个相等的数之间不能有任何数（或者中间的数都比它们大，但这不满足 $|a_i - a_j|=1$）。
        - 由于相等不满足差为 1，直接更新栈顶位置（或保留一个即可，因为它们会同时被更小的数挡住）。
    - 当当前数 $a_j$ **大于** 栈顶元素时：
        - 说明栈顶元素找到了它的“右边界”。
        - 弹出栈顶元素 $a_{top}$，并检查它与 $a_j$ 是否满足 $|a_{top} - a_j| = 1$。
        - 继续比较新的栈顶，直到栈为空或栈顶元素 $\geq a_j$。

> [!tip] 关键点
> 其实更简单的思考方式是：**每一对满足条件的 $(a_i, a_j)$，在单调栈维护过程中，其中一个数必然会在另一个数进入栈或弹出栈时被触发检查。**

## 2.3 代码实现

```cpp
#include <iostream>
#include <vector>
#include <stack>
#include <cmath>

using namespace std;

/**
 * 核心逻辑：
 * 我们寻找满足 |a_i - a_j| = 1 且中间数都大于 max(a_i, a_j) 的对。
 * 这意味着在单调递增栈的维护过程中，
 * 只有相邻的、未被更小数挡住的元素才可能配对。
 */

void solve() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }

    long long count = 0;
    // 栈内存储数值
    vector<int> st;

    for (int i = 0; i < n; ++i) {
        // 当发现当前元素比栈顶小时，它可能与栈顶配对（中间无阻隔）
        // 当发现当前元素比栈顶大时，栈顶被弹出前可能与当前元素配对
        
        while (!st.empty() && a[i] > st.back()) {
            if (a[i] - st.back() == 1) {
                count++;
            }
            st.pop_back();
        }
        
        if (!st.empty()) {
            if (st.back() - a[i] == 1) {
                count++;
            }
            // 如果相等，为了满足“严格大于”的要求，旧的相等元素已经没用了
            if (st.back() == a[i]) {
                st.pop_back();
            }
        }
        
        st.push_back(a[i]);
    }

    cout << count << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--) {
        solve();
    }
    return 0;
}
```

## 2.4 复杂度与细节分析

- **时间复杂度**：$O(N)$。虽然代码中有 `while` 循环，但每个元素最多进栈一次、出栈一次。对于 $3 \times 10^5$ 的数据量，可以在 100ms 内运行完毕。
- **空间复杂度**：$O(N)$。用于存储栈。
- **关于相等元素**：如果序列中有连续的 `2 2 2`，它们之间不满足 $|a_i - a_j|=1$。根据代码逻辑，当遇到第二个 `2` 时，会弹出第一个 `2` 并压入新的 `2`。这保证了栈的单调性，同时正确处理了边界。

这种解法之所以高效，是因为它利用单调栈过滤掉了那些绝对不可能成为端点的“被遮挡”的数。
