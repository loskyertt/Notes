# 1. 题目

给定一种规律 `pattern` 和一个字符串 `s`，判断 `s` 是否遵循相同的规律。

这里的 **遵循** 指完全匹配，例如，`pattern` 里的每个字母和字符串 `s` 中的每个非空单词之间存在着双向连接的对应规律。具体来说：

- `pattern` 中的每个字母都 **恰好** 映射到 `s` 中的一个唯一单词。
- `s` 中的每个唯一单词都 **恰好** 映射到 `pattern` 中的一个字母。
- 没有两个字母映射到同一个单词，也没有两个单词映射到同一个字母。

- **输入描述**：
  - `pattern`：只包含小写英文字母的字符串（$1 \leq \text{pattern.length} \leq 300$）。
  - `s`：由单个空格分隔的小写英文字母组成的字符串（$1 \leq s.\text{length} \leq 3000$），不包含前导或尾随空格。

- **输出描述**：返回布尔值 `true` 或 `false`，表示 `s` 是否遵循 `pattern` 的规律。

示例1

```
输入：pattern = "abba", s = "dog cat cat dog"
输出：true
```

示例2

```
输入：pattern = "abba", s = "dog cat cat fish"
输出：false
```

示例3

```
输入：pattern = "aaaa", s = "dog cat cat dog"
输出：false
```

---

# 2. 题解

这道题本质上是验证两组元素之间是否存在**双向唯一映射**（即数学上的**双射**关系）。

## 2.1 问题分析与核心概念

我们可以将问题理解为建立“暗号对接”系统。`pattern` 中的字母代表暗号，`s` 中的单词代表明文。匹配过程必须遵守以下两条铁律：

1. **字母对单词的唯一性**：如果一个字母 `a` 代表了单词 `dog`，那么它不能再代表其他单词，且每次遇到 `a` 必须对应 `dog`。
2. **单词对字母的唯一性**：如果一个单词 `dog` 被分配给了字母 `a`，那么它就不能再分配给字母 `b`。

**案例解析**：

- **示例 1 (`pattern = "abba", s = "dog cat cat dog"`)**：
  - `a` 与 `dog` 建立映射，`b` 与 `cat` 建立映射。
  - 再次遇到 `b` 时对应 `cat`，再次遇到 `a` 时对应 `dog`，逻辑通顺。
  - **结果**：`true`。

- **示例 3 (`pattern = "ab", s = "dog dog"`)**：
  - `a` 与 `dog` 建立映射。
  - 随后 `b` 也试图与 `dog` 建立映射。虽然 `b` 之前没出现过，但 `dog` 已经被 `a` 占用了。
  - **结果**：`false`（违反了单词对字母的唯一性）。

## 2.2 算法思路：双向映射验证

为了同时满足上述两条铁律，最清晰的方法是**维护两个哈希表**，分别记录两个方向的映射关系。

### 2.2.1 算法步骤

1. **字符串分割**：利用空格将字符串 `s` 分割成单词数组 `words`。
2. **长度校验**：如果 `pattern` 的长度与 `words` 的长度不相等，说明无法一一对应，直接返回 `false`。
3. **遍历验证**：同时遍历 `pattern` 和 `words`：
   - 检查 **字母 -> 单词** 的映射：如果当前字母已有映射，检查映射值是否为当前单词。
   - 检查 **单词 -> 字母** 的映射：如果当前单词已有映射，检查映射值是否为当前字母。
   - 如果上述检查均通过且为新组合，则在两个哈希表中建立双向映射。
4. 若遍历结束未发现冲突，返回 `true`。

> [!tip] 💡 为什么需要两个哈希表？

> 若只使用一个哈希表（例如仅记录 `字母 -> 单词`），只能检测出“一个字母对应多个单词”的错误，无法检测出“多个字母对应同一个单词”的错误。
> 
> | 错误类型 | 示例 | 仅用 `字母->单词` 表检测 | 使用双向映射检测 |
> | :--- | :--- | :--- | :--- |
> | 一个字母对应多个单词 | `a` 先遇 `dog` 后遇 `cat` | **能检测** (发现 `a` 映射冲突) | **能检测** |
> | 多个字母对应同一个单词 | `a` 遇 `dog`，`b` 也遇 `dog` | **无法检测** (`b` 是新键，插入成功) | **能检测** (通过 `单词->字母` 表发现冲突) |

# 3. 代码实现

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <sstream>
#include <unordered_map>

using namespace std;

class Solution {
public:
    bool wordPattern(string pattern, string s) {
        // 1. 分割字符串，将 s 拆分为单词数组
        vector<string> words;
        stringstream ss(s);
        string word;
        while (ss >> word) {
            words.push_back(word);
        }

        // 2. 长度校验：字母数量必须等于单词数量
        if (pattern.length() != words.size()) return false;

        // 3. 定义两个哈希表用于双向映射
        unordered_map<char, string> p2s; // 字母 -> 单词
        unordered_map<string, char> s2p; // 单词 -> 字母

        for (int i = 0; i < pattern.length(); ++i) {
            char ch = pattern[i];
            string w = words[i];

            // 检查字母是否已有映射且映射是否一致
            if (p2s.count(ch) && p2s[ch] != w) return false;
            
            // 检查单词是否已有映射且映射是否一致
            if (s2p.count(w) && s2p[w] != ch) return false;

            // 如果是新配对，建立双向映射
            p2s[ch] = w;
            s2p[w] = ch;
        }

        return true;
    }
};
```

# 4. 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 为 `pattern` 的长度。分割字符串、遍历验证和哈希表操作的时间复杂度均为线性。
- **空间复杂度**：$O(n)$，需要存储单词数组和两个哈希表的映射关系。

# 5. 扩展方法：单映射表与集合

如果希望减少数据结构的数量，可以使用**一个哈希表**加上**一个集合**来实现：

1. 使用 `unordered_map<char, string>` 记录 `字母 -> 单词` 的映射。
2. 使用 `unordered_set<string>` 记录已经被映射过的单词。

**逻辑**：
- 若字母在哈希表中存在，检查映射单词是否匹配。
- 若字母不存在，检查当前单词是否已在 `set` 中。若在 `set` 中，说明该单词已被其他字母占用，返回 `false`；若不在，则建立映射并将单词加入 `set`。

这种方式同样能保证双向绑定的正确性。
