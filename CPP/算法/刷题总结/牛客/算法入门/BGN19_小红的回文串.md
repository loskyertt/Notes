# 1. 题目

小红有一个字符串，她可以进行以下操作：

- **拆分**：把 `'w'` 拆成 2 个 `'v'`，`'m'` 拆成 2 个 `'n'`。
- **轴对称**：把 `'b'` 轴对称成 `'d'`，`'p'` 轴对称成 `'q'`，反之亦然。
- **翻转**：把 `'b'` 翻转成 `'q'`，把 `'d'` 翻转成 `'p'`，把 `'n'` 翻转成 `'u'`，反之亦然。

经过若干次操作后，小红想知道这个字符串能不能变成回文串。

- **输入描述**：
  - 第一行输入一个整数 $T$（$1 \leq T \leq 10^4$）表示询问次数。
  - 接下来 $T$ 行，每行输入一个字符串表示询问。
  - 所有字符串长度之和不超过 $10^5$。

- **输出描述**：输出 $T$ 行，每行输出 "YES" 或 "NO" 表示是否可以变成回文串。

示例1

```
输入：5
wovv
bod
pdd
moom
lalalalai

输出：YES
YES
YES
YES
NO
```

> **说明**：
> - 第一个字符串可以变成：vvovv（将第一个 w 拆成两个 v）
> - 第二个字符串可以变成：bob、dod、pop 或 qoq
> - 第三个字符串可以变成：bdb
> - 第四个字符串本来就是回文的，不用进行操作
> - 第五个字符串不可以变成回文串

# 2. 题解

这道题本质上是一个关于**字符等价性**和**字符串构建**的问题。由于操作涉及字符形态改变和数量变化，直接在原字符串上使用双指针匹配会存在逻辑陷阱。

## 2.1 操作性质分析

首先，我们需要对题目中的三种操作进行分类，分析它们对字符串结构的影响：

1.  **轴对称与翻转（等价类合并）**：
    - 题目描述 `b` 可以变成 `d`、`p`、`q`，且操作可逆。
    - 这意味着在判断能否构成回文时，`b`、`d`、`p`、`q` 这四个字符是**完全等价**的。无论字符串某一位是什么，只要属于这个集合，都可以变成该集合内的任意字符来匹配另一端。
    - 同理，`n` 和 `u` 通过翻转操作可以互变，它们属于同一个等价类。

2.  **拆分（长度变化）**：
    - `w` $\to$ `vv` 和 `m` $\to$ `nn` 这两个操作会改变字符串的长度。
    - 长度的改变使得我们不能简单地使用双指针法（即左指针 `l++` 右指针 `r--`）。例如，字符串 `"wv"`，若 `w` 拆分为 `vv`，变为 `"vvv"`，这是一个回文串。但在原字符串层面，`w` 和 `v` 并不是显而易见的匹配关系。

## 2.2 解题思路：标准化处理

针对上述特性，最清晰的做法是对字符串进行**标准化**处理。我们的目标是消除所有变换带来的不确定性，将字符串转化为一个“基准形态”。只要两个字符串的基准形态相同，它们就可以互相转化。

### 2.2.1 建立映射规则

我们需要将所有具有“变换关系”的字符统一为一个标准字符：

1.  **处理等价类（长度不变）**：
    - 对于 `b, d, p, q`：任选一个作为代表，例如统一映射为 `'b'`。
    - 对于 `n, u`：任选一个作为代表，例如统一映射为 `'n'`。

2.  **处理拆分类（长度改变）**：
    - 对于 `w`：它等价于两个 `v`。为了统一，我们将其展开，映射为字符串 `"vv"`。
    - 对于 `m`：它等价于两个 `n`。结合上面的等价类规则，我们将其映射为字符串 `"nn"`。

3.  **处理无关字符**：
    - 对于 `v, a, l, o` 等未提及的字符，它们只能对应自己，保持原样。特别注意 `v`，虽然 `w` 会变成 `v`，但 `v` 本身不能变成其他字符，也不参与 `n/u` 的等价类，所以 `v` 保持不变。

### 2.2.2 判定回文

经过标准化处理后，原问题转化为：**判断转换后的新字符串是否为回文串**。

- **充分性**：如果新字符串是回文串，那么原字符串可以通过逆操作（或正向操作）还原或变换。例如新串首尾都是 `'b'`，原串首尾分别是 `'d'` 和 `'q'`，它们显然可以互相变换匹配。
- **必要性**：如果原字符串能变成回文串，那么在标准化规则下，回文串两端的字符必须属于同一个等价类或拆分类，这意味着它们标准化后的结果必然相同，即新字符串必然是回文。

# 3. 算法实现

## 3.1 算法步骤

1.  读入字符串 $S$。
2.  初始化一个空字符串 $T$ 用于存储转换结果。
3.  遍历字符串 $S$ 中的每个字符 $c$：
    -   若 $c \in \{b, d, p, q\}$，向 $T$ 追加 `'b'`。
    -   若 $c \in \{n, u\}$，向 $T$ 追加 `'n'`。
    -   若 $c = 'w'$，向 $T$ 追加 `"vv"`。
    -   若 $c = 'm'$，向 $T$ 追加 `"nn"`。
    -   否则，直接向 $T$ 追加 $c$。
4.  判断字符串 $T$ 是否为回文串（比较 $T$ 和 $T$ 的逆序串）。
5.  输出结果。

## 3.2 代码

```cpp
#include <iostream>
#include <string>
#include <algorithm>

using namespace std;

void solve() {
    string s;
    cin >> s;
    string transformed = "";

    // 第一步：标准化处理
    for (char c : s) {
        if (c == 'w') {
            transformed += "vv"; // w 拆分为 vv
        } else if (c == 'm') {
            transformed += "nn"; // m 拆分为 nn
        } else if (c == 'b' || c == 'd' || c == 'p' || c == 'q') {
            transformed += 'b';  // b, d, p, q 统一为 b
        } else if (c == 'n' || c == 'u') {
            transformed += 'n';  // n, u 统一为 n
        } else {
            transformed += c;    // 其他字符（如 a, v, l, i 等）保持原样
        }
    }

    // 第二步：直接判断转换后的字符串是否是回文
    string rev = transformed;
    reverse(rev.begin(), rev.end());

    if (transformed == rev) {
        cout << "YES" << endl;
    } else {
        cout << "NO" << endl;
    }
}

int main() {
    // 优化输入输出效率
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    if (!(cin >> t)) return 0;
    while (t--) {
        solve();
    }
    return 0;
}
```

## 3.3 复杂度分析

- **时间复杂度**：设所有字符串的总长度为 $N$。遍历字符串的时间复杂度为 $O(N)$，构建新字符串的最坏情况长度为 $2N$，反转和比较字符串的时间复杂度为 $O(N)$。因此，总时间复杂度为 $O(N)$。
- **空间复杂度**：需要额外的空间存储转换后的字符串，最坏情况下空间复杂度为 $O(N)$。

# 4. 示例验证

利用上述算法逻辑验证题目中的示例：

1.  **输入：`wovv`**
    - `w` $\to$ `vv`
    - `o` $\to$ `o`
    - `vv` $\to$ `vv`
    - 转换后：`vvovv`。是回文，输出 **YES**。

2.  **输入：`bod`**
    - `b` $\to$ `b`
    - `o` $\to$ `o`
    - `d` $\to$ `b`
    - 转换后：`bob`。是回文，输出 **YES**。

3.  **输入：`pdd`**
    - `p` $\to$ `b`
    - `d` $\to$ `b`
    - `d` $\to$ `b`
    - 转换后：`bbb`。是回文，输出 **YES**。

4.  **输入：`moom`**
    - `m` $\to$ `nn`
    - `o` $\to$ `o`
    - `o` $\to$ `o`
    - `m` $\to$ `nn`
    - 转换后：`nnoonn`。是回文，输出 **YES**。

5.  **输入：`lalalalai`**
    - 所有字符均无变换映射。
    - 转换后：`lalalalai`。不是回文，输出 **NO**。
