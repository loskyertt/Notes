# 1. 字符串分割

在 C++ 中，处理字符串分割（将一个长字符串按特定规则拆分为多个子串）是一项常见任务。特别是将一句由空格分隔的句子拆分成单词，`std::stringstream` 提供了一种简洁且健壮的实现方式。

## 1.1 代码示例与功能

首先观察一段经典的分割代码：

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <sstream> // 必须包含此头文件

void splitString(const std::string& s) {
    std::stringstream ss(s); // 1. 创建字符串流
    std::string word;
    
    // 2. 循环提取单词
    while (ss >> word) {
        std::cout << "提取到: " << word << std::endl;
    }
}
```

**功能描述**：这段代码能够将输入字符串 `s`（例如 `"dog cat cat dog"`）自动拆分为独立的单词，并输出或存储。它能够自动处理单词之间的空格，无论是一个空格还是多个连续空格。

## 1.2 核心原理详解

为了深入理解这段代码，我们需要剖析 `std::stringstream` 和 `>>` 运算符的工作机制。

### 1.2.1 字符串流的初始化

```cpp
std::stringstream ss(s);
```

这行代码调用了 `std::stringstream` 的构造函数，将字符串 `s` 中的内容“倒入”了一个流对象中。
- **形象理解**：可以将 `stringstream` 想象成一个“传送带”或“漏斗”。原本死板的字符串数据变成了流动的数据流，这使得我们可以像处理标准输入（`cin`）一样处理字符串。

### 1.2.2 流提取运算符 `>>`

```cpp
while (ss >> word)
```

这是分割逻辑的核心。`>>` 运算符在 C++ 中被称为**流提取运算符**，其行为与 `std::cin >> variable` 完全一致。

**工作流程**：
1.  **跳过空白字符**：`>>` 运算符会自动忽略并跳过流开头的所有空格、制表符（`\t`）和换行符（`\n`）。
2.  **读取数据**：从第一个非空白字符开始读取，直到遇到下一个空白字符或流结束。
3.  **存入变量**：将读取到的内容存入右侧的变量 `word` 中。
4.  **返回流状态**：表达式 `ss >> word` 返回流对象 `ss` 自身的引用。在 `while` 循环条件中，流对象会被隐式转换为布尔值：
    - 如果流处于有效状态（读取成功），转换为 `true`。
    - 如果流处于无效状态（例如已读取到末尾），转换为 `false`，循环终止。

### 1.2.3 循环执行过程

假设输入字符串为 `"  dog   cat  dog "`（注意包含多余空格）：

| 循环次数 | 操作前流的状态 | `>>` 操作行为 | `word` 的值 | 循环条件结果 |
| :--- | :--- | :--- | :--- | :--- |
| **第1次** | `"  dog   cat  dog "` | 跳过前导空格，读取 `dog` | `"dog"` | `true` (继续) |
| **第2次** | `"   cat  dog "` | 跳过多余空格，读取 `cat` | `"cat"` | `true` (继续) |
| **第3次** | `"  dog "` | 跳过多余空格，读取 `dog` | `"dog"` | `true` (继续) |
| **第4次** | `""` (空) | 流已到底，无数据可读 | (未改变) | `false` (终止) |

## 1.3 方法对比与适用场景

虽然 `stringstream` 方法非常便捷，但在特定场景下，手动分割方法也有其优势。

### 1.3.1 方法一：`stringstream`（推荐用于单词分割）

**优点**：
- 代码简洁，逻辑清晰。
- 自动处理任意数量的连续空格，鲁棒性强。
- 类似于处理标准输入，符合 C++ 流的习惯。

**缺点**：
- 默认只能以空白字符（空格、制表符、换行）为分隔符。
- 性能相对较低，因为涉及流的构造和析构，不适合极高性能要求的场景。

### 1.3.2 方法二：`find` 与 `substr`（适用于自定义分隔符）

如果需要按逗号、冒号等非空白字符分割，`stringstream` 默认无法直接实现（虽然可以通过定制 locale 实现，但较复杂），此时手动分割更直观。

**示例代码**：按逗号 `,` 分割。

```cpp
#include <string>
#include <vector>

void splitByDelimiter(const std::string& s, char delimiter) {
	std::vector<std::string> tokens;  // ① 存储分割结果的容器
	size_t start = 0;                  // ② 当前子串的起始索引（含）
	size_t end = s.find(delimiter);    // ③ 查找第一个分隔符位置，等价于 s.find(delimiter, 0)
    
	while (end != std::string::npos) {              // ④ 未找到分隔符时 find() 返回 npos
	    tokens.push_back(s.substr(start, end - start));  // ⑤ 提取 [start, end) 区间子串
	    start = end + 1;                              // ⑥ 移动 start 到分隔符后一位
	    end = s.find(delimiter, start);               // ⑦ 从新位置继续查找
	}
    // 处理最后一个分隔符之后的内容
    tokens.push_back(s.substr(start));
}
```

> 对于 ` s.find(delimiter)`，如果未找到 → pos = npos（极大值）。

**说明**：

| 参数 | 类型 | 说明 |
|------|------|------|
| `s` | `const std::string&` | 待分割的源字符串（常量引用，避免拷贝） |
| `delimiter` | `char` | 单字符分隔符（如 `','`、`'/'`、`' '`） |

**适用场景**：
- 分隔符不是空白字符。
- 对性能有较高要求。
