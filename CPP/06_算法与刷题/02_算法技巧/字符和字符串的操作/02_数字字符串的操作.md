# 1. 遍历数字各位并求和

在程序设计中，将一个整数拆解为一个个数字是基础且重要的操作。以 `int a = 1234` 为例，最经典且高效的方法是使用**取模**和**整除**运算。

## 1.1 方法一：数学运算（剥洋葱法）

这是算法竞赛和处理数值逻辑时最常用的方法。我们可以将数字看作一个洋葱，从外层（个位）一层层剥开。

**核心逻辑**：
1.  **取最低位**：通过 `a % 10` 获得当前数字的最后一位。
2.  **去掉最低位**：通过 `a / 10` 去掉当前数字的最后一位。
3.  **重复**：直到数字变为 0 为止。

**代码实现**：

```cpp
#include <iostream>
#include <cmath> // 用于 abs 函数

int main() {
    int a = 1234;
    // 处理负数情况：求各位和通常指绝对值的和
    // 注意：如果不处理，负数取模结果可能因编译器而异，统一转为正数处理更安全
    if (a < 0) a = std::abs(a); 

    int sum = 0; 
    
    while (a > 0) {
        // 1. 取出最后一位
        int digit = a % 10; 
        
        // 2. 累加到总和
        sum += digit;
        
        // 3. 去掉最后一位
        a /= 10; 
    }
    
    std::cout << "各位数字之和为: " << sum << std::endl;
    return 0;
}
```

> [!warning] 关于负数的处理
> 在 C++ 标准中，负数的取模结果由实现定义（通常结果的符号与被除数相同）。例如 `-12 % 10` 可能得到 `-2`。为了避免逻辑错误，在进行数字拆分前，建议统一取绝对值处理。

## 1.2 方法二：字符串遍历

当数字非常大（超过 `long long` 范围）或者不需要进行数学运算时，可以将数字视为字符串处理。

**核心逻辑**：
利用 ASCII 码的特性，字符 `'0'` 到 `'9'` 是连续排列的。将字符减去 `'0'` 即可得到对应的整数值。

**代码实现**：

```cpp
#include <iostream>
#include <string>

int main() {
    int a = 1234;
    // 如果输入本身是大整数，应直接作为 string 读入
    std::string s = std::to_string(a); 
    int sum = 0;
    
    for(char c : s) {
        // 过滤掉负号等非数字字符
        if (c >= '0' && c <= '9') {
            // 字符转数字：'1' - '0' = 1
            sum += (c - '0'); 
        }
    }
    
    std::cout << sum << std::endl;
    return 0;
}
```

**原理补充**：
在 ASCII 表中，`'0'` 的值是 48，`'1'` 是 49，依此类推。
- `'9' - '0'` 等价于 `57 - 48`，结果为整数 `9`。
- 这种转换方式是 C/C++ 处理字符数字的标准范式。

# 2. 数字反转

数字反转是面试和竞赛中的高频考点，例如将 `2001` 变成 `1002`，将 `2010` 变成 `102`（首部的 0 自动省略）。

## 2.1 方法一：数学构造法

这是最符合直觉且效率最高的方法，核心思想是**弹出与推入**。

**核心思路**：
我们不是在原数上修改，而是构建一个新的数字 `rev`。
1. **弹出**：从原数 `x` 的末尾取出一位 `digit`。
2. **推入**：将 `digit` 放到新数 `rev` 的末尾。
	- 操作公式：`rev = rev * 10 + digit`。
    - 原理：每次循环将 `rev` 向左移动一位（乘 10），腾出个位给新来的数字。

**代码实现**：

```cpp
#include <iostream>
#include <climits> // 用于 INT_MAX 等宏

int reverseInteger(int x) {
    int rev = 0;
    
    while (x != 0) {
        int digit = x % 10; // 弹出最后一位
        x /= 10;            // 原数去尾
        
        // 溢出检查（关键步骤，详见下文）
        if (rev > INT_MAX / 10 || (rev == INT_MAX / 10 && digit > 7)) return 0;
        if (rev < INT_MIN / 10 || (rev == INT_MIN / 10 && digit < -8)) return 0;
        
        rev = rev * 10 + digit; // 推入新数
    }
    
    return rev;
}

int main() {
    int a = 2010;
    std::cout << a << " 反转后: " << reverseInteger(a) << std::endl; 
    // 输出 102 (自动处理了末尾的 0)
    return 0;
}
```

### 2.1.1 执行过程演示

以 `2010` 反转为例，观察算法如何自动处理末尾的 0：

| 循环次数 | `x` (原数) | `digit` (弹出位) | `rev` (新数计算) | `rev` 结果 |
| :--- | :--- | :--- | :--- | :--- |
| **初始** | 2010 | - | - | 0 |
| **第1次** | 201 | 0 | `0 * 10 + 0` | 0 |
| **第2次** | 20 | 1 | `0 * 10 + 1` | 1 |
| **第3次** | 2 | 0 | `1 * 10 + 0` | 10 |
| **第4次** | 0 | 2 | `10 * 10 + 2` | 102 |

**结论**：由于整数在内存中不存储前导零，当 `digit` 为 0 时，`rev * 10 + 0` 实际上只是将之前的数值左移了一位，若 `rev` 当前为 0，则结果仍为 0。因此，数学法天然能够处理末尾的 0。

### 2.1.2 溢出风险与处理

整数反转最容易被忽视的问题是**溢出**。
- `int` 类型的范围约为 $-2.1 \times 10^9$ 到 $2.1 \times 10^9$。
- 如果输入 `2147483647`，反转后约为 $7.4 \times 10^9$，这会超出 `int` 范围，导致未定义行为。

**检查策略**：
在执行 `rev = rev * 10 + digit` 之前，必须判断 `rev` 是否会溢出。
- 如果 `rev > INT_MAX / 10`，那么 `rev * 10` 必定溢出。
- 如果 `rev == INT_MAX / 10`，则需检查即将加入的 `digit` 是否超过 `INT_MAX` 的个位数（即 7）。

## 2.2 方法二：字符串反转法

如果不涉及数学运算，或者题目允许使用字符串，这种方法代码量最少。

**代码实现**：

```cpp
#include <iostream>
#include <string>
#include <algorithm>  // 包含 reverse 函数

int main() {
  int a = -1230;
  std::string s = std::to_string(a);

  // 反转字符串
  std::reverse(s.begin(), s.end());

  // 此时 s 变为 "0321-"
  // 需要处理负号位置和前导零

  // 简单处理：转回整数（利用 stoi 的自动去零和报错机制）
  try {
    int result = std::stoi(s);         // stoi 会自动处理前导零
    std::cout << result << std::endl;  // 输出 321 (注意：简单的字符串反转会改变负号位置，逻辑需修正)
  } catch (...) {
    std::cout << "溢出或无效转换" << std::endl;
  }

  return 0;
}
```

> [!note] 字符串法的局限性
> 直接对带负号的整数字符串进行 `reverse` 会导致负号跑到末尾（如 `-123` 变成 `321-`）。使用 `stoi` 会将 `321-` 解析为 `321`（遇到非法字符停止），这可能不符合数学上的反转预期。因此，在处理带符号整数反转时，**数学构造法**逻辑更加严密。

# 3. 大数求模

对于长度很大的字符串表示的数字求模（例如 $10^{1000} \pmod{13}$），由于数字远超 `long long` 的承载范围，我们不能直接转换成整数。核心思想是利用**同余定理**，通过**秦九韶算法**（也叫逐位迭代法）来处理。

## 3.1 数学原理

假设有一个 $n$ 位数 $N = d_1 d_2 \dots d_n$，它可以表示为多项式形式：

$$N = d_1 \times 10^{n-1} + d_2 \times 10^{n-2} + \dots + d_n \times 10^0$$

在计算机处理过程中，我们可以通过循环展开这个多项式，这被称为秦九韶算法。以数字 $1234$ 为例，其展开过程如下：

$$1234 = ((1 \times 10 + 2) \times 10 + 3) \times 10 + 4$$

根据**同余运算**的性质，我们可以得到以下两条核心规则：
1.  **加法同余**：$(a + b) \pmod m = ((a \pmod m) + (b \pmod m)) \pmod m$
2.  **乘法同余**：$(a \times b) \pmod m = ((a \pmod m) \times (b \pmod m)) \pmod m$

这意味着，在计算的每一步乘法和加法之后，都可以立即对 $m$ 取模。这样，中间结果始终保持在 $[0, m-1]$ 的范围内，从而避免了数值溢出。

**推导过程**：
设前 $k-1$ 位数字组成的数为 $A_{k-1}$，当前第 $k$ 位数字为 $d_k$。则前 $k$ 位组成的数 $A_k$ 可表示为：
$$A_k = A_{k-1} \times 10 + d_k$$
对其取模：
$$A_k \pmod m = ((A_{k-1} \pmod m) \times 10 + d_k) \pmod m$$

## 3.2 代码实现

下面是标准的处理函数，适用于非负整数的大数求模。

```cpp
#include <iostream>
#include <string>

/**
 * @brief 计算大数（字符串形式）对模数的余数
 * @param num 字符串形式的大数
 * @param mod 模数
 * @return 余数 (0 <= result < mod)
 */
long long bigNumberMod(const std::string& num, long long mod) {
  long long res = 0;
  for (char c : num) {
    // 核心迭代公式
    // 1. res * 10：左移一位
    // 2. + (c - '0')：加上当前位
    // 3. % mod：即时取模，防止溢出
    res = (res * 10 + (c - '0')) % mod;
  }
  return res;
}

int main() {
  std::string bigNum = "123456789123456789123456789";
  long long m = 10007;

  std::cout << "Result: " << bigNumberMod(bigNum, m) << std::endl;
  return 0;
}
```

## 3.3 处理负数与大模数

### 3.3.1 负数处理

如果输入字符串可能包含负号（如 `"-123"`），需要对代码进行修正。在数学定义中，负数取模的结果通常要求为非负数（即 $a \pmod m \in [0, m-1]$）。

**修正逻辑**：
1. 检测首字符是否为 `'-'`。
2. 若为负数，先计算其绝对值的模，最后通过 `(mod - res) % mod` 将其转换为对应的负数同余类。

```cpp
long long bigNumberModSigned(const std::string& num, long long mod) {
  bool is_negative = false;
  int start_index = 0;
  
  // 判断符号
  if (num[0] == '-') {
    is_negative = true;
    start_index = 1;
  } else if (num[0] == '+') {
    start_index = 1;
  }

  long long res = 0;
  for (int i = start_index; i < num.size(); ++i) {
    res = (res * 10 + (num[i] - '0')) % mod;
  }

  // 如果是负数，结果应满足: x = -res (mod mod)
  // 例如：-5 % 3 = 1。先算出 5 % 3 = 2，再算 (3 - 2) % 3 = 1
  if (is_negative) {
    res = (mod - res) % mod;
  }
  
  return res;
}
```

### 3.3.2 大模数与溢出风险

在上述代码中，中间计算项 `res * 10` 仍然可能溢出。
- **判定条件**：如果 `mod` 的值超过 `long long` 范围的一半（约 $4.5 \times 10^{18}$），则 `res * 10` 可能溢出。
- **解决方案**：
    1.  **常规场景**：算法竞赛或开发中，模数通常在 $10^9$ 级别（如 $10^9+7$），`long long` 完全足够。
    2.  **极端场景**：如果模数确实接近 `LLONG_MAX`，则需要使用 **快速乘法取模**（类似快速幂的思想）来替代 `res * 10`，或者使用 `__int128`（如果编译器支持）。

```cpp
// 使用 __int128 处理超大模数（仅适用于支持该扩展的编译器，如 GCC/Clang）
long long safeMod(__int128 a, __int128 b, __int128 m) {
    return (a * b) % m;
}
// 在主循环中：res = safeMod(res, 10, mod) + (c - '0');
```

## 3.4 扩展：大数幂模

如果题目要求 $a^b \pmod m$，其中指数 $b$ 是一个大数（字符串），此时逐位迭代法不再适用。我们需要利用**欧拉降幂定理**。

根据费马小定理或欧拉定理，当 $a$ 与 $m$ 互质时：
$$a^b \equiv a^{b \pmod {\phi(m)}} \pmod m$$
其中 $\phi(m)$ 是欧拉函数。

**处理步骤**：
1. 计算 $\phi(m)$。
2. 使用秦九韶算法计算指数 $b \pmod {\phi(m)}$，得到缩减后的指数 $exp$。
3. 使用快速幂算法计算 $a^{exp} \pmod m$。
