# 1. 题目

给定两个整数 $X, Y$，你可以任意顺序多次执行以下两种操作之一：

1. 交换：$(X, Y) = (Y, X)$；
2. 变换：$(X, Y) = (X + Y, X - Y)$。

求使 $X = Y$ 成立所需的最少操作次数；如无法实现，输出 $-1$。

- **输入描述**：输入一行，包含两个整数 $X, Y$（$-100 \leq X, Y \leq 100$）。
- **输出描述**：输出一个整数——使 $X = Y$ 所需的最少操作次数；如无法实现，输出 $-1$。

示例1

```
输入：5 8

输出：-1
```

> **说明**：对 $(5, 8)$ 无论如何操作，无法使两者相等，故输出 $-1$。

示例2

```
输入：5 -5
输出：3
```

> **说明**：
> 一种最优操作序列为：
> 1. 变换：$(5, -5) \rightarrow (0, 10)$；
> 2. 交换：$(0, 10) \rightarrow (10, 0)$；
> 3. 变换：$(10, 0) \rightarrow (10, 10)$。
> 共 $3$ 步使得 $X = Y$。

---

# 2. 题解

若 $X$ 和 $Y$ 为任意值，则第一步顺序不用考虑交换：

1. 先作差，得到 $X = X + Y$ 和 $Y = X - Y$ 如果 $Y = 0$ 就相等了（说明 $X = Y$），此时就直接返回，共需 0 步；如果 $X = 0$ 就是参照题目给的 **示例2**，需要 3 步。
2. 若接着作差，得到 $X = 2X$ 和 $Y = 2Y$，等价于 $X$ 和 $Y$，就回到初始情况了。
3. 若交换再作差，得到 $X = 2X$ 和 $Y = -2Y$，等价于 $X$ 和 $-Y$。再对 $X$ 和 $-Y$ 作差得到 $X = X - Y$ 和 $Y = X + Y$，同第一步过后的**交换**。

因此只有当 $X = Y$，或者 $X = 0$。或者 $Y = 0$ 的情况才能够得到相等，否则就是进入了上面的循环。

代码实现：

```cpp
void solve() {
  int x, y;
  std::cin >> x >> y;

  // 这步也是 x-y=0 的情况
  if (x == y) {
    std::cout << 0 << std::endl;
    return;
  }

  if (x == 0) {
    std::cout << 2 << std::endl;
    return;
  }

  if (y == 0) {
    std::cout << 1 << std::endl;
    return;
  }

  // 直接参照示例 2
  if (x + y == 0) {
    std::cout << 3 << std::endl;
    return;
  }

  std::cout << -1 << std::endl;
}
```
