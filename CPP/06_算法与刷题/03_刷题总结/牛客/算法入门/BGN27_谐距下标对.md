# 1. 题目

给定一个长度为 $n$ 的整数数组 $\{a_1, a_2, \dots, a_n\}$。若下标满足 $i < j$ 且 $a_j - a_i = j - i$，则称 $(i, j)$ 为一对谐距下标对。

请计算数组中的谐距下标对数量。

- **输入描述**：
  - 第一行输入整数 $n$（$1 \leq n \leq 10^5$）。
  - 第二行输入 $n$ 个整数 $a_1, a_2, \dots, a_n$（$1 \leq a_i \leq 10^5$）。

- **输出描述**：输出一个整数，表示谐距下标对数量。

示例1

```
输入：6
1 2 3 4 5 6

输出：15
```

---

# 2. 题解

## 2.1 暴力解法及其局限性分析

最直观的思路是使用双重循环枚举所有可能的下标对 $(i, j)$，逐一验证是否满足条件。

### 2.1.1 代码实现

```cpp
#include <iostream>
#include <vector>

void solve() {
    int n;
    std::cin >> n;

    std::vector<int> nums(n);
    for (int i = 0; i < n; ++i) {
        std::cin >> nums[i];
    }

    int count = 0; // 存储结果
    for (int i = 0; i < n; ++i) {
        for (int j = i + 1; j < n; ++j) {
            if (nums[j] - nums[i] == j - i) {
                ++count;
            }
        }
    }

    std::cout << count << "\n";
}

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);
    solve();
    return 0;
}
```

### 2.1.2 存在的问题

上述代码在小规模数据下逻辑正确，但无法通过本题的测试点，主要原因有两点：

1. **时间复杂度过高（TLE）**
    - 双重循环的时间复杂度为 $O(n^2)$。
    - 本题中 $n \le 10^5$，运算次数约为 $(10^5)^2 = 10^{10}$ 次。
    - 一般竞赛环境的 1 秒时限仅能处理约 $10^8$ 次运算，该算法会严重超时。

2. **数据类型溢出**
    - 当 $n=10^5$ 时，最坏情况下（例如数组为升序序列），谐距下标对的数量接近 $\frac{n(n-1)}{2} \approx 5 \times 10^9$。
    - `int` 类型的最大值约为 $2.1 \times 10^9$，无法容纳该结果，会导致溢出错误。必须使用 `long long` 类型。

## 2.2 优化思路：数学变形与哈希表

为了降低时间复杂度，我们需要减少重复计算，利用数学性质将二重循环降维。

### 2.2.1 等式变形

题目要求满足 $a_j - a_i = j - i$。我们可以通过移项对等式进行变形：

$$a_j - j = a_i - i$$

这意味着，只要两个位置的下标与数值的差值相等，它们就能构成一个谐距下标对。

### 2.2.2 算法设计

基于上述变形，问题转化为：**统计数组中每个不同的 $a_k - k$ 值出现的次数**。

1.  定义 $b_k = a_k - k$。
2.  遍历数组，计算每一个位置的 $b_k$。
3.  使用哈希表（如 `std::unordered_map`）记录每个 $b_k$ 值出现的频次。
4.  对于某个特定的差值 $v$，如果它在数组中出现了 $c$ 次，那么这 $c$ 个位置任意选取两个都能满足条件。对应的对数为组合数 $C_c^2 = \frac{c(c-1)}{2}$。

### 2.2.3 复杂度分析

-   **时间复杂度**：遍历数组计算差值为 $O(n)$，遍历哈希表统计结果最坏情况为 $O(n)$。总时间复杂度为 $O(n)$，完全可以满足时限要求。
-   **空间复杂度**：需要哈希表存储频次，空间复杂度为 $O(n)$。

## 2.3 优化后的代码实现

```cpp
#include <iostream>
#include <unordered_map>

void solve() {
    int n;
    if (!(std::cin >> n)) return;

    // 使用哈希表记录 (数值 - 下标) 出现的次数
    std::unordered_map<int, long long> counts;
    
    for (int i = 1; i <= n; ++i) {
        int val;
        std::cin >> val;
        // 计算差值并计数
        // 题目输入下标通常视为 1 起始，代码中 i 也从 1 开始，保持一致
        // 若题目明确 0 起始，则 i 从 0 开始
        counts[val - i]++;
    }

    long long total_pairs = 0;
    for (auto const& [diff, cnt] : counts) {
        if (cnt >= 2) {
            // 计算组合数 C(cnt, 2)
            total_pairs += (cnt * (cnt - 1)) / 2;
        }
    }

    std::cout << total_pairs << "\n";
}

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);
    solve();
    return 0;
}
```

## 2.4 示例验证

以示例输入为例：
数组：`1 2 3 4 5 6`（下标 $i$ 从 1 开始）

| 下标 $i$ | 数值 $a_i$ | 差值 $b_i = a_i - i$ |
| :--- | :--- | :--- |
| 1 | 1 | 0 |
| 2 | 2 | 0 |
| 3 | 3 | 0 |
| 4 | 4 | 0 |
| 5 | 5 | 0 |
| 6 | 6 | 0 |

-   差值 $0$ 出现了 $6$ 次。
-   计算对数：$C_6^2 = \frac{6 \times 5}{2} = 15$。
-   输出结果为 15，与示例一致。

## 2.5 总结

本题的关键在于通过数学变形将看似关联的两个下标 $i$ 和 $j$ 解耦。
1.  **识别瓶颈**：$O(n^2)$ 无法通过 $10^5$ 的数据规模。
2.  **数学转化**：将 $a_j - a_i = j - i$ 转化为 $a_i - i = a_j - j$，将“配对问题”转化为“计数问题”。
3.  **数据类型**：注意结果可能超过 `int` 范围，使用 `long long` 存储答案。
