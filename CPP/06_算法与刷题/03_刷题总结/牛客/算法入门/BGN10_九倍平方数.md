# 1. 题目

给定一个不含前导零的十进制数字串 $n$（长度 $\leq 10^5$）。你可以多次执行以下操作：

- 选择 $n$ 中的某一位数字 $x$（$0 \leq x \leq 9$）；
- 若 $x^2 < 10$，将该位替换为 $x^2$。

若通过若干次（可为 0 次）操作可以使最终数字能被 9 整除，则称数字串 $n$ 为**好数**。判断每个测试用例的数字串 $n$ 是否为好数。

> [!warning] 数据规模说明
> 数字串长度 $\leq 10^5$，因此 $n$ 的数值远超 `long long` 的范围。**必须以字符串形式读入**，不能用 `int` 或 `long long` 存储。

**输入格式**：
- 第一行输入整数 $t$（$1 \leq t \leq 10^4$），表示测试用例数量。
- 随后 $t$ 行，每行一个数字串 $n$，保证所有用例数字串 $n$ 的总长度 $\leq 10^5$。

**输出格式**：对每个用例输出 `YES` 或 `NO`（大写），表示是否存在操作序列使得最终数字能被 9 整除。

**样例**：

```
输入：
9
123
322
333333333333
9997
5472778912773
1234567890
23
33
52254522632

输出：
NO
YES
YES
NO
NO
YES
NO
YES
YES
```

> [!info] 样例说明
> - **第 1 组**（`123`）：所有可能的结果为 `123`、`143`、`129`、`149`，数位和分别为 6、8、12、14，均不被 9 整除，输出 NO。
> - **第 2 组**（`322`）：将第二位 `2` 替换为 $2^2=4$，得到 `342`，$3+4+2=9$，可被 9 整除，输出 YES。
> - **第 3 组**（`333333333333`）：数位和为 36，已能被 9 整除，无需操作，输出 YES。
> - **第 8 组**（`33`）：数位和为 6，对两个 `3` 均执行操作，数位和变为 $9+9=18$，可被 9 整除，输出 YES。

# 2. 题解

## 2.1 数学基础：整除 9 的判定准则

**定理**：一个十进制整数能被 9 整除，当且仅当它的**各数位之和**能被 9 整除。

**证明**：设整数 $N$ 的十进制表示为 $d_k d_{k-1} \cdots d_1 d_0$，则：

$$N = \sum_{i=0}^{k} d_i \times 10^i$$

注意到 $10 \equiv 1 \pmod{9}$，因此 $10^i \equiv 1^i = 1 \pmod{9}$，故：

$$N \equiv \sum_{i=0}^{k} d_i \times 1 = \sum_{i=0}^{k} d_i \pmod{9}$$

即 $N \equiv S \pmod{9}$，其中 $S$ 为各数位之和。$N$ 能被 9 整除当且仅当 $S \equiv 0 \pmod 9$。$\blacksquare$

**推论**：题目中对某一位数字执行操作（将 $x$ 替换为 $x^2$），**本质上是将数位总和 $S$ 增加了 $x^2 - x$**，而不改变其他位。

## 2.2 操作分析：每个数字的可替换性

根据"$x^2 < 10$"的限制，逐一枚举 0–9：

| 数字 $x$ | $x^2$ | 可操作？ | 对数位和的增量 $\Delta$ | 备注 |
| :---: | :---: | :---: | :---: | :--- |
| 0 | 0 | ✓ | $0 - 0 = 0$ | 无意义，操作前后数字不变 |
| 1 | 1 | ✓ | $1 - 1 = 0$ | 无意义，操作前后数字不变 |
| **2** | **4** | **✓** | $4 - 2 =$ **$+2$** | **有效增量之一** |
| **3** | **9** | **✓** | $9 - 3 =$ **$+6$** | **有效增量之一** |
| 4 | 16 | ✗ | — | $16 \geq 10$，不满足条件 |
| 5 | 25 | ✗ | — | $25 \geq 10$，不满足条件 |
| 6 | 36 | ✗ | — | $36 \geq 10$，不满足条件 |
| 7 | 49 | ✗ | — | $49 \geq 10$，不满足条件 |
| 8 | 64 | ✗ | — | $64 \geq 10$，不满足条件 |
| 9 | 81 | ✗ | — | $81 \geq 10$，不满足条件 |

> [!note] 操作的"一次性"
> 将 `2` 替换为 `4` 后，$4^2 = 16 \geq 10$，无法再次操作；将 `3` 替换为 `9` 后，$9^2 = 81 \geq 10$，同样无法再次操作。因此每个 `2` 最多贡献一次 $+2$，每个 `3` 最多贡献一次 $+6$，操作是**一次性的**。

**结论**：我们手中只有两种有效工具——对每个数位上的 `2` 可选择是否贡献 $+2$，对每个数位上的 `3` 可选择是否贡献 $+6$。

## 2.3 问题转化

设数字串的**初始数位总和**为 $S$，其对 9 的余数为 $rem = S \bmod 9$：

- 若 $rem = 0$：已能被 9 整除，直接输出 **YES**。
- 若 $rem \neq 0$：需要通过操作**补足差值**，目标为使**数位总和**对 9 的余数变为 0，即补足 $target = 9 - rem$。

设字符串中 `2` 的个数为 $count_2$，`3` 的个数为 $count_3$。问题转化为：

> 是否存在整数 $i \in [0,\ count_2]$ 和 $j \in [0,\ count_3]$，使得：
> $$(i \times 2 + j \times 6) \bmod 9 = target$$

## 2.4 枚举验证

直接暴力枚举 $i$ 和 $j$ 的所有组合，判断是否有满足条件的方案。

**关键观察：枚举范围可以截断。**

分析 $i \times 2 \pmod{9}$ 和 $j \times 6 \pmod{9}$ 的周期：

- $i \times 2 \pmod 9$ 的序列（$i=0,1,2,\ldots$）：$0,2,4,6,8,1,3,5,7,\mathbf{0},\ldots$，**周期为 9**。即 $i$ 与 $i+9$ 贡献相同的余数。
- $j \times 6 \pmod 9$ 的序列（$j=0,1,2,\ldots$）：$0,6,3,\mathbf{0},6,3,\ldots$，**周期为 3**。即 $j$ 与 $j+3$ 贡献相同的余数。

因此，$i$ 只需枚举 $[0,\ \min(count_2,\ 8)]$ 共最多 9 个值；$j$ 只需枚举 $[0,\ \min(count_3,\ 2)]$ 共最多 3 个值。每个测试用例最多枚举 $9 \times 3 = 27$ 次，是常数级操作。

> [!tip] 代码实现时取 10 作为上界
> 代码中对 $i$ 使用 `min(count_2, 9)`（枚举 $i=0$ 到 $9$，共 10 个值）、对 $j$ 使用 `min(count_3, 9)`（枚举 $j=0$ 到 $9$，共 10 个值），略大于理论下界，但同样正确，且不影响 $O(1)$ 的常数级复杂度。

## 2.5 示例分析

**示例：`123`**

- 初始和：$1+2+3=6$，$rem=6$，$target=3$
- 资源：$count_2=1$，$count_3=1$
- 枚举所有组合（$(i,j)$，$i \leq 1$，$j \leq 1$）：

| $i$ | $j$ | $i\times2 + j\times6$ | 结果 mod 9 |
|:---:|:---:|:---:|:---:|
| 0 | 0 | 0 | 0 |
| 1 | 0 | 2 | 2 |
| 0 | 1 | 6 | 6 |
| 1 | 1 | 8 | 8 |

无法凑出余数 3，输出 **NO**。

---

**示例：`322`**

- 初始和：$3+2+2=7$，$rem=7$，$target=2$
- 资源：$count_2=2$，$count_3=1$
- 取 $i=1,\ j=0$：$1\times2+0\times6=2$，$2 \bmod 9=2=target$ ✓

输出 **YES**。（即将第二个 `2` 替换为 `4`，数位和变为 $3+4+2=9$。）

---

**示例：`33`**

- 初始和：$3+3=6$，$rem=6$，$target=3$
- 资源：$count_2=0$，$count_3=2$
- 取 $i=0,\ j=2$：$0+2\times6=12$，$12 \bmod 9=3=target$ ✓

输出 **YES**。（将两个 `3` 均替换为 `9`，数位和变为 $9+9=18$，$18 \bmod 9=0$。）

## 2.6 代码

```cpp
#include <algorithm>
#include <ios>
#include <iostream>
#include <string>

void solve() {
    std::string s;
    std::cin >> s;

    int sum_digit = 0;
    int count_2 = 0, count_3 = 0;

    for (char c : s) {
        int digit = c - '0';
        sum_digit += digit;
        if (digit == 2) ++count_2;
        else if (digit == 3) ++count_3;
    }

    int rem = sum_digit % 9;
    if (rem == 0) {
        std::cout << "YES\n";
        return;
    }

    int target = 9 - rem;

    // i × 2 mod 9 的周期为 9，j × 6 mod 9 的周期为 3
    // 枚举 [0, min(count_2, 9)] × [0, min(count_3, 9)] 已覆盖所有余数情况
    for (int i = 0; i <= std::min(count_2, 9); ++i) {
        for (int j = 0; j <= std::min(count_3, 9); ++j) {
            if ((i * 2 + j * 6) % 9 == target) {
                std::cout << "YES\n";
                return;
            }
        }
    }

    std::cout << "NO\n";
}

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);

    int t;
    std::cin >> t;
    while (t--) {
        solve();
    }
}
```

## 2.7 复杂度分析

设所有测试用例数字串的**总长度**为 $L$（题目保证 $L \leq 10^5$）。

| 步骤 | 时间复杂度 | 说明 |
| :--- | :--- | :--- |
| 读入并遍历字符串 | $O(L)$（总计）| 每个字符恰好被访问一次 |
| 枚举 $i,j$ 组合 | $O(1)$（每个用例）| 最多枚举 $10 \times 10 = 100$ 次 |
| **总体** | $O(L)$ | 瓶颈在字符串遍历，与用例数 $t$ 无关 |

**空间复杂度**：$O(L)$（字符串存储）。在竞赛中，$L \leq 10^5$ 完全可以接受。
