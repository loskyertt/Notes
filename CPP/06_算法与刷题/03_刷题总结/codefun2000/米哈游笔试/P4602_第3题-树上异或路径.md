# 1. 题目

给你一棵有 $n$ 个节点的无向树。每条边有一个非负整数权值 $w$。

请计算这棵树上所有简单路径的异或和之和。

端点 $u$ 与 $v$ 视为同一路径，仅统计一次，两个端点相同时，路径异或和为 $0$。

若结果可能很大，请将答案对 $1000000007$ 取模后输出。

- **输入描述**：
  - 第一行输入一个整数 $T$，表示测试用例数量。
  - 对于每个测试用例：
    - 第一行输入一个整数 $n$，表示节点数量。
    - 接下来 $n-1$ 行，每行输入三个整数 $u, v, w$，表示节点 $u$ 和 $v$ 之间有一条权值为 $w$ 的边。

- **输出描述**：对于每个测试用例，输出一个整数，表示所有简单路径的异或和之和（对 $1000000007$ 取模）。

示例1

```
输入：
2
3
1 2 1
2 3 2
4
1 2 0
2 3 0
3 4 7

输出：
6
21
```

异或运算（符号为 $\oplus$）在处理路径时，是把路径上**所有边**的权值连着算。
- 如果路径只有一条边，权值为 $w$，那么结果就是 $w$。
- 如果路径有两条边，权值分别为 $w_1, w_2$，那么结果就是 $w_1 \oplus w_2$。
- 如果路径有三条边，结果就是 $w_1 \oplus w_2 \oplus w_3$。

**示例 1：**
树的结构：$1 \xrightarrow{\text{权值 } 1} 2 \xrightarrow{\text{权值 } 2} 3$
- **路径 (1, 2)**：只经过边 $(1, 2)$。计算过程：就是 $1$。
- **路径 (2, 3)**：只经过边 $(2, 3)$。计算过程：就是 $2$。
- **路径 (1, 3)**：经过了边 $(1, 2)$ 和边 $(2, 3)$。计算过程：$1 \oplus 2$。
    - 二进制表示：$1$ 是 `01`， $2$ 是 `10`。
    - `01 XOR 10 = 11`（即十进制的 $3$）。
- **总和**：$1 + 2 + 3 = 6$。

# 2. 题解


## 代码实现

```cpp
#include <iostream>
#include <vector>

using namespace std;

typedef long long ll;
const int MOD = 1000000007;

struct Edge {
    int to;
    int weight;
};

vector<vector<Edge>> adj;
vector<int> dists;

// DFS 计算根到每个点的异或路径和
void dfs(int u, int p, int current_xor) {
    dists[u] = current_xor;
    for (auto& edge : adj[u]) {
        if (edge.to != p) {
            dfs(edge.to, u, current_xor ^ edge.weight);
        }
    }
}

void solve() {
    int n;
    cin >> n;
    adj.assign(n + 1, vector<Edge>());
    dists.assign(n + 1, 0);

    for (int i = 0; i < n - 1; ++i) {
        int u, v, w;
        cin >> u >> v >> w;
        adj[u].push_back({v, w});
        adj[v].push_back({u, w});
    }

    // 1. 预处理所有点到根的异或距离
    dfs(1, 0, 0);

    ll total_sum = 0;

    // 2. 按位处理 (假设权值在 int 范围内，处理 31 位)
    for (int j = 0; j < 31; ++j) {
        ll cnt1 = 0, cnt0 = 0;
        for (int i = 1; i <= n; ++i) {
            if ((dists[i] >> j) & 1) cnt1++;
            else cnt0++;
        }

        // 路径 (u, v) 的异或和在第 j 位为 1，当且仅当 dist[u] 和 dist[v] 在该位不同
        // 贡献 = (不同对的数量) * (这一位的权值)
        ll pairs = (cnt1 * cnt0) % MOD;
        ll bit_val = (1LL << j) % MOD;
        ll contribution = (pairs * bit_val) % MOD;
        
        total_sum = (total_sum + contribution) % MOD;
    }

    cout << total_sum << endl;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--) {
        solve();
    }
    return 0;
}
```
