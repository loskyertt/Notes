# 1. 题目

在一张无限的二维网格上，有若干住户的家位于整数坐标点上（同一坐标可能有多人）。你首先在任意整数坐标点上固定建造一个快递驿站，然后每天从该驿站出发前往原点$(0, 0)$。你总会选择一条从驿站到原点的最短路径。路径由一系列相邻的格点组成，每一步只能向上、下、左、右移动一个单位，路径中包含起点（驿站位置）和终点（原点）。例如：从$(x_0, y_0)$到$(0, 0)$的最短路径长度为$|x_0 - 0| + |y_0 - 0|$的路径都视为最短路径。你可以在所有最短路径中任选其一。

在选定最优驿站位置后，允许在多天内每天任选一条最短路径并在路径途经的住户完成投递。问最多能累计送达多少不同住户？

- **输入描述**：
  - 输入包含多组测试数据。第一行包含整数$T$（$1 \leq T \leq 10^5$）表示测试组数。每组数据描述如下：
    - 第一行输入一个整数$n$（$1 \leq n \leq 2 \times 10^5$）；
    - 接下来$n$行，每行输入两个整数$x_i, y_i$（$-10^9 \leq x_i, y_i \leq 10^9$），表示一位住户的家在$(x_i, y_i)$。
  - 保证所有测试中$n$的总和不超过$2 \times 10^5$。

- **输出描述**：对于每组测试数据，输出一行，仅包含一个整数——在最优驿站位置与任意多次最短路径选择下，最终可送达的不同住户人数。

示例1

```
输入：
3
6
5 5
3 3
2 1
1 0
4 4
-2 5
5
2 2
2 2
2 2
1 1
0 1
5
2 1
1 2
0 0
-3 0
0 -3

输出：
5
5
3
```

这里以**示例 3** 为例：
住户位置：`(2,1), (1,2), (0,0), (-3,0), (0,-3)`
- 如果你选驿站为 $(2,2)$，你能覆盖第一象限的 `(2,1), (1,2), (0,0)`，共 3 人。
- 如果你选驿站为 $(-3,0)$，你能覆盖 `(-3,0), (0,0)`，共 2 人。
- 最高纪录是 3。

# 2. 题解

这道题表面上是一个二维网格路径问题，但通过几何分析，我们可以将其转化为一个经典的**区域覆盖**问题。

## 2.1 题意解析

### 2.1.1 核心规则

1. **驿站选址**：你可以选定任何一个坐标 $(x_0, y_0)$ 作为起点。
2. **终点固定**：终点永远是 $(0, 0)$。
3. **最短路径**：从 $(x_0, y_0)$ 到 $(0, 0)$ 的最短路径长度一定是 $|x_0| + |y_0|$。这意味着你每一步都必须**缩小**与原点在横坐标或纵坐标上的距离。
    - 例如，如果你在 $(3, 3)$，你只能向左或向下走，不能向右或向上走。
4. **覆盖范围**：如果你选定驿站 $(x_0, y_0)$，所有能被送达的住户 $(x_i, y_i)$ 必须满足：
    - $x_i$ 在 $0$ 和 $x_0$ 之间（含边界）。
    - $y_i$ 在 $0$ 和 $y_0$ 之间（含边界）。
    - 并且 $x_i$ 和 $x_0$ 同号（或为0），$y_i$ 和 $y_0$ 同号（或为0）。

**结论**：选定 $(x_0, y_0)$ 后，你能送达所有位于以 $(0,0)$ 和 $(x_0, y_0)$ 为对角顶点的**矩形区域内**的住户。

## 2.2 解题思路：象限分类与坐标离散化

由于驿站只能选在一个点，这个点必然落在某个象限（或坐标轴上）。

1. **分象限处理**：
    我们将住户按坐标的正负号分为四个区域（第一、二、三、四象限）。注意：坐标轴上的点（如 `x=0` 或 `y=0`）比较特殊，它们可以被相邻的两个象限同时考虑。

2. **转化模型**：
    以第一象限为例，所有住户满足 $x_i \ge 0, y_i \ge 0$。我们要找一个 $(x_0, y_0)$，使得满足 $0 \le x_i \le x_0$ 且 $0 \le y_i \le y_0$ 的住户数量最多。

3. **贪心/离散化**：
    - 显然，$x_0$ 和 $y_0$ 只需要取某个住户的坐标值即可。
    - 这本质上是在寻找一个点，其“左下方”包含的邻居最多。
    - 由于坐标范围高达 $10^9$，我们需要对坐标进行**离散化**，或者利用**二维偏序/扫描线**的思想。但其实这道题有一个更简单的视角：

### 2.2.1 核心观察

在选定象限后（以第一象限 $x, y \ge 0$ 为例）：

如果我们选定某个住户 $i$ 作为驿站位置，那么所有满足 $x_j \le x_i$ 且 $y_j \le y_i$ 的住户 $j$ 都会被覆盖。

**这不就是找一个点，统计其矩形区域内的点数吗？**

> [!question] 由于驿站坐标可以无限大，对于第一象限，我们只需要把所有 $x_i \ge 0, y_i \ge 0$ 的住户都圈进来吗？
> **不对！**

**注意题意**：你必须选择一条最短路径。如果你为了圈住 $(5,1)$ 和 $(1,5)$ 而选了 $(5,5)$，这两者确实都在 $(0,0)$ 到 $(5,5)$ 的矩形内，这没问题。

真正的限制是：**驿站只能在一个点**。如果住户 A 在 $(5, 5)$，住户 B 在 $(-2, 5)$。你选驿站为 $(5, 5)$，能送到 A，但送不到 B（因为 B 的 $x$ 是负数，不在 $(0,0)$ 到 $(5,5)$ 的路径上）。所以，我们只需要**分别计算四个象限中住户最多的那个象限**即可。

## 2.3 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <map>

using namespace std;

/**
 * 核心逻辑：
 * 驿站 (x0, y0) 能覆盖的点 (xi, yi) 必须满足：
 * 1. xi 与 x0 同号且 |xi| <= |x0|
 * 2. yi 与 y0 同号且 |yi| <= |y0|
 * * 实际上，我们只需要统计四个象限（含坐标轴）中，
 * 哪一个象限拥有的住户数量最多即可。
 * 因为只要我们把驿站设在那个象限非常远的地方，
 * 那个象限里所有的住户都会落在它到原点的矩形内。
 */

void solve() {
    int n;
    cin >> n;
    
    // 统计四个象限：
    // q1: x>=0, y>=0
    // q2: x<=0, y>=0
    // q3: x<=0, y<=0
    // q4: x>=0, y<=0
    int q1 = 0, q2 = 0, q3 = 0, q4 = 0;

    for (int i = 0; i < n; ++i) {
        long long x, y;
        cin >> x >> y;
        if (x >= 0 && y >= 0) q1++;
        if (x <= 0 && y >= 0) q2++;
        if (x <= 0 && y <= 0) q3++;
        if (x >= 0 && y <= 0) q4++;
    }

    // 取四个象限中的最大值
    int ans = max({q1, q2, q3, q4});
    cout << ans << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--) {
        solve();
    }
    return 0;
}
```
