# 1. 题目

给定四个整数 $n, k, m, r$，其中 $0 \leq r \leq m - 1$ 且 $m \geq 1$。判断是否可以将 $n$ 表示为 $k$ 个两两不同的正整数之和，且每个数都与 $r$ 在模 $m$ 意义下同余。若可行，输出一组构造；否则输出 `NO`。

$$\exists a_1, \ldots, a_k \in \mathbb{Z}_{>0} \text{ s.t. } \sum_{i=1}^{k} a_i = n, \ a_i \equiv r \pmod{m}, \ a_i \text{ 两两不同}$$

- **输入描述**：
  - 每个测试文件均包含多组测试数据。第一行输入一个整数 $t$（$1 \leq t \leq 10^4$）表示测试用例数量。
  - 对每个测试用例，输入一行四个整数：$n, k, m, r$（$0 \leq n \leq 10^{18}$，$1 \leq k \leq 2 \times 10^5$，$1 \leq m \leq 10^9$，$0 \leq r \leq m - 1$）
  - 除此之外，保证单个测试文件的 $k$ 之和不超过 $2 \times 10^5$。

- **输出描述**：对于每个测试用例：
  - 若不存在表示，输出一行 `NO`；
  - 否则输出一行 `YES`，并在下一行输出 $k$ 个两两不同的正整数 $a_1, \ldots, a_k$（顺序任意，需满足同余与求和的约束）。若存在多个合法答案，输出任意一组即可。

示例1

```
输入：
3
15 3 4 1
18 3 5 3
36 3 6 0

输出：
YES
1 5 9
NO
YES
6 12 18
```

> **说明**：
> - 对于第一组数据：$a = \{1, 5, 9\}$，均为正整数，互不相同，且 $a_i \equiv 1 \pmod{4}$，并且 $\sum a_i = 15$。
> - 对于第二组数据：不存在满足条件的表示，输出 `NO`。
> - 对于第三组数据：$a = \{6, 12, 18\}$，均为正整数，互不相同，且 $a_i \equiv 0 \pmod{6}$，并且 $\sum a_i = 36$。

# 2. 题解

这道题是一道关于**等差数列**与**贪心构造**的数学分析题。虽然涉及模运算，但只要理解了“同余”的本质，就能通过简单的代数变形解决。

## 2.1 题意解析

我们要找 $k$ 个**正整数**，满足：

1. **总和**为 $n$。
2. **两两不同**。
3. **同余约束**：每个数除以 $m$ 的余数都是 $r$。
    - 也就是说，这些数都可以写成 $a_i = q_i \cdot m + r$ 的形式，其中 $q_i$ 是非负整数。
    - **特别注意**：由于要求 $a_i$ 是**正整数**，如果 $r=0$，那么 $q_i$ 必须从 $1$ 开始（因为 $0 \cdot m + 0 = 0$ 不是正整数）；如果 $r > 0$，则 $q_i$ 可以从 $0$ 开始。

> [!question] 示例 2 为什么是 `NO`？
> $n=18, k=3, m=5, r=3$
> - 最小的三个满足 $a_i \equiv 3 \pmod 5$ 的正整数是：$3, 8, 13$。
> - 它们的和是 $3 + 8 + 13 = 24$。
> - 因为 $24 > 18$，即使取最小的数，和也已经超过了 $18$，所以无法构造，输出 `NO`。

## 2.2 解题思路

### 2.2.1 第一步：代数变形

设 $a_i = q_i \cdot m + r$。根据题意：

$$\sum_{i=1}^{k} (q_i \cdot m + r) = n$$

$$m \cdot \sum_{i=1}^{k} q_i + k \cdot r = n$$

$$m \cdot \sum_{i=1}^{k} q_i = n - k \cdot r$$

由此得到两个核心判定条件：

1. **整除性**：$(n - k \cdot r)$ 必须能被 $m$ 整除。
2. **最小和约束**：令 $S = \sum q_i = \frac{n - k \cdot r}{m}$。我们需要找到 $k$ 个**两两不同**的非负整数 $q_i$（如果 $r=0$ 则需 $q_i \ge 1$），使得它们的和等于 $S$。

### 2.2.2 第二步：确定 $q_i$ 的最小值

- **情况 A ($r > 0$)**：$q_i \in \{0, 1, 2, \ldots\}$。
    为了让总和尽可能小，$q_i$ 最小应取 $0, 1, 2, \ldots, k-1$。
    它们的最小和 $S_{min} = \frac{(k-1)k}{2}$。

- **情况 B ($r = 0$)**：$q_i \in \{1, 2, 3, \ldots\}$。
    为了让总和尽可能小，$q_i$ 最小应取 $1, 2, 3, \ldots, k$。
    它们的最小和 $S_{min} = \frac{k(k+1)}{2}$。

**判定**：如果 $S < S_{min}$，输出 `NO`。

### 2.2.3 第三步：贪心构造

如果满足 $S \ge S_{min}$，我们可以先取最小的 $k$ 个 $q_i$：

1. 计算剩余的量 $diff = S - S_{min}$。
2. 为了保持 $k$ 个数两两不同，我们将这个 $diff$ 全部加到最大的那个 $q_i$ 上。
    - 例如 $r>0, k=3, S=6$：初始 $q = \{0, 1, 2\}$，$S_{min}=3$，$diff=3$。
    - 最终 $q = \{0, 1, 2+3\} = \{0, 1, 5\}$。
    - 对应的 $a = \{0\cdot m+r, 1\cdot m+r, 5\cdot m+r\}$。

## 2.3 代码实现

```cpp
#include <iostream>
#include <vector>

using namespace std;

typedef long long ll;

/**
 * 题目：构造 k 个互不相同且模 m 同余 r 的正整数，和为 n
 * 核心：
 * a_i = q_i * m + r
 * sum(a_i) = m * sum(q_i) + k * r = n
 * sum(q_i) = (n - k * r) / m
 */

void solve() {
    ll n, k, m, r;
    cin >> n >> k >> m >> r;

    // 1. 检查基础整除条件
    // 注意 n - k*r 可能会溢出或者为负数
    if (n < k * r) {
        cout << "NO" << endl;
        return;
    }

    ll remaining = n - k * r;
    if (remaining % m != 0) {
        cout << "NO" << endl;
        return;
    }

    ll S = remaining / m;

    // 2. 确定 q_i 的最小取值范围
    // 如果 r == 0，a_i 必须是正整数，则 q_i >= 1
    // 如果 r > 0，a_i = q_i*m + r >= 1，则 q_i >= 0
    ll min_q_sum = 0;
    if (r == 0) {
        // q_i 取 1, 2, ..., k
        // 使用 __int128 防止 k*(k+1)/2 溢出 (k=2e5, k^2=4e10, long long 够用，但 S 最大 1e18)
        if (k > 2000000000LL) { // 冗余检查
            cout << "NO" << endl;
            return;
        }
        min_q_sum = k * (k + 1) / 2;
    } else {
        // q_i 取 0, 1, ..., k-1
        min_q_sum = k * (k - 1) / 2;
    }

    if (S < min_q_sum) {
        cout << "NO" << endl;
        return;
    }

    // 3. 构造结果
    cout << "YES" << endl;
    ll diff = S - min_q_sum;
    for (int i = 1; i <= k; ++i) {
        ll qi = (r == 0) ? i : i - 1;
        // 把所有的差值加到最后一个数上，保证两两不同
        if (i == k) {
            qi += diff;
        }
        cout << qi * m + r << (i == k ? "" : " ");
    }
    cout << endl;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--) {
        solve();
    }
    return 0;
}
```

## 2.4 复杂度与注意事项

- **时间复杂度**：$O(\sum k)$。对于每个测试用例，我们只遍历一次 $k$。题目保证 $\sum k \le 2 \times 10^5$，因此可以通过。
- **空间复杂度**：$O(1)$ 或 $O(k)$ 取决于你是否存储结果，本代码直接输出，空间为 $O(1)$。
- **数据溢出**：
    - $n$ 最大为 $10^{18}$，必须使用 `long long`。
    - $k \cdot r$ 可能会超过 $10^{18}$，计算时需小心。
    - `k * (k + 1) / 2` 在 $k=2 \times 10^5$ 时约为 $2 \times 10^{10}$，在 `long long` 范围内安全。

通过这种“先取最小值，再把余量塞给最大值”的策略，我们总能构造出一组满足“两两不同”且“和为 $n$”的解。
