# 1. 核心概念

函数指针保存的是函数入口地址。它的类型由**返回类型**和**参数列表**共同决定。

```cpp
void (*callback)(int);
int (*binary_op)(int, int);
```

函数指针常用于回调：调用方把一段行为交给框架或库，由框架在合适时机调用。

```text
普通调用:
调用方 ----------> 被调用函数

回调:
调用方 ----------> 框架/库
调用方 <---------- 框架/库在特定时机调用回调
```

> [!summary]
> 回调的本质是**控制反转**：流程由框架掌握，变化点由调用方注入。

# 2. 基本语法

## 2.1 声明

```cpp
void (*func_ptr)(int);
int (*calc_ptr)(int, int);
bool (*pred_ptr)(const char*);
```

括号不可省略：

```cpp
void (*p)(int); // p 是函数指针
void* f(int);   // f 是一个返回 void* 的函数
```

## 2.2 赋值与调用

```cpp
#include <iostream>

void print_value(int x)
{
    std::cout << x << '\n';
}

int main()
{
    void (*p)(int) = print_value;
    p(42);

    if (p != nullptr) {
        (*p)(7);
    }
}
```

函数名在此处可隐式转换为函数地址，`print_value` 和 `&print_value` 都可以赋给匹配的函数指针。

## 2.3 类型别名

原始函数指针语法可读性较差，建议用 `using` 定义别名。

```cpp
using Callback = void(*)(int);

void for_each_value(const std::vector<int>& values, Callback cb)
{
    for (int value : values) {
        cb(value);
    }
}
```

# 3. 函数指针数组

函数指针数组适合根据索引、枚举或状态分派到不同函数。

```cpp
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }
int mul(int a, int b) { return a * b; }

using BinaryOp = int(*)(int, int);

BinaryOp ops[] = {add, sub, mul};

int result = ops[0](10, 3);
```

工程上要注意边界检查：

```cpp
std::size_t index = /* external input */;
if (index < std::size(ops)) {
    result = ops[index](10, 3);
}
```

# 4. 成员函数指针

非静态成员函数隐含 `this` 指针，因此不能赋给普通函数指针。

```cpp
class Calculator
{
public:
    int add(int a, int b) { return a + b; }
    static int mul(int a, int b) { return a * b; }
};

int (Calculator::*member_ptr)(int, int) = &Calculator::add;
int (*static_ptr)(int, int) = &Calculator::mul;
```

调用成员函数指针必须绑定对象：

```cpp
Calculator calc;
int a = (calc.*member_ptr)(1, 2);

Calculator* p = &calc;
int b = (p->*member_ptr)(1, 2);
```

| 类型 | 是否需要对象 | 指针类型 |
|---|---:|---|
| 普通函数 | 否 | `R (*)(Args...)` |
| 静态成员函数 | 否 | `R (*)(Args...)` |
| 非静态成员函数 | 是 | `R (C::*)(Args...)` |

# 5. 回调函数

## 5.1 基础示例

```cpp
#include <iostream>

void on_task_done(int result)
{
    std::cout << "result = " << result << '\n';
}

void do_task(void (*callback)(int))
{
    int result = 42;
    callback(result);
}

int main()
{
    do_task(on_task_done);
}
```

`do_task` 不关心具体业务逻辑，只要求回调签名匹配。

## 5.2 C 接口中的回调

C 语言没有 Lambda、模板和 `std::function`，因此常通过函数指针加 `void* user_data` 传递上下文。

```cpp
using Callback = void(*)(void*);

void register_callback(Callback cb, void* user_data);
```

这种接口在 `pthread`、`qsort`、GUI 框架和底层库中很常见。

# 6. 现代 C++ 替代方案

## 6.1 Lambda

Lambda 适合定义局部一次性逻辑。

```cpp
std::vector<int> values{1, 2, 3, 4};
int threshold = 2;

auto count = std::count_if(values.begin(), values.end(),
    [threshold](int value) {
        return value > threshold;
    });
```

捕获列表决定 Lambda 是否携带状态：

| 捕获写法 | 含义 |
|---|---|
| `[]` | 不捕获 |
| `[x]` | 按值捕获 `x` |
| `[&x]` | 按引用捕获 `x` |
| `[=]` | 默认按值捕获 |
| `[&]` | 默认按引用捕获 |

不捕获变量的 Lambda 可以转换为匹配的函数指针；带捕获的 Lambda 不能转换为普通函数指针。

## 6.2 `std::function`

`std::function` 是类型擦除包装器，可以存储多种可调用对象。

```cpp
#include <functional>

void do_task(std::function<void(int)> callback)
{
    callback(42);
}
```

优点是灵活，缺点是可能有类型擦除开销和堆分配。在热路径中不应无脑使用。

## 6.3 模板

模板接收可调用对象时，编译器能看到具体类型，通常更容易内联。

```cpp
template <typename F>
void for_each_value(const std::vector<int>& values, F&& func)
{
    for (int value : values) {
        func(value);
    }
}
```

C++20 可用概念约束：

```cpp
template <std::invocable<int> F>
void for_each_value(const std::vector<int>& values, F&& func)
{
    for (int value : values) {
        func(value);
    }
}
```

# 7. 选型建议

| 方案 | 能否捕获状态 | 运行时开销 | 典型场景 |
|---|---:|---:|---|
| 原始函数指针 | 否 | 极低 | C 接口、无状态回调 |
| Lambda | 是 | 通常极低 | 局部逻辑、标准库算法 |
| `std::function` | 是 | 中等 | 需要存储统一回调类型 |
| 模板 | 是 | 低 | 高性能通用算法 |
| 成员函数指针 | 依赖对象 | 低 | 需要显式绑定类成员 |

选择顺序：

1. 对接 C API：使用原始函数指针。
2. 临时传入逻辑：优先 Lambda。
3. 需要把回调存成成员变量：考虑 `std::function`。
4. 写性能敏感的泛型库：使用模板或概念约束。

---

# 8. 易错点

1. **省略函数指针声明括号**：`void *f(int)` 不是函数指针。
2. **把成员函数指针当普通函数指针**：非静态成员函数需要对象和 `this`。
3. **带捕获 Lambda 传给 C 回调**：普通 C 函数指针无法保存捕获状态。
4. **忽略回调生命周期**：按引用捕获局部变量后异步调用，可能悬空。
5. **热路径滥用 `std::function`**：可能引入额外间接调用和分配。

---

# 9. 总结

> [!summary]
> 函数指针是 C/C++ 中最基础的行为抽象；现代 C++ 通常用 Lambda、模板和 `std::function` 提升表达力，但理解函数指针仍是理解回调、C 接口和底层分派机制的基础。
