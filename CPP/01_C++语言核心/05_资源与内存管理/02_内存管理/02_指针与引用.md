# 1. 基本概念

## 1.1 指针

指针 `T*` 是一个变量，它保存另一块内存的地址。若该地址上存在一个 `T` 类型对象，就可以通过解引用访问该对象。

```cpp
int x = 42;
int* p = &x;

*p = 7; // 修改 p 指向的对象，x 变为 7
```

```text
变量:          内容:
+-----+        +------+
|  x  |        |  42  |
+-----+        +------+
  ^
  |
 p 保存 x 的地址
```

两个基础操作符：

| 操作符 | 名称 | 含义 |
|---|---|---|
| `&obj` | 取地址 | 得到对象地址，类型为 `T*` |
| `*p` | 解引用 | 访问指针指向的对象，结果是一个左值 |

## 1.2 引用

引用 `T&` 是已有对象的别名。引用必须初始化，初始化后不能重新绑定到另一个对象。

```cpp
int x = 1;
int& r = x;

r = 2; // 修改的是 x
```

声明引用时的 `&` 和表达式中的取地址符 `&` 语义不同：

```cpp
int& r = x;  // & 是引用声明的一部分
int* p = &x; // & 是取地址操作符
```

> [!summary]
> 指针表达“可能指向某对象的地址”；引用表达“某对象的别名”。

# 2. 指针与引用的区别

| 维度 | 指针 `T*` | 引用 `T&` |
|---|---|---|
| 是否可为空 | 可以为 `nullptr` | 语义上不应为空 |
| 是否可改指向 | 可以 | 不可以重新绑定 |
| 是否需要解引用 | 访问对象时需要 `*` 或 `->` | 像对象本身一样使用 |
| 是否支持算术 | 数组场景可做指针算术 | 不支持 |
| 典型语义 | 可选对象、动态对象、数组遍历 | 必须存在的对象别名 |

选择建议：

- 参数必定存在且函数不接管所有权时，优先使用 `T&` 或 `const T&`。
- 参数可以为空时，使用 `T*` 或智能指针。
- 需要表达所有权时，使用 `std::unique_ptr`、`std::shared_ptr` 或容器。

# 3. 存储期与所有权

## 3.1 对象活多久

| 存储期 | 示例 | 生命周期 |
|---|---|---|
| 自动存储期 | 局部变量 | 进入作用域创建，离开作用域销毁 |
| 静态存储期 | 全局变量、`static` | 程序期间长期存在 |
| 动态存储期 | `new T` | 从分配开始，到 `delete` 或资源管理器释放为止 |

```cpp
TreeNode* root = new TreeNode(2);
delete root;
root = nullptr;
```

`delete root` 释放的是 `root` 指向的对象，不是删除 `root` 这个指针变量。`root` 本身依然存在，因此释放后应避免继续解引用。

## 3.2 所有权不是指针类型自动表达的

原始指针只是一种地址值，不能单独说明“谁负责释放”。

```cpp
void observe(TreeNode* p);              // 可能只是观察，不拥有
std::unique_ptr<TreeNode> make_node();  // 明确返回独占所有权
```

现代 C++ 中，原始指针适合表达**非拥有关系**；拥有关系应尽量交给 RAII 类型表达。

# 4. 常见指针错误

| 错误 | 示例 | 后果 |
|---|---|---|
| 未初始化指针 | `int* p; *p = 1;` | 未定义行为 |
| 空指针解引用 | `int* p = nullptr; *p = 1;` | 未定义行为 |
| 悬空指针 | `delete p; *p = 1;` | 未定义行为 |
| 双重释放 | `delete p; delete p;` | 未定义行为 |
| 释放方式不匹配 | `new[]` 配 `delete` | 未定义行为 |
| 多态删除无虚析构 | `delete base_ptr;` | 派生类资源可能泄漏 |

> [!warning]
> C++ 中“程序能跑一次”不代表行为正确。未定义行为可能表现为正常输出、垃圾值、崩溃或被优化器改写成完全意外的结果。

# 5. 指针传参

## 5.1 传指针值

```cpp
void reset_local(int* p)
{
    delete p;
    p = nullptr;
}
```

这里的 `p` 是调用方指针变量的一份拷贝。`delete p` 会释放对象，但 `p = nullptr` 只修改函数内部的副本，调用方的指针仍然保存旧地址。

```text
调用前:
caller_ptr ----+
               v
local p ------> heap object

delete 后:
caller_ptr ----X  已释放对象
local p = nullptr
```

调用方指针变成悬空指针。

## 5.2 传指针引用

```cpp
void reset_owner(int*& p)
{
    delete p;
    p = nullptr;
}
```

`int*&` 表示“指针变量本身的引用”。函数内部修改 `p` 的指向，调用方指针同步改变。

```cpp
int* ptr = new int(10);
reset_owner(ptr);
// ptr == nullptr
```

这适合在老式接口中修正调用方指针状态，但现代 C++ 更推荐直接使用 `std::unique_ptr`：

```cpp
std::unique_ptr<int> p = std::make_unique<int>(10);
p.reset();
```

# 6. `const` 与指针组合

`const` 修饰指针时，要看它约束的是“指针指向的对象”还是“指针变量本身”。

| 写法 | 指向对象可改 | 指针可改指向 | 含义 |
|---|---:|---:|---|
| `const int* p` | 否 | 是 | 指向常量的指针 |
| `int* const p` | 是 | 否 | 常量指针 |
| `const int* const p` | 否 | 否 | 指向常量的常量指针 |

```cpp
int a = 1;
int b = 2;

const int* p1 = &a;
p1 = &b;     // OK
// *p1 = 3;  // 错误

int* const p2 = &a;
*p2 = 3;     // OK
// p2 = &b;  // 错误
```

> [!tip]
> 从右向左读通常更容易：`int* const p` 表示 `p` 是 const，类型是 `int*`。

# 7. 指针与数组

## 7.1 数组到指针的退化

数组名在大多数表达式中会退化为指向首元素的指针。

```cpp
int arr[3] = {1, 2, 3};
int* p = arr;      // 等价于 &arr[0]
*(p + 1) = 42;     // 修改 arr[1]
```

但 `sizeof(arr)` 不会退化，它得到整个数组的字节数；`sizeof(p)` 得到指针变量大小。

```cpp
sizeof(arr); // 3 * sizeof(int)
sizeof(p);   // 指针大小，常见为 4 或 8
```

## 7.2 指针失效

标准库容器扩容、删除或移动元素时，可能使旧指针和引用失效。

```cpp
std::vector<int> v{1, 2, 3};
int* p = &v[0];

v.push_back(4); // 可能触发扩容
// p 可能已经失效
```

# 8. `void*`

## 8.1 基本语义

`void*` 是无类型指针，可以保存任意对象地址，但不能直接解引用。

```cpp
int x = 42;
void* p = &x;

// *p = 1;                 // 错误：不知道对象类型
*static_cast<int*>(p) = 1; // 先转回正确类型
```

## 8.2 使用场景

`void*` 常见于 C 接口和底层边界：

- `malloc` 返回原始内存地址。
- `memcpy`、`memset` 操作原始字节序列。
- C 风格回调用 `void* user_data` 传递上下文。
- 跨语言接口用 `void*` 表示不透明句柄。

```cpp
using Callback = void(*)(void*);

void register_callback(Callback cb, void* user_data);
```

## 8.3 C++ 替代方案

| 场景 | 推荐替代 |
|---|---|
| 泛型算法 | 模板 |
| 多种固定类型 | `std::variant` |
| 任意值容器 | `std::any` |
| 多态对象 | 基类指针 + 虚函数 |
| 回调携带上下文 | Lambda / `std::function` |

> [!warning]
> `void*` 丢失类型信息，也不会自动触发析构逻辑。在 C++ 业务代码中应尽量避免把它作为通用容器使用。

# 9. `std::uintptr_t`

## 9.1 定义

`std::uintptr_t` 是定义在 `<cstdint>` 中的无符号整数类型，用于保存指针的数值表示。

```cpp
#include <cstdint>

int x = 42;
int* p = &x;

std::uintptr_t addr = reinterpret_cast<std::uintptr_t>(p);
int* restored = reinterpret_cast<int*>(addr);
```

它主要解决跨平台指针宽度问题：32 位平台指针通常是 32 位，64 位平台指针通常是 64 位，不能用 `unsigned int` 或 `unsigned long` 硬编码承接。

## 9.2 典型用途

`std::uintptr_t` 常用于底层地址计算：

```cpp
void* ptr = /* raw address */;

std::uintptr_t addr = reinterpret_cast<std::uintptr_t>(ptr);
std::uintptr_t aligned = (addr + 15) & ~std::uintptr_t(15);
void* aligned_ptr = reinterpret_cast<void*>(aligned);
```

常见场景：

- 内存对齐计算。
- 自定义分配器和内存池。
- 指针哈希或地址调试输出。
- 极少数需要地址位运算的数据结构。

## 9.3 限制

> [!warning]
> `std::uintptr_t` 是可选类型，虽然主流平台普遍提供，但标准并不要求所有实现必须提供。

使用时还要注意：

1. 指针转整数再转回指针，只应还原为兼容的原指针类型。
2. 整数运算可能破坏地址有效性，不能随意制造指针。
3. `std::size_t` 表示对象大小，不保证一定能承接任意指针值。

---

# 10. 总结

| 概念 | 一句话 |
|---|---|
| 指针 | 保存地址的变量，可为空、可改指向 |
| 引用 | 已有对象的别名，初始化后不可重绑定 |
| 指针引用 | 调用方指针变量本身的别名 |
| `void*` | 丢失类型信息的通用地址 |
| `std::uintptr_t` | 用整数形式承接指针数值，服务于底层地址运算 |

> [!summary]
> 指针相关错误大多来自三种混淆：**地址与对象混淆、生命周期与作用域混淆、观察关系与所有权混淆**。
