> 在 C++ 中，运算符重载（Operator Overloading）是一种强大的特性，它允许你为自定义的类定义运算符（如 `+`, `-`, `*`, `<<` 等）的行为。这能让你的对象像内置类型一样自然地参与运算。

---

# 1. 运算符重载的基本规则

在动手写代码之前，有几条基本原则需要遵守：

- **不能创建新运算符：** 你只能重载 C++ 中已有的运算符（比如你不能发明一个 `**` 表示幂运算）。
    
- **不可重载的运算符：** 只有少数几个运算符不能重载：
    - `.` (成员访问运算符)
    - `.*` (成员指针访问运算符)
    - `::` (作用域解析运算符)
    - `?:` (条件运算符)
    - `sizeof`, `typeid`
    
- **优先级和结合性不变：** 重载后的运算符保持其 **原有的优先级和结合性**。
    
- **至少有一个自定义类型：** 你不能重载两个 `int` 之间的 `+` 法。重载函数的参数中必须至少有一个是类对象或其引用。
    
- **不建议改变语义：** 技术上你可以让 `+` 执行减法逻辑，但为了代码可读性，请务必保持运算符的直觉含义。

# 2. 使用示例

重载运算符有两种主要的实现方式：

1. **成员函数形式：** 运算符 **左侧** 的操作数必须是该类的对象（通常用于 `+=`, `[]`, `()`）。
    
2. **非成员函数（友元函数）形式：** 通常用于双目运算符（如 `+`, `-`）或需要左操作数不是类对象的情况（如 `<<`）。

## 2.1 示例一：字符串类（String）

> 这里通过一个字符串类的例子，展示如何重载 `[]` 和 `<<` 运算符。

```cpp
#include <cstring>
#include <iostream>
#include <ostream>

class String {
 private:
  char *m_buffer;
  unsigned int m_size;

 public:
  String(const char *string) {
    m_size = strlen(string);
    m_buffer = new char[m_size + 1];
    memcpy(m_buffer, string, m_size + 1);
  }

  ~String() {
    if (!m_buffer) {
      return;
    }

    delete[] m_buffer;
    m_buffer = nullptr;
  }

  // 1. 成员函数重载 []
  char &operator[](unsigned int index) { return m_buffer[index]; }

  // 为了让 << 访问私有成员，将其声明为友元
  friend std::ostream &operator<<(std::ostream &stream, const String &string);
};

// 2. 非成员函数重载 << (流插入运算符)
// 必须是非成员函数，因为左操作数是 std::ostream 而不是 String
std::ostream &operator<<(std::ostream &stream, const String &string) {
  stream << string.m_buffer;
  return stream;
}

int main() {
  String str = "loskyertt";
  str[2] = 'a';
  std::cout << str << std::endl;
}
```

这里的运算符是 `[]`（下标运算符）。
- **它的左操作数是：** `str1`（这是一个 `String` 类的对象）。
- **它的右操作数是：** `1`（这是一个索引值）。

在 C++ 中，判断运算符“左侧”操作数，是看**运算符作用在谁身上**。在代码中：

```cpp
str1[1] = 'a';
```

当你调用 `str1[1]` 时，编译器实际上将其转化为：`str1.operator[](1)`。

## 2.2 示例二：复数类 (Complex)

> 这里再通过一个复数类的例子，展示如何重载 `+` 和 `<<` 运算符。

我们希望实现两个复数相加：

```cpp
#include <iostream>

class Complex {
private:
    double real;
    double imag;

public:
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}

    // 1. 成员函数重载 +
    // 这里的 operator+ 只需要一个参数，因为左操作数是 this 指针
    Complex operator+(const Complex& other) const {
        return Complex(this->real + other.real, this->imag + other.imag);
    }

    // 为了让 << 访问私有成员，将其声明为友元
    friend std::ostream& operator<<(std::ostream& os, const Complex& c);
};

// 2. 非成员函数重载 << (流插入运算符)
// 必须是非成员函数，因为左操作数是 std::ostream 而不是 Complex
std::ostream& operator<<(std::ostream& os, const Complex& c) {
    os << c.real << " + " << c.imag << "i";
    return os; // 返回引用支持链式调用：cout << c1 << c2;
}

int main() {
    Complex c1(1.2, 2.5);
    Complex c2(0.8, 1.5);

    Complex c3 = c1 + c2; // 相当于 c1.operator+(c2)

    std::cout << "c1: " << c1 << std::endl;
    std::cout << "c2: " << c2 << std::endl;
    std::cout << "c3 (c1+c2): " << c3 << std::endl;

    return 0;
}
```

## 2.3 自增运算符

区分前置 `++obj` 和后置 `obj++` 是初学者常考的知识点：

```cpp
// 前置 ++：返回引用，效率更高
Complex& operator++() {
    real++;
    return *this;
}

// 后置 ++：参数里多一个 int 占位，返回副本
Complex operator++(int) {
    Complex temp = *this; // 记录原状态
    real++;               // 执行增加
    return temp;          // 返回增加前的状态
}
```

# 3. 常见运算符重载对比表

|**运算符类型**|**推荐实现方式**|**备注**|
|---|---|---|
|**赋值 `=`**|只能是成员函数|必须处理自我赋值，通常返回 `*this` 的引用。|
|**算术 `+`, `-`, `*`**|建议非成员函数|允许左右操作数进行隐式类型转换。|
|**复合赋值 `+=`, `-=`**|成员函数|改变了左操作数的状态。|
|**流 `<<`, `>>`**|必须是非成员函数|因为左操作数是 `ostream` 或 `istream`。|
|**下标 `[]`**|成员函数|通常需要提供 `const` 和非 `const` 两个版本。|
|**自增/自减 `++`, `--`**|成员函数|后置版本（`obj++`）需要一个额外的 `int` 占位参数。|

# 4. 返回值类型

> **返回值：什么时候用引用（&），什么时候返回值？**
> 准则只有一个：看运算后那个“结果”在函数结束后是否还存在。

## 4.1 返回引用 `T&` 的情况

当你希望重载运算符的结果能作为 **左值**（即可以被放在等号左边赋值），或者为了 **连续操作** 时，使用引用。

- **下标运算符 `[]`：**
    
    如 **示例一** 代码所示，你需要通过 `str1[1] = 'a'` 修改对象内部的值。如果返回的是值（副本），你修改的只是一个临时变量，原对象内容不会变。所以**必须返回引用**。
    
- **赋值运算符 `=` 和 复合赋值 `+=`：**
    
    为了支持 `a = b = c` 这样的连续赋值，通常返回 `*this` 的引用。
    
- **流运算符 `<<`：**
    
    为了支持 `cout << a << b`，必须返回 `ostream&`。

## 4.2 返回值 `T` 的情况

当运算产生了一个**新的对象**，且这个对象是函数内部定义的局部变量时，必须返回值。

- **算术运算符 `+`, `-`, `*`, `/`：**
    
    例如 `c = a + b`。`a + b` 的结果既不是 `a` 也不是 `b`，而是一个全新的临时中间值。这个中间值在函数执行完后就会被销毁，如果你返回它的引用，程序会崩溃（访问野指针）。
    
    ```cpp
    Complex operator+(const Complex& other) {
        Complex temp(this->real + other.real, ...);
        return temp; // 必须返回拷贝，不能返回 &temp
    }
    ```
