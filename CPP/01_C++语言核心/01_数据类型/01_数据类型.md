# 1. C++ 数据类型体系概述

C++ 的数据类型系统是一个多层次的架构，旨在平衡**效率**、**可移植性**与**抽象能力**。理解这一体系需要从**基本整数**、**固定宽度整数**、**浮点数**以及**特殊用途类型**四个维度入手。

## 1.1 核心分类速览

| 分类 | 典型类型 | 位数（典型） | 是否平台相关 | 推荐场景 |
|------|----------|-------------|-------------|----------|
| **基本整数** | `short`/`int`/`long`/`long long` | 16/32/32~64/64 | ✅ 是 | 通用计数、不敏感精度的场景 |
| **固定宽度整数** | `int32_t`/`uint64_t` 等 | **精确** 8/16/32/64 | ❌ 否 | 需要精确位数/跨平台二进制兼容 |
| **指针相关** | `intptr_t`/`uintptr_t`/`size_t` | 与指针同宽（32/64） | ✅ 是 | 指针运算、内存大小、数组索引 |
| **浮点类型** | `float`/`double`/`long double` | 32/64/80~128 | ⚠️ 部分 | 科学计算、图形、物理模拟 |
| **字符/布尔** | `char`/`char16_t`/`bool` | 8/16/8 | ❌ 否 | 文本处理、逻辑判断 |

# 2. 基本整数类型

基本整数类型是 C++ 语言内置的基础，其位数由编译器根据目标平台决定，遵循“最小位数保证”原则。

## 2.1 类型属性与规则

标准规定：
1. `sizeof(short) ≤ sizeof(int) ≤ sizeof(long) ≤ sizeof(long long)`
2. 每种类型采用**二进制补码**表示负数。
3. 无符号类型范围为 `[0, 2ᴺ-1]`，有符号为 `[-2ᴺ⁻¹, 2ᴺ⁻¹-1]`。

**类型对照表：**

| 类型 | 最小位数（标准保证） | 典型位数（x86-64） | 有符号范围（典型） |
|------|-------------------|------------------|-------------------|
| `short` | 16 bits | 16 | -32,768 ~ +32,767 |
| `int` | 16 bits | **32** | -2,147,483,648 ~ +2,147,483,647 |
| `long` | 32 bits | **32** (Win) / **64** (Linux) | 随平台变化 |
| `long long` | 64 bits | 64 | -9.2×10¹⁸ ~ +9.2×10¹⁸ |

> ⚠️ **注意**：`long` 的跨度最大。在 Windows (LLP64 模型) 中为 4 字节，在 Linux/macOS (LP64 模型) 中为 8 字节。跨平台代码应避免依赖 `long` 的固定位数。

## 2.2 现代范围查询方法

推荐使用 `<limits>` 头文件中的模板类查询属性，避免使用宏魔法数字。

```cpp
#include <limits>
#include <iostream>

void print_type_info() {
    // 查询 int 的最小值和最大值
    std::cout << "int range: [" 
              << std::numeric_limits<int>::min() << ", "
              << std::numeric_limits<int>::max() << "]\n";
    
    // 查询类型位数
    std::cout << "int bits: " 
              << sizeof(int) * 8 << "\n";
}
```

# 3. 固定宽度整数类型 (C++11)

为了解决跨平台开发中数据大小不一致的问题，C++11 引入了 `<cstdint>` 头文件。

## 3.1 精确宽度类型

**核心价值**：位数**精确固定**，与平台无关，适合二进制协议、文件格式、加密算法等场景。

| 类型 | 位数 | 有符号范围 | 说明 |
|------|------|-----------|------|
| `std::int8_t` / `std::uint8_t` | 8 | -128 ~ +127 / 0 ~ 255 | ⚠️ 常被实现为 `char`，I/O 时需 `static_cast<int>` |
| `std::int16_t` / `std::uint16_t` | 16 | -32768 ~ +32767 / 0 ~ 65535 | 网络协议端口号 |
| `std::int32_t` / `std::uint32_t` | 32 | ±21 亿 / 0 ~ 42 亿 | 游戏坐标、时间戳 |
| `std::int64_t` / `std::uint64_t` | 64 | ±922 亿亿 / 0 ~ 1844 亿亿 | 文件大小、大整数计数 |

> ⚠️ **陷阱提示**：`std::uint8_t` 在很多平台上直接是 `unsigned char` 的别名。直接输出 `std::cout << uint8_t_val` 会打印出字符而非数字，必须转为 `int` 输出。

## 3.2 最小宽度与最快类型

除了精确宽度，标准还提供了适应性更强的类型：

**1. 最小宽度类型 (`_least`)**
- 定义：`int_leastN_t` 保证**至少**有 N 位。
- 场景：嵌入式系统，内存受限，需要节省空间但保证数据不溢出。
- 示例：`int_least32_t` 可能在 32 位机器上是 4 字节，在某些 64 位机器上可能为了对齐也是 4 字节（或更多）。

**2. 最快类型 (`_fast`)**
- 定义：`int_fastN_t` 保证**至少**有 N 位，且是该平台上处理速度最快的整数类型。
- 场景：高性能计算循环计数，不在意内存占用。
- 示例：在 64 位 CPU 上，`int_fast32_t` 可能被定义为 64 位整数，因为 64 位运算比 32 位快。

# 4. 指针与大小相关类型

在涉及内存操作、指针运算和容器索引时，正确选择类型是程序健壮性的关键。

## 4.1 `std::size_t`

- **定义**：`sizeof` 运算符的返回值类型，是无符号整数。
- **位数**：与平台指针宽度一致（32 位系统为 32 位，64 位系统为 64 位）。
- **用途**：
  - 所有 STL 容器的 `size()` 返回值。
  - 数组索引（`for (size_t i = 0; ...)`）。
  - `memcpy`, `malloc` 等函数的长度参数。

> 🚫 **陷阱**：`size_t` 是无符号的，避免在表达式中混用负数。
> ```cpp
> std::size_t i = 10;
> // 错误：i - 12 会下溢变成巨大的正数，导致循环或判断逻辑错误
> if (i - 12 >= 0) { ... } // 永远为真
> ```

## 4.2 `std::ptrdiff_t`

- **定义**：两个指针相减的结果类型，是有符号整数。
- **用途**：处理指针差值，或者需要表示“带符号的偏移量”时。
- **优势**：相比 `int`，它能保证容纳同一数组内任意两个指针的差值。

## 4.3 `std::intptr_t` 与 `std::uintptr_t`

- **定义**：足够容纳指针值的整数类型。
- **用途**：需要将指针视为整数进行运算（如哈希计算）、序列化或在 C 风格接口中传递指针数据。
- **注意**：C++ 标准保证 `void*` 可以安全转换为 `intptr_t` 再转回 `void*`，结果不变。

# 5. 浮点类型

浮点数用于表示实数，遵循 IEEE 754 标准（绝大多数平台）。

## 5.1 类型分类

| 类型 | 典型位数 | 精度（有效数字） | 典型范围 | 推荐场景 |
|------|---------|----------------|-------------|----------|
| `float` | 32 | ~7 位十进制 | ±1.2×10⁻³⁸ ~ ±3.4×10³⁸ | 图形学、纹理坐标、节省内存 |
| `double` | 64 | ~15 位十进制 | ±2.2×10⁻³⁰⁸ ~ ±1.8×10³⁰⁸ | **默认选择**、科学计算、物理 |
| `long double` | 80/128 | 18~33 位 | 更大 | 极高精度计算、金融 |

> 💡 **最佳实践**：除非有明确的内存或性能限制，否则浮点数默认使用 `double`。`float` 的精度在累积运算中极易丢失。

## 5.2 浮点数精度问题

由于二进制无法精确表示部分十进制小数（如 0.1），浮点数运算存在误差。
- **判等陷阱**：严禁使用 `==` 判断两个浮点数是否相等。
- **正确做法**：判断差值是否小于一个极小值 `epsilon`。

```cpp
#include <cmath>
#include <limits>

bool isEqual(double a, double b) {
    return std::abs(a - b) < std::numeric_limits<double>::epsilon();
}
```

# 6. 字符与布尔类型

## 6.1 字符类型演化

| 类型 | 位数 | 字面量前缀 | 用途 | 备注 |
|------|------|-----------|------|------|
| `char` | 8 | 无 | ASCII、窄字符串 | 符号性取决于编译器 |
| `signed char` | 8 | - | 明确的字节(-128~127) | 仅用于小数值运算 |
| `unsigned char` | 8 | - | **二进制数据缓冲区** | 推荐用于内存操作 |
| `char16_t` | 16 | `u"..."` | UTF-16 字符串 | C++11 引入 |
| `char32_t` | 32 | `U"..."` | UTF-32 字符串 | C++11 引入 |
| `wchar_t` | 16/32 | `L"..."` | 宽字符串 | Win 下 16 位，Linux 下 32 位，跨平台慎用 |

## 6.2 布尔类型 `bool`

- **取值**：`true` / `false`。
- **大小**：`sizeof(bool)` 通常为 1 字节，但标准未强制规定。
- **陷阱**：`bool` 参与算术运算时，`true` 提升为 `1`，`false` 提升为 `0`。不要将非 0/1 的整数强制转换给 `bool`，可能导致逻辑混淆。

## 6.3 字节类型 `std::byte` (C++17)

- **定义**：`<cstddef>`，表示最原始的内存单元。
- **特点**：不参与算术运算（不能加减），只能按位运算或转换。这提供了类型安全，防止将内存数据当作整数误用。

# 7. 类型选择最佳实践

## 7.1 推荐策略

1.  **通用整数**：首选 `int`。它是 CPU 处理效率最高的“自然字长”。循环计数、临时变量均可使用。
2.  **数组索引与内存大小**：首选 `std::size_t`。与 STL 容器接口保持一致，避免编译器警告。
3.  **需要固定位数**：首选 `<cstdint>` 中的 `int32_t` 或 `int64_t`。用于网络通信、文件格式解析、精确时间戳。
4.  **大整数**：首选 `long long` 或 `int64_t`。防止运算溢出。
5.  **浮点数**：首选 `double`。除非在向量运算或纹理处理中为了内存对齐和带宽才用 `float`。

## 7.2 避免陷阱

### 陷阱一：无符号整数下溢
```cpp
// ❌ 危险写法
for (std::size_t i = vec.size() - 1; i >= 0; --i) { 
    // 当 vec 为空时，size()-1 变成巨大的正数，导致越界访问
}

// ✅ 推荐写法
for (std::size_t i = vec.size(); i-- > 0; ) {
    // 利用后置递减，i 从 size()-1 变到 0 后停止
}
```

### 陷阱二：隐式截断
```cpp
std::int64_t big_val = 0x123456789ABCDEF0;
std::int32_t small_val = big_val; // 隐式截断，丢失高位数据
// ✅ 应明确使用 static_cast 并检查范围
```

### 陷阱三：`char` 的符号性
```cpp
char c = 200; // 200 超出了 signed char 的范围 (通常 -128~127)
// 若编译器默认 char 为 signed，这可能是负数 (-56)
// ✅ 处理二进制数据请始终使用 unsigned char 或 std::byte
```

# 8. 调试与查询技巧

使用模板函数自动打印类型信息，有助于跨平台调试。

```cpp
#include <iostream>
#include <cstdint>
#include <limits>
#include <type_traits>

template<typename T>
void print_type_info(const char* name) {
    std::cout << name << ":\n"
              << "  Size:   " << sizeof(T) << " bytes (" << sizeof(T) * 8 << " bits)\n"
              << "  Signed: " << (std::is_signed_v<T> ? "Yes" : "No") << "\n"
              << "  Min:    " << std::numeric_limits<T>::min() << "\n"
              << "  Max:    " << std::numeric_limits<T>::max() << "\n\n";
}

int main() {
    print_type_info<int>("int");
    print_type_info<std::int64_t>("std::int64_t");
    print_type_info<std::size_t>("std::size_t");
    print_type_info<double>("double");
}
```

# 9. 总结

C++ 数据类型的选择遵循“适合即是最好”的原则：
- **通用场景**：`int` 和 `double`。
- **精确控制**：`<cstdint>` (如 `int32_t`)。
- **内存与索引**：`std::size_t`。
- **警惕**：无符号整数的下溢问题、浮点数的精度问题。
