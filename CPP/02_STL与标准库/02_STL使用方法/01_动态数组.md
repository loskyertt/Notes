# 1. 常用技巧

`std::vector`（动态数组）是竞赛中最常用的容器，支持 $O(1)$ 随机访问，在尾部插入元素均摊时间为 $O(1)$。在竞赛场景下，能调用 STL 函数实现就尽量不手动实现，既节省代码量又能保证正确性。

## 1.1 内存预分配与清空

- **预分配空间**：`vector` 默认初始容量较小，频繁扩容会导致多次拷贝和内存分配，消耗时间。使用 `v.reserve(n)` 提前分配足够的内存，可以避免扩容开销。

- **快速清空**：
  - `v.clear()`：将 `size` 置 0，但通常不释放内存（`capacity` 不变）。这在后续插入数量相似时是优势，但若需要释放内存，需使用“交换技法”。

```cpp
// 交换技法：创建一个空 vector 与 v 交换，交换后 v 的 capacity 变为 0
vector<int>().swap(v); 
```

## 1.2 去重操作

若需对容器内元素去重，标准做法是“排序 + `unique` + `erase`”。因为 `std::unique` 只能去除**相邻**的重复元素，所以必须先排序。

```cpp
sort(v.begin(), v.end());                             // 1. 排序
v.erase(unique(v.begin(), v.end()), v.end());         // 2. 去重并删除末尾废弃元素
```

# 2. 结构体排序

当容器中存储的是自定义结构体时，`std::sort` 无法直接比较大小，需要指定排序规则。

假设有如下结构体：

```cpp
struct Info {
  int id;
  int score;
};

std::vector<Info> nums = {{1, 90}, {2, 85}, {3, 90}, {4, 70}};
```

**需求**：优先按 `score` 降序排列；若 `score` 相同，则按 `id` 升序排列。

## 2.1 方式一：Lambda 表达式（推荐）

使用 Lambda 表达式作为 `std::sort` 的第三个参数，逻辑清晰且无需修改结构体定义。

**核心规则**：
Lambda 表达式返回 `true` 表示第一个参数应该排在第二个参数前面。
- 升序（小在前）：使用 `<` 号。
- 降序（大在前）：使用 `>` 号。

**实现代码**：

```cpp
// 降序：分数高的在前；分数相同，id 小的在前
std::sort(nums.begin(), nums.end(), [](const Info& a, const Info& b) {
    if (a.score != b.score)
        return a.score > b.score; // 分数不同：大于号表示大的在前（降序）
    return a.id < b.id;           // 分数相同：小于号表示小的在前（升序）
});
```

> [!warning] **a 和 b 的位置不能随意互换**，换了就是换了排序方向。
> 保持 `a` 在左、`b` 在右的习惯，然后只用调整 `<` 或 `>` 来控制升降序，最不容易出错。

**参数传递方式的选择**：

| 传参方式 | 发生了什么 | 适用场景 |
| :--- | :--- | :--- |
| `Info a` | 拷贝构造，产生临时对象 | 对象极小（如只包含基本类型），拷贝开销可忽略 |
| `const Info& a` | 传递引用，无拷贝，禁止修改 | **结构体或大对象，推荐使用** |

## 2.2 方式二：重载运算符

若该结构体在全局范围内都有固定的排序需求，可重载 `operator<`。此时调用 `sort` 时无需传递第三个参数。

```cpp
struct Info {
    int id;
    int score;

    // 重载 < 运算符，定义结构体的“自然顺序”
    bool operator<(const Info& other) const {
        if (score != other.score)
            return score > other.score; // 此处定义为降序
        return id < other.id;
    }
};

// 排序时直接调用
std::sort(nums.begin(), nums.end());
```

## 2.3 多级排序的构建方法

> [!note] `std::sort` 内部基于快速排序、堆排序和插入排序的混合实现。理解其比较逻辑对于编写复杂排序至关重要。
> **比较函数的本质**：
> 比较函数回答的问题始终是：**“a 是否应该排在 b 的前面？”**
> - 返回 `true`：`a` 排在 `b` 前面。
> - 返回 `false`：`b` 排在 `a` 前面（或两者等价）。

- **多级排序的构建方法**：利用 `if` 语句的短路特性，由高优先级到低优先级依次判断。

- **构造模板**：
	1. **第 1 步**：用自然语言描述排序规则（先按 A，再按 B）。
	2. **第 2 步**：将“A 不同”作为第一层 `if`，返回 A 的比较结果。
	3. **第 3 步**：在后续语句中处理 B 的比较。

**实例扩展**：假设按 **班级升序 $\to$ 分数降序 $\to$ ID 升序**。

```cpp
[](const Info& a, const Info& b) {
    if (a.classId != b.classId)
        return a.classId < b.classId; // 班级升序

    if (a.score != b.score)
        return a.score > b.score;     // 分数降序

    return a.id < b.id;               // ID 升序
}
```

# 3. 查找最值与元素

查找 `vector` 中的最大值、最小值或指定元素，推荐使用 `<algorithm>` 头文件中的标准库函数，而非手写循环。

## 3.1 查找最大/最小值

使用 `std::max_element` 和 `std::min_element`。

**注意**：这些函数返回的是**迭代器**，不是数值本身。如果需要数值，需解引用 `*`；如果需要下标，可用迭代器减去 `begin()`。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> v = {10, 5, 8, 20, 3, 15};

    // 查找最大值
    auto max_it = std::max_element(v.begin(), v.end());
    
    // 查找最小值
    auto min_it = std::min_element(v.begin(), v.end());

    if (!v.empty()) {
        std::cout << "最大值: " << *max_it << std::endl;
        std::cout << "最小值: " << *min_it << std::endl;
        
        // 计算下标
        int max_index = std::distance(v.begin(), max_it);
        std::cout << "最大值下标: " << max_index << std::endl;
    }

    return 0;
}
```

## 3.2 同时获取最小值和最大值

使用 `std::minmax_element` 可在一次遍历中同时找到最大值和最小值，效率更高。

```cpp
// 返回一个 pair，first 是最小值的迭代器，second 是最大值的迭代器
auto result = std::minmax_element(v.begin(), v.end());

if (!v.empty()) {
    std::cout << "最小值: " << *result.first << std::endl;
    std::cout << "最大值: " << *result.second << std::endl;
}
```

## 3.3 查找指定值的元素

使用 `std::find` 查找指定值。

- **返回值**：返回指向第一个匹配元素的迭代器。若未找到，返回 `v.end()`。

```cpp
// 查找值为 8 的元素
auto it = std::find(v.begin(), v.end(), 8);

if (it != v.end()) {
    std::cout << "找到了，下标是: " << (it - v.begin()) << std::endl;
} else {
    std::cout << "未找到" << std::endl;
}
```

**注意**：若容器已排序，应使用 `std::lower_bound` 进行二分查找，时间复杂度为 $O(\log N)$，远快于 `std::find` 的 $O(N)$。

# 4. 删除指定元素

`vector` 并没有直接的“按值删除”成员函数，通常结合 `<algorithm>` 库使用。

## 4.1 删除指定值的所有出现（Erase-Remove 惯用法）

这是删除所有等于某个值的元素最高效、最标准的方法。

```cpp
#include <iostream>
#include <vector>
#include <algorithm> // 包含 remove

int main() {
    std::vector<int> v = {10, 5, 8, 5, 20, 5, 15};
    int value_to_delete = 5;

    // std::remove 将不等于 5 的元素移到前面，返回新的逻辑结束迭代器
    // v.erase 物理删除后面多余的元素
    v.erase(std::remove(v.begin(), v.end(), value_to_delete), v.end());

    // 输出结果: 10 8 20 15
    for (int n : v) std::cout << n << " ";
    
    return 0;
}
```

**原理**：`std::remove` 不会改变容器大小，它只是把要保留的元素移到前面，把要删除的元素“挤”到后面，并返回一个指向“新结尾”的迭代器。`v.erase` 负责从“新结尾”到“旧结尾”的物理删除。

## 4.2 删除满足特定条件的元素

使用 `std::remove_if` 结合 Lambda 表达式。

```cpp
// 删除所有偶数
v.erase(std::remove_if(v.begin(), v.end(), [](int n) {
    return n % 2 == 0; // 返回 true 则“移除”
}), v.end());
```

## 4.3 删除指定下标的元素

直接使用 `erase` 成员函数，注意参数必须是迭代器。

```cpp
int index_to_delete = 2; 
if (index_to_delete >= 0 && index_to_delete < v.size()) {
    v.erase(v.begin() + index_to_delete);
}
```

## 4.4 迭代器失效陷阱

在使用迭代器遍历 vector 时直接调用 `erase` 会导致迭代器失效，引发程序崩溃。

**错误写法**：
```cpp
// ❌ 危险代码！
for (auto it = v.begin(); it != v.end(); ++it) {
    if (*it == 5) {
        v.erase(it); // erase 后 it 失效，下一次循环 ++it 崩溃
    }
}
```

**正确写法**：利用 `erase` 的返回值（指向下一个有效元素的迭代器）更新迭代器。
```cpp
// ✅ 正确代码
for (auto it = v.begin(); it != v.end(); /* 这里不要写 ++it */) {
    if (*it == 5) {
        it = v.erase(it); // erase 返回下一个有效迭代器
    } else {
        ++it; // 只有没删除时才手动后移
    }
}
```

# 5. 统计元素个数

统计满足特定条件的元素个数，使用 `<algorithm>` 中的 `std::count` 或 `std::count_if`。

## 5.1 统计指定值的数量

使用 `std::count`。

```cpp
std::vector<int> v = {1, 2, 3, 2, 4, 2};
// 统计 2 出现的次数
int cnt = std::count(v.begin(), v.end(), 2); // 结果为 3
```

## 5.2 统计满足条件的数量

使用 `std::count_if`，配合 Lambda 表达式进行复杂条件判断。

```cpp
struct Info {
  int id;
  int score;
};

int main() {
    std::vector<Info> nums = {{1, 90}, {2, 85}, {3, 60}, {4, 75}, {5, 95}};

    // 统计分数 >= 80 的人数
    int cnt = std::count_if(nums.begin(), nums.end(), [](const Info& p) {
        return p.score >= 80; // 返回 true 则计数
    });

    std::cout << "分数 >= 80 的人数有: " << cnt << " 个" << std::endl;
    
    return 0;
}
```

# 6. 二分查找

在 C++ 中，对于**已排序**的序列（如 `std::vector` 或数组），使用二分查找可以将查找的时间复杂度从 $O(N)$ 降低到 $O(\log N)$。STL 提供了三个核心函数：`std::lower_bound`、`std::upper_bound` 和 `std::binary_search`。

## 6.1 `std::lower_bound`

`std::lower_bound` 用于查找第一个 **大于或等于（`>=`）** 给定值的元素位置。

- **基本定义**：返回指向范围内第一个不小于（即 `>=`）目标值的元素的迭代器。
- **返回值处理**：
    - 如果找到符合条件的元素，返回该元素的迭代器。
    - 如果所有元素都小于目标值，返回 `end()`。
    - 通过 `it - v.begin()` 可以将迭代器转换为下标索引。

```cpp
std::vector<int> v = {1, 2, 4, 4, 5, 6};
int target = 4;

// 查找第一个 >= 4 的位置
auto it = std::lower_bound(v.begin(), v.end(), target);

if (it != v.end()) {
    std::cout << "值: " << *it << " 索引: " << (it - v.begin()) << std::endl; 
    // 输出：值: 4 索引: 2
}
```

## 6.2 `std::upper_bound`

`std::upper_bound` 用于查找第一个 **大于（`>`）** 给定值的元素位置。

- **基本定义**：返回指向范围内第一个严格大于目标值的元素的迭代器。
- **返回值处理**：同样地，若无符合条件的元素则返回 `end()`。

```cpp
std::vector<int> v = {1, 2, 4, 4, 5, 6};
int target = 4;

// 查找第一个 > 4 的位置
auto it = std::upper_bound(v.begin(), v.end(), target);

if (it != v.end()) {
    std::cout << "值: " << *it << " 索引: " << (it - v.begin()) << std::endl; 
    // 输出：值: 5 索引: 4
}
```

理解 `std::lower_bound` 和 `std::upper_bound` 这两个函数的关键在于处理“重复元素”时的边界：

|**函数**|**查找条件**|**语义**|
|---|---|---|
|`std::lower_bound`|`*it >= target`|查找目标值区域的**左边界**（起点）|
|`std::upper_bound`|`*it > target`|查找目标值区域的**右边界的下一个位置**（终点）|

## 6.4 常用应用场景

### 6.4.1 判断元素是否存在

虽然可以使用 `std::binary_search` 直接返回 `bool`，但通过 `lower_bound` 可以在判断的同时获取位置。

```cpp
std::vector<int> v = {1, 3, 5, 7};
int target = 5;

auto it = std::lower_bound(v.begin(), v.end(), target);

// 必须同时满足：1. 没越界 2. 指向的值等于目标值
if (it != v.end() && *it == target) {
    // 元素存在
}
```

### 6.4.2 统计元素出现次数

在有序序列中，目标值 `target` 出现的次数等于 `upper_bound` 减去 `lower_bound` 的距离。

```cpp
std::vector<int> v = {1, 2, 4, 4, 4, 6};
auto low = std::lower_bound(v.begin(), v.end(), 4);
auto up = std::upper_bound(v.begin(), v.end(), 4);

int count = up - low; // 结果为 3
```

### 6.4.3 有序插入

当需要向有序 `std::vector` 中插入一个新元素并保持有序时，应使用 `lower_bound` 获取插入位置。

```cpp
std::vector<int> v = {10, 20, 30, 40};
int num = 25;

auto it = std::lower_bound(v.begin(), v.end(), num);
v.insert(it, num); // 插入后变为 {10, 20, 25, 30, 40}
```

## 6.5 特殊情况：非升序与非容器对象

### 6.5.1 在降序序列中使用

如果数组是降序排列的，必须传入自定义比较器 `std::greater<T>()`。此时 `lower_bound` 的含义变为：第一个**小于等于**目标值的位置。

```cpp
std::vector<int> v = {9, 7, 5, 3, 1};
// 降序查找第一个 <= 5 的位置
auto it = std::lower_bound(v.begin(), v.end(), 5, std::greater<int>());
```

### 6.5.2 在普通数组上使用

这两个函数同样适用于原生数组。

```cpp
int arr[] = {1, 3, 5, 7, 9};
int n = 5;
auto it = std::lower_bound(arr, arr + n, 6);
int index = it - arr; // 索引为 3 (指向 7)
```

## 6.6 总结对照表

|**函数**|**查找条件**|**返回值 (target=5, v={1,3,5,5,7})**|**复杂度**|
|---|---|---|---|
|`std::binary_search`|是否存在|`true`|$O(\log N)$|
|`std::lower_bound`|第一个 `>=`|指向第一个 `5` 的迭代器|$O(\log N)$|
|`std::upper_bound`|第一个 `>`|指向 `7` 的迭代器|$O(\log N)$|
|`std::equal_range`|返回 `pair`|`{lower_bound, upper_bound}`|$O(\log N)$|

> **注意**：对于 `std::set` 或 `std::map` 等关联容器，应使用其**成员函数**（如 `v.lower_bound()`）而非 `std::lower_bound(v.begin(), ...)`。因为成员函数的时间复杂度是 $O(\log N)$，而全局函数在非随机访问迭代器（如链表结构）上会退化为 $O(N)$。
