# 1. 有序关联容器（基于红黑树）

> [!abstract] 有序关联容器的底层实现是**红黑树**（Red-Black Tree）。
> 红黑树是一种自平衡的二叉搜索树，它保证树的高度始终为 $O(\log n)$，从而使查找、插入和删除的时间复杂度稳定在 $O(\log n)$。元素在插入时会自动根据键进行排序，遍历时始终保持有序。

## 1.1 `std::set`

`std::set` 是**键**的有序集合，具有以下核心特性：

- **唯一性**：每个元素仅出现一次，重复插入无效。
- **有序性**：元素默认按升序排列（由 `std::less<Key>` 决定）。
- **不可修改**：元素即为键，不能直接修改元素的值（迭代器指向 `const` 元素），只能删除旧值再插入新值。

### 1.1.1 常用基本操作

```cpp
#include <iostream>
#include <set>

int main() {
    std::set<int> s;

    // 1. 插入元素
    // insert() 返回 pair<iterator, bool>，bool 表示是否插入成功
    auto [it, success] = s.insert(10);
    s.insert(5);
    s.insert(20);
    s.insert(5); // 重复插入失败，success == false，set 中只有 5, 10, 20

    // 2. 查找元素
    // find() 返回迭代器，若未找到则返回 end()，时间复杂度 O(log n)
    if (s.find(10) != s.end()) {
        std::cout << "Found 10" << std::endl;
    }
    // count() 返回 0 或 1，可用于判断元素是否存在
    if (s.count(10)) {
        std::cout << "10 exists" << std::endl;
    }

    // 3. 删除元素
    s.erase(5);              // 按值删除，返回删除的元素个数
    s.erase(s.find(10));     // 按迭代器删除，更高效（省去一次查找）

    // 4. 遍历（自动升序）
    for (int x : s) {
        std::cout << x << " "; // 输出: 20
    }

    // 5. 常用查询
    std::cout << s.size() << std::endl;  // 元素个数
    std::cout << s.empty() << std::endl; // 是否为空

    // 6. 降序排列的 set
    std::set<int, std::greater<int>> s_desc = {3, 1, 4, 1, 5};
    for (int x : s_desc) {
        std::cout << x << " "; // 输出: 5 4 3 1
    }

    return 0;
}
```

### 1.1.2 范围查询：lower_bound 与 upper_bound

`set` 提供了两个极其重要的范围查询接口，时间复杂度均为 $O(\log n)$。**应优先使用容器自身的成员函数，而非 `<algorithm>` 中的同名全局函数**，因为全局版本对 `set` 只能线性扫描（$O(n)$）。

| 函数 | 返回值 |
|---|---|
| `lower_bound(val)` | 指向**第一个 ≥ val** 的元素的迭代器 |
| `upper_bound(val)` | 指向**第一个 > val** 的元素的迭代器 |
| `equal_range(val)` | 返回 `pair<lower_bound, upper_bound>`，即等于 val 的范围 |

```cpp
std::set<int> s = {1, 3, 5, 7, 9};

auto lb = s.lower_bound(4); // 指向 5（第一个 >= 4 的元素）
auto ub = s.upper_bound(5); // 指向 7（第一个 >  5 的元素）

// 遍历 [4, 7) 范围内的元素
for (auto it = lb; it != ub; ++it) {
    std::cout << *it << " "; // 输出: 5
}
```

## 1.2 `std::multiset`

`std::multiset` 与 `set` 几乎完全相同，**唯一的区别是允许存储重复元素**。底层同为红黑树，但允许键值相等的节点同时存在。

### 1.2.1 与 set 的区别

| 特性 | `std::set` | `std::multiset` |
|---|---|---|
| 重复元素 | 不允许 | 允许 |
| `insert()` 返回值 | `pair<iterator, bool>` | `iterator`（始终成功） |
| `count(key)` 返回值 | 0 或 1 | 实际出现次数 |

### 1.2.2 重复元素的操作

```cpp
#include <iostream>
#include <set>

int main() {
    std::multiset<int> ms = {5, 1, 5, 3, 5};
    // 内部有序存储: 1, 3, 5, 5, 5

    std::cout << ms.count(5) << std::endl; // 输出: 3

    // equal_range 获取所有等于 5 的迭代器范围
    auto [lo, hi] = ms.equal_range(5);
    for (auto it = lo; it != hi; ++it) {
        std::cout << *it << " "; // 输出: 5 5 5
    }

    // 只删除一个 5（按迭代器删除）
    ms.erase(ms.find(5));
    std::cout << ms.count(5) << std::endl; // 输出: 2

    // 删除所有 5（按值删除）
    ms.erase(5);
    std::cout << ms.count(5) << std::endl; // 输出: 0

    return 0;
}
```

## 1.3 `std::map`

`std::map` 存储**键值对**（`key-value`），根据 Key 进行排序和索引。Key 必须唯一，Value 可以重复。底层同为红黑树，以 Key 作为排序依据。

### 1.3.1 常用基本操作

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> scores;

    // 1. 插入元素（三种方式）
    scores["Alice"] = 90;                          // 方式一：下标赋值（若 key 不存在则先插入默认值再赋值）
    scores.insert({"Bob", 85});                    // 方式二：insert，若 key 已存在则插入失败
    scores.emplace("Charlie", 95);                 // 方式三：emplace，直接在容器内原地构造，效率最高

    // insert_or_assign：无论 key 是否存在，都执行插入或更新（C++17）
    scores.insert_or_assign("Alice", 92);          // Alice 的分数更新为 92
    
    // try_emplace：只在 key 不存在时才插入（C++17），避免不必要的构造
    scores.try_emplace("Alice", 100);              // Alice 已存在，插入失败，值不变

    // 2. 访问元素
    std::cout << "Alice: " << scores["Alice"] << std::endl; // 输出: 92
    // 注意：若 key 不存在，[] 会自动插入 {key, 默认值}，可能导致意外的元素
    // 推荐使用 at()：key 不存在时抛出 std::out_of_range 异常
    std::cout << "Bob: " << scores.at("Bob") << std::endl;

    // 3. 安全查找（不修改容器的首选方式）
    auto it = scores.find("David");
    if (it != scores.end()) {
        std::cout << "David: " << it->second << std::endl;
    } else {
        std::cout << "David not found." << std::endl;
    }

    // 4. 删除
    scores.erase("Bob");            // 按 key 删除
    scores.erase(scores.find("Charlie")); // 按迭代器删除

    // 5. 遍历（按 Key 升序）
    for (const auto& [key, val] : scores) { // C++17 结构化绑定
        std::cout << key << ": " << val << std::endl;
    }

    return 0;
}
```

### 1.3.2 三种访问方式的对比

| 访问方式 | key 不存在时的行为 | 适用场景 |
|---|---|---|
| `map[key]` | 插入 `{key, 默认值}` 并返回引用 | 需要插入或更新时 |
| `map.at(key)` | 抛出 `std::out_of_range` 异常 | 确定 key 存在，需要只读访问时 |
| `map.find(key)` | 返回 `end()`，不修改容器 | 不确定 key 是否存在时（推荐） |

### 1.3.3 排序机制与自定义比较器

`std::map` 的排序完全基于 **Key**，Value 不参与排序逻辑。

- 默认使用 `std::less<Key>`，即按 Key **升序**排列。
- 若 Key 是自定义结构体，必须提供严格弱序（Strict Weak Ordering）的比较逻辑。

**方式一：重载 `operator<`**

```cpp
struct Player {
    int id;
    bool operator<(const Player& other) const {
        return id < other.id; // 按 id 升序
    }
};
std::map<Player, std::string> scoreboard;
```

**方式二：传入自定义比较器（函数对象）**

```cpp
struct CmpByLength {
    bool operator()(const std::string& a, const std::string& b) const {
        return a.size() < b.size(); // 按字符串长度排序
    }
};
std::map<std::string, int, CmpByLength> m;
```

**方式三：降序排列**

```cpp
std::map<int, std::string, std::greater<int>> m_desc;
```

### 1.3.4 范围查询：lower_bound 与 upper_bound

与 `set` 相同，`map` 也提供成员函数版本的 `lower_bound` 和 `upper_bound`，基于 Key 进行范围查询，时间复杂度 $O(\log n)$。

```cpp
std::map<int, std::string> m = {{1,"a"}, {3,"c"}, {5,"e"}, {7,"g"}};

auto lb = m.lower_bound(3); // 指向 {3, "c"}
auto ub = m.upper_bound(5); // 指向 {7, "g"}

for (auto it = lb; it != ub; ++it) {
    std::cout << it->first << ":" << it->second << " "; // 输出: 3:c 5:e
}
```

## 1.4 `std::multimap`

`std::multimap` 与 `map` 几乎完全相同，**唯一的区别是允许 Key 重复**，即一个 Key 可以对应多个 Value。

### 1.4.1 与 map 的核心区别

- **不支持 `[]` 运算符**：一个 Key 可能对应多个 Value，下标语义不明确。
- **不支持 `at()`**：同上。
- **`insert()` 始终成功**：返回 `iterator` 而非 `pair<iterator, bool>`。

### 1.4.2 常用基本操作

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::multimap<int, std::string> mm;

    // 插入（始终成功）
    mm.insert({1, "Apple"});
    mm.insert({1, "Avocado"}); // Key=1 重复，允许
    mm.insert({2, "Banana"});
    mm.emplace(1, "Apricot");  // Key=1 再次重复

    std::cout << mm.count(1) << std::endl; // 输出: 3

    // 遍历 Key=1 的所有值
    auto [lo, hi] = mm.equal_range(1);
    for (auto it = lo; it != hi; ++it) {
        std::cout << it->second << " "; // 输出: Apple Avocado Apricot（顺序按插入）
    }

    // 查找某一个（返回第一个匹配的迭代器）
    auto it = mm.find(1);
    if (it != mm.end()) {
        std::cout << it->second << std::endl; // 输出: Apple
    }

    // 删除 Key=1 的所有元素
    mm.erase(1); // 删除 3 个

    return 0;
}
```

## 1.5 按值排序的通用解决方案

无论是 `std::map` 还是 `std::unordered_map`，其内部结构（红黑树或哈希表）都是为"通过 Key 快速查找"而设计的，**无法直接按 Value 排序**。

标准做法是：将容器内容转存到 `std::vector<std::pair<Key, Value>>` 后，使用 `std::sort` 进行自定义排序。

### 1.5.1 实现步骤

```cpp
#include <iostream>
#include <map>
#include <vector>
#include <algorithm>
#include <string>

int main() {
    std::map<std::string, int> scores = {{"Alice", 90}, {"Bob", 85}, {"Charlie", 95}, {"David", 90}};

    // 1. 转存到 vector
    std::vector<std::pair<std::string, int>> vec(scores.begin(), scores.end());

    // 2. 自定义排序：先按 Value 降序，再按 Key 升序
    std::sort(vec.begin(), vec.end(), [](const auto& a, const auto& b) {
        if (a.second != b.second) {
            return a.second > b.second; // 第一优先级：Value 降序
        }
        return a.first < b.first;       // 第二优先级：Key 升序
    });

    // 3. 输出结果
    for (const auto& [name, score] : vec) {
        std::cout << name << ": " << score << std::endl;
    }
    // 输出: Charlie: 95 / Alice: 90 / David: 90 / Bob: 85

    return 0;
}
```

> `std::unordered_map` 同理，转存后排序步骤完全相同。

**性能分析**：
- 时间复杂度：$O(n)$ 拷贝 + $O(n \log n)$ 排序，总体 $O(n \log n)$。
- 空间复杂度：$O(n)$（额外的 vector）。

# 2. 无序关联容器（基于哈希表）

> [!abstract] 无序关联容器的底层实现是**哈希表**（Hash Table，具体为拉链法/开放寻址法）。
> 元素位置由哈希函数直接计算得出，查找、插入和删除的平均时间复杂度为 $O(1)$，但**不保证元素的存储顺序**（既不是插入顺序，也不是大小顺序）。

## 2.1 `std::unordered_set`

`std::unordered_set` 是基于哈希值的集合，元素唯一且无序（迭代顺序不确定）。

### 2.1.1 常用基本操作

```cpp
#include <iostream>
#include <unordered_set>

int main() {
    std::unordered_set<int> us = {5, 1, 10};

    us.insert(20);
    us.insert(5); // 插入失败，元素已存在

    // 查找：平均 O(1)
    if (us.find(10) != us.end()) {
        std::cout << "Found 10" << std::endl;
    }
    if (us.count(10)) { // 返回 0 或 1
        std::cout << "10 exists" << std::endl;
    }

    // 遍历：顺序不确定，取决于哈希值和桶分配
    for (int x : us) {
        std::cout << x << " "; // 可能是: 10 5 1 20（顺序无意义）
    }

    return 0;
}
```

**适用场景**：
- 快速判断元素是否存在（去重、查重）。
- 不需要有序输出，追求 $O(1)$ 的查找性能。

## 2.2 `std::unordered_multiset`

`std::unordered_multiset` 与 `unordered_set` 类似，**区别在于允许存储重复的元素**。

```cpp
#include <iostream>
#include <unordered_set>

int main() {
    std::unordered_multiset<int> ums;
    ums.insert(1);
    ums.insert(1);
    ums.insert(2);

    std::cout << ums.count(1) << std::endl; // 输出: 2

    // equal_range 获取所有等于 1 的迭代器范围
    auto [lo, hi] = ums.equal_range(1);
    for (auto it = lo; it != hi; ++it) {
        std::cout << *it << " "; // 输出: 1 1
    }

    // 只删除一个 1
    ums.erase(ums.find(1));
    std::cout << ums.count(1) << std::endl; // 输出: 1

    return 0;
}
```

## 2.3 `std::unordered_map`

`std::unordered_map` 是最常用的关联容器之一，存储 Key 唯一的键值对，提供最快的查找速度（平均 $O(1)$）。

### 2.3.1 常用基本操作

```cpp
#include <iostream>
#include <unordered_map>
#include <string>

int main() {
    std::unordered_map<std::string, int> um;

    // 插入
    um["apple"] = 5;
    um["banana"] = 2;
    um.emplace("cherry", 8); // 原地构造，效率更高

    // 访问
    std::cout << "apple: " << um["apple"] << std::endl; // 若 key 不存在，[] 会插入默认值

    // 安全访问：at() 在 key 不存在时抛出 std::out_of_range
    try {
        std::cout << um.at("orange") << std::endl;
    } catch (const std::out_of_range& e) {
        std::cout << "Key not found: " << e.what() << std::endl;
    }

    // 推荐：先 find 再访问
    if (auto it = um.find("banana"); it != um.end()) {
        std::cout << "banana: " << it->second << std::endl;
    }

    // 遍历：无序
    for (const auto& [key, val] : um) {
        std::cout << key << ": " << val << std::endl;
    }

    return 0;
}
```

### 2.3.2 自定义 Key 的哈希与相等判断

对于标准类型（`int`、`string` 等），STL 内置了哈希函数。若 Key 是**自定义结构体**，必须同时提供两样东西：

1. **哈希函数**：告诉容器如何将自定义类型转换为 `size_t`。
2. **相等判断**：哈希冲突时，容器需要调用 `operator==` 确认两个对象是否真正相等。

仅提供 `operator<`（用于有序容器的比较器）是**不够的**，因为哈希表不依赖大小关系。

```cpp
#include <unordered_map>

struct Player {
    int id;
    std::string name;

    // 相等判断（必须）
    bool operator==(const Player& other) const {
        return id == other.id;
    }
};

// 自定义哈希函数对象（必须）
struct PlayerHasher {
    size_t operator()(const Player& p) const {
        // 直接复用标准库对 int 的哈希
        return std::hash<int>{}(p.id);
    }
};

// 将 PlayerHasher 作为第三个模板参数传入
std::unordered_map<Player, std::string, PlayerHasher> player_notes;
```

**组合多个字段的哈希（推荐写法）**：

```cpp
struct Point {
    int x, y;
    bool operator==(const Point& o) const { return x == o.x && y == o.y; }
};

struct PointHasher {
    size_t operator()(const Point& p) const {
        // 使用哈希组合（XOR + 位移），避免 (0,1) 与 (1,0) 产生相同哈希
        return std::hash<int>{}(p.x) ^ (std::hash<int>{}(p.y) << 32);
    }
};
```

### 2.3.3 性能分析

| 操作 | 平均时间复杂度 | 最坏时间复杂度（哈希冲突严重） |
|---|---|---|
| 查找 | $O(1)$ | $O(n)$ |
| 插入 | $O(1)$ | $O(n)$ |
| 删除 | $O(1)$ | $O(n)$ |

- **内存占用**：通常比 `std::map` 更大，需要维护哈希桶数组及链表/探测结构。
- **哈希冲突**：大量冲突时性能退化为 $O(n)$，可通过自定义哈希函数缓解。

## 2.4 `std::unordered_multimap`

`std::unordered_multimap` 是支持 **Key 重复**的无序键值对容器。

### 2.4.1 与 unordered_map 的核心区别

- **不支持 `[]` 运算符**：一个 Key 可能对应多个 Value，语义不明确。
- **`insert()` 始终成功**。

### 2.4.2 常用基本操作

```cpp
#include <iostream>
#include <unordered_map>
#include <string>

int main() {
    std::unordered_multimap<int, std::string> umm;

    umm.insert({1, "Apple"});
    umm.insert({1, "Android"}); // 允许 Key 重复
    umm.emplace(2, "Banana");

    std::cout << umm.count(1) << std::endl; // 输出: 2

    // 遍历 Key=1 的所有值
    auto [lo, hi] = umm.equal_range(1);
    for (auto it = lo; it != hi; ++it) {
        std::cout << it->second << " "; // 输出: Apple Android（顺序不确定）
    }

    return 0;
}
```

# 3. `std::bitset`

> [!abstract] `std::bitset` 是一种**固定大小的位序列**。
> 严格来说 `std::bitset` 不属于关联容器，而是一种定长的位数组。与 `bool` 数组或 `vector<bool>` 相比，它在空间和位运算效率上更优，常用于状态压缩、标志位管理和集合运算。

> [!warning] `bitset` 的大小是**编译期常量**（模板参数），无法在运行时动态调整。

## 3.1 基本定义与初始化

```cpp
#include <iostream>
#include <bitset>
#include <string>

int main() {
    // 1. 默认初始化：全为 0
    std::bitset<8> b1;                    // 00000000

    // 2. 使用无符号整数初始化（将整数转为二进制）
    std::bitset<8> b2(10);                // 10 的二进制: 00001010

    // 3. 使用字符串初始化（字符串最右侧对应第 0 位）
    std::bitset<8> b3(std::string("10101010")); // 10101010

    std::cout << b2 << std::endl; // 输出: 00001010
    std::cout << b3 << std::endl; // 输出: 10101010

    return 0;
}
```

## 3.2 常用操作

`bitset` 支持位运算符（`&`, `|`, `^`, `~`, `<<`, `>>`），使用方式与整数位运算相同。**位的下标从右向左，从 0 开始计数**（第 0 位是最低有效位）。

```cpp
std::bitset<8> b("11001010");
//   位下标:   7654 3210
//   位的值:   1100 1010

// 1. 按位访问
bool bit0 = b[0]; // 0（最低位）
bool bit3 = b[3]; // 1

// 2. 成员函数
b.set();        // 全部置 1  -> 11111111
b.reset();      // 全部置 0  -> 00000000
b.set(2);       // 第 2 位置 1 -> 00000100
b.reset(2);     // 第 2 位置 0 -> 00000000
b.flip();       // 全部取反
b.flip(3);      // 第 3 位取反

// 3. 查询函数
size_t cnt = b.count();    // 统计 1 的个数
bool any = b.any();        // 是否有任意一位为 1
bool none = b.none();      // 是否全为 0
bool all = b.all();        // 是否全为 1
bool bit = b.test(3);      // 检查第 3 位是否为 1（越界时抛出异常）

// 4. 类型转换
unsigned long ul = b.to_ulong();   // 转换为 unsigned long（超出范围时抛出异常）
std::string s = b.to_string();     // 转换为字符串（最高位在左）

// 5. 位运算操作
std::bitset<8> a("11001010");
std::bitset<8> c("10110011");
std::cout << (a & c) << std::endl; // 按位与: 10000010
std::cout << (a | c) << std::endl; // 按位或: 11111011
std::cout << (a ^ c) << std::endl; // 按位异或: 01111001
std::cout << (a << 2) << std::endl; // 左移 2 位: 00101000
```

## 3.3 应用场景

- **状态压缩**：在图论算法（如旅行商问题 TSP）中，用一个 `bitset` 或整数表示哪些节点已被访问，极大减少内存和时间开销。
- **权限管理**：每一位代表一种权限的开关（如读/写/执行），通过位运算高效地判断和修改权限。
- **集合运算**：将集合映射到位，利用 `&`（交集）、`|`（并集）、`^`（对称差）、`~`（补集）实现 $O(n/w)$（$w$ 为机器字长）的高效运算，远快于基于 `set` 的实现。
- **筛法（Sieve）**：如埃拉托斯特尼筛法中用 `bitset` 标记合数，相比 `bool` 数组节省约 8 倍内存。

# 4. 容器性能对比与选型指南

## 4.1 时间复杂度对比

| 容器 | 底层结构 | 查找 | 插入 | 删除 | 是否有序 | 允许重复 Key |
|---|---|---|---|---|---|---|
| `set` / `map` | 红黑树 | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ | ✅ 有序 | ❌ |
| `multiset` / `multimap` | 红黑树 | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ | ✅ 有序 | ✅ |
| `unordered_set` / `unordered_map` | 哈希表 | $O(1)$ 均摊 | $O(1)$ 均摊 | $O(1)$ 均摊 | ❌ 无序 | ❌ |
| `unordered_multiset` / `unordered_multimap` | 哈希表 | $O(1)$ 均摊 | $O(1)$ 均摊 | $O(1)$ 均摊 | ❌ 无序 | ✅ |

> 注：哈希表在最坏情况（大量哈希冲突）下退化为 $O(n)$。

## 4.2 "无序"的含义

在 C++ STL 中，"无序"指的是**元素的迭代顺序不确定且无逻辑意义**，既不是按大小排列，也不是按插入顺序排列。

三种主要顺序的对比：

| 容器类型 | 迭代顺序 | 实现原理 |
|---|---|---|
| `std::vector` | **插入顺序** | 动态数组，元素按 `push_back` 先后排列 |
| `std::map` / `std::set` | **大小顺序** | 红黑树，按 Key 的 `operator<` 升序/降序排列 |
| `std::unordered_map` / `std::unordered_set` | **"随机"顺序** | 哈希表，顺序取决于哈希值和扩容状态，无意义 |

## 4.3 选型建议

- **需要有序遍历，或频繁使用 `lower_bound` / `upper_bound` 范围查询** → 选 `map` / `set`。
- **只关心查找、插入、删除性能，不需要有序** → 选 `unordered_map` / `unordered_set`（性能更优）。
- **需要存储重复 Key** → 在对应的 `multi` 版本中选择。
- **Key 是自定义类型**：
  - 用于有序容器 → 提供 `operator<` 或自定义比较器。
  - 用于无序容器 → 提供哈希函数对象 **和** `operator==`。
- **需要位运算或集合高效运算，且集合大小固定** → 选 `bitset`。
