# 1. 着色器

着色器（Shader）就是 **运行在 GPU 上的小程序**，用 GLSL 语言（一种类 C 语言）编写。

GPU 和 CPU 的工作方式有根本区别：

CPU：少量核心，串行处理，擅长复杂逻辑；
GPU：几千个核心，并行处理，擅长重复计算。

一帧画面可能有：
- 100万个顶点  → 顶点着色器同时处理100万次
- 200万个像素  → 片段着色器同时处理200万次

着色器就是告诉这几千个核心"每个核心具体做什么计算"的程序。

## 1.1 顶点着色器

**每个顶点执行一次**，核心任务是确定顶点最终出现在屏幕的哪个位置。

比如下面这个着色器什么都没做，顶点坐标原样输出：

```glsl
#version 330 core
layout (location = 0) in vec3 aPos;  // 从 VAO 读入顶点位置

void main() {
    gl_Position = vec4(aPos, 1.0);   // 直接输出，不做任何变换
}
```

实际项目里顶点着色器负责做 MVP 变换：

```glsl
#version 330 core
layout (location = 0) in vec3 aPos;

uniform mat4 model;       // 物体自身的位移/旋转/缩放
uniform mat4 view;        // 摄像机的位置和朝向
uniform mat4 projection;  // 透视效果（近大远小）

void main() {
    gl_Position = projection * view * model * vec4(aPos, 1.0);
}
```

你可以把这三个矩阵当成：

- **model**：把物体从"自身坐标"摆放到"世界里的某个位置"
- **view**：架好摄像机，从某个角度看世界
- **projection**：加上透视效果，远处的东西变小

## 1.2 片段着色器

**每个片段（像素候选）执行一次**，核心任务是决定这个像素的颜色。

比如：

```glsl
#version 330 core
out vec4 FragColor;  // 输出颜色（R, G, B, A）

void main() {
    FragColor = vec4(1.0, 0.5, 0.2, 1.0);  // 硬编码橙色，所有像素一样
}
```

> 上面这个着色器让整个三角形变成纯橙色。

实际项目里片段着色器会做很多事：

**例一：用 uniform 动态改变颜色**

> uniform 是 C++ 向着色器传参数的方式。

```glsl
// GLSL
uniform vec4 ourColor;  // 从 C++ 传入颜色

void main() {
    FragColor = ourColor;
}
```

```cpp
// C++ 侧，每帧改变颜色，实现颜色动画
float timeValue = glfwGetTime();
float greenValue = (sin(timeValue) / 2.0f) + 0.5f;  // 0~1 之间循环
glUniform4f(colorLocation, 0.0f, greenValue, 0.0f, 1.0f);
```

**例二：顶点颜色插值**

> 两者通过 out/in 传递数据，光栅化阶段自动插值。

```glsl
// 顶点着色器：把颜色传给片段着色器
layout (location = 0) in vec3 aPos;
layout (location = 1) in vec3 aColor;  // 从 VAO 读入顶点颜色
out vec3 ourColor;                     // 传给片段着色器

void main() {
    gl_Position = vec4(aPos, 1.0);
    ourColor = aColor;
}
```

```glsl
// 片段着色器：接收插值后的颜色
in vec3 ourColor;   // 光栅化阶段自动插值好了
out vec4 FragColor;

void main() {
    FragColor = vec4(ourColor, 1.0);
}
```

效果就是三角形三个顶点各自一个颜色，中间平滑过渡：

```
     红色顶点
        △
       /  \
      /    \
绿色顶点──蓝色顶点
  中间自动插值出渐变色
```

**例三：纹理采样（贴图）**

```glsl
in vec2 TexCoord;        // 从顶点着色器传来的纹理坐标
uniform sampler2D tex;   // 纹理图片

void main() {
    FragColor = texture(tex, TexCoord);  // 查图片上对应位置的颜色
}
```

## 1.2 两者的配合

一次完整的绘制流程中，顶点着色器和片段着色器的分工是：

```
顶点着色器                        片段着色器
──────────────────────────────────────────────
负责"在哪里"                     负责"什么颜色"
每顶点执行一次                   每像素执行一次
输出 gl_Position                 输出 FragColor
可以传数据给片段着色器 →  out/in 变量  → 接收并使用
```

顶点着色器向片段着色器传数据靠 `out` / `in` 关键字：

```glsl
// 顶点着色器
out vec3 ourColor;   // 声明要传出去的数据
void main() {
    ourColor = aColor;
}

// 片段着色器
in vec3 ourColor;    // 接收，名字必须相同
void main() {
    FragColor = vec4(ourColor, 1.0);
}
```

光栅化阶段会自动对这些传递的数据做 **插值**，所以三个顶点颜色不同时，中间像素会自动得到混合颜色，不需要你手动计算。

# 2. GLSL

其实完全不懂 glsl 的语法，对学习 opengl影响不大，因为 GLSL 语法本身不多，如有 C++ 基础，上手极快。

> 比如 `if / else`、`for / while`、函数定义、`+ - * /` 这些和 C++ 完全一样。因为 glsl 没有指针、内存管理、类、STL 这些，语法反而比 C++ 简单很多。

学 OpenGL 的过程中 GLSL 是 **边用边学** 的，不需要提前系统学习。你会遇到的顺序大概是：

```
现在：最简单的 in/out/uniform，几行代码
↓
纹理章节：加上 sampler2D 和 texture()
↓
光照章节：加上 dot()、normalize()、更复杂的数学
↓
高级效果：才会用到更多内置函数
```

## 2.1 GLSL 语法（三板块）

**一、内置向量类型**

```glsl
vec2 / vec3 / vec4   // 2/3/4维浮点向量
mat4                 // 4×4矩阵

// 构造方式
vec3 pos = vec3(1.0, 0.0, 0.0);
vec4 color = vec4(pos, 1.0);  // 用 vec3 + 一个值构造 vec4

// 分量访问
pos.x  pos.y  pos.z   // 当位置用
color.r  color.g  color.b  color.a  // 当颜色用
```

**二、修饰符关键字**

```glsl
in        // 接收数据（从 VBO 或上一阶段传入）
out       // 传出数据（到下一阶段）
uniform   // 从 C++ 传入的全局变量
```

**三、内置变量和函数**

```glsl
// 内置变量
gl_Position   // 顶点着色器必须赋值的输出

// 常用内置函数（见名知意）
texture(sampler, uv)   // 采样纹理
normalize(v)           // 向量归一化
length(v)              // 向量长度
dot(v1, v2)            // 点乘
mix(a, b, t)           // 线性插值
clamp(x, 0.0, 1.0)    // 限制范围
```

## 2.2 语法拆解

示例：

```glsl
#version 330 core
layout (location = 0) in vec3 aPos;  // 从 VAO 读入顶点位置

void main() {
    gl_Position = vec4(aPos, 1.0);   // 直接输出，不做任何变换
}
```

`layout (location = 0) in vec3 aPos` 这整行是一个**变量声明**，只是 GLSL 的声明语法比 C++ 多了修饰符。对比一下：

```cpp
// C++ 的变量声明：
int x;

// GLSL 的变量声明：
layout (location = 0) in vec3 aPos;
// ↑ 修饰符1        ↑修饰符2 ↑类型 ↑变量名
```

- `vec3` 就是 GLSL 的内置类型，相当于 C++ 里的 `float[3]`，表示一个三维向量：

```glsl
vec3 aPos;  // 等价于存了 x, y, z 三个 float
```

- `aPos` 是 **你自己起的名字**，叫什么都行：

```glsl
in vec3 aPos;      // 常用写法
in vec3 position;  // 也可以
in vec3 abc;       // 也行，只是不推荐
```

- `in` 是修饰符，表示"从外部接收数据"，其作用是告诉 GPU 这个变量的数据 **从 VAO/VBO 读入**：

```glsl
in vec3 aPos;   // 这个值由 VAO 提供，每个顶点不同
out vec4 vertexColor;  // 这个值由你在着色器里赋值，传给下一阶段
```

- `layout (location = 0)` 是指定槽位编号，即告诉 GPU：**这个变量对应 VAO 里的第 0 号属性槽**。

还记得 C++ 里这行代码吗：

```cpp
glVertexAttribPointer(0, 3, GL_FLOAT, ...);
//                    ↑
//                  槽位编号 0
```

`layout (location = 0)` 就是和这里的 `0` 对应，把 GLSL 变量和 VAO 槽位 **连接** 起来：

```
VAO 槽位 0 的数据  ──→  layout(location=0) in vec3 aPos
```

如果你有多个属性（位置 + 颜色），就这样区分：

```glsl
layout (location = 0) in vec3 aPos;    // 槽位0 → 位置
layout (location = 1) in vec3 aColor;  // 槽位1 → 颜色
```

对应 C++ 里：

```cpp
glVertexAttribPointer(0, 3, ...);  // 槽位0：位置
glVertexAttribPointer(1, 3, ...);  // 槽位1：颜色
```

整行的完整含义：

```glsl
layout (location = 0) in vec3 aPos;
// 对应VAO槽位0 - 从外部读入 - 3维向量 - 变量名
```

> 声明一个叫 `aPos` 的三维向量变量，它的值从 VAO 的第 0 号槽位读入。

`layout` 是 GLSL 的**限定符关键字**，专门用来描述变量的一些元信息，括号里是参数：

```glsl
layout (location = 0)   // 最常用：指定槽位
layout (location = 2)   // 指定其他槽位
```

类比 C++ 里的 `__attribute__` 或者现代 C++ 的 `[[nodiscard]]`，都是修饰变量/函数的额外信息。

## 2.3 建议

不需要专门去找 GLSL 教程，遇到不认识的语法就查 [docs.gl](https://docs.gl)。把 GLSL 当作 OpenGL 的一部分一起学就行，不要单独割裂出来。

后面写着色器会频繁用到这些：

```glsl
// 基本类型
float x = 1.0;
vec2 uv = vec2(0.5, 0.5);       // 2维向量，常用于纹理坐标
vec3 pos = vec3(1.0, 0.0, 0.0); // 3维向量，常用于位置/颜色
vec4 color = vec4(1.0, 0.5, 0.2, 1.0); // 4维，常用于颜色(RGBA)
mat4 mvp;                        // 4×4矩阵

// 向量分量访问，两种方式等价
vec3 v = vec3(1.0, 2.0, 3.0);
v.x  v.y  v.z        // 当作位置用
v.r  v.g  v.b        // 当作颜色用（完全一样，只是语义不同）

// 向量混合构造（swizzle）
vec4 result = vec4(v.rgb, 1.0);  // 用 vec3 的 xyz 加上 1.0 构造 vec4

// 内置函数
float len = length(v);           // 向量长度
vec3 n = normalize(v);           // 归一化
float d = dot(v1, v2);           // 点乘
vec3 c = cross(v1, v2);          // 叉乘
vec4 col = texture(sampler, uv); // 纹理采样
```
