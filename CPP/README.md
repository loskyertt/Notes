# C++ 知识笔记库

本仓库收录了 C++ 开发相关的系统性笔记，涵盖语言核心特性、设计模式、算法、游戏开发及图形学等主题，适合作为学习与查阅的参考手册。

---

# 使用说明

1. **浏览**：通过上方目录导航快速定位目标主题
2. **搜索**：使用 `Ctrl + P` 打开文件搜索，输入关键词快速查找
3. **编辑**：本仓库为纯 Markdown 文件，可直接在 Obsidian 或任意编辑器中编辑
4. **扩展**：新增笔记时请遵循 `序号_标题.md` 的命名规范，便于排序管理
