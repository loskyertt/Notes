## 推荐学习路线

1. 先阅读 `01_C++语言核心`，建立语言、对象模型和资源管理基础。
2. 再阅读 `02_STL与标准库`，把容器、迭代器、lambda、optional、variant 等常用工具串起来。
3. 进入 `03_并发编程`、`04_系统编程` 和 `05_网络编程`，补齐工程实践中的底层能力。
4. 使用 `06_算法与刷题` 做专项练习，用 `07_设计模式` 总结工程抽象方法。
5. 图形或游戏方向可继续阅读 `08_图形与游戏开发`。

## 命名与维护规范

- 顶层目录使用 `NN_主题` 排序。
- 普通知识笔记使用 `NN_中文标题.md` 命名。
- 刷题笔记保留平台题号或题源前缀，便于回查。
- 图片放在对应主题目录的 `imgs/` 下，并使用相对路径引用。
- 新增笔记后同步更新对应目录的 `README.md`。
