# 1. SQL 基础概念

**SQL（Structured Query Language，结构化查询语言）** 是用于操作关系型数据库的标准语言，主要分为以下几类：

| 分类 | 全称 | 包含语句 | 作用 |
|---|---|---|---|
| **DDL** | 数据定义语言 | `CREATE` / `ALTER` / `DROP` | 定义和修改表结构 |
| **DML** | 数据操纵语言 | `INSERT` / `UPDATE` / `DELETE` | 增删改数据 |
| **DQL** | 数据查询语言 | `SELECT` | 查询数据 |
| **DCL** | 数据控制语言 | `GRANT` / `REVOKE` | 权限管理 |
| **TCL** | 事务控制语言 | `COMMIT` / `ROLLBACK` | 事务管理 |

# 2. 数据定义语言（DDL）

## 2.1 创建表

```sql
CREATE TABLE contact (
    mob_no   VARCHAR(20)  NOT NULL,       -- 手机号，非空
    name     VARCHAR(50)  NOT NULL,       -- 姓名，非空
    provider VARCHAR(50),                 -- 运营商
    CONSTRAINT pk_contact PRIMARY KEY (mob_no)  -- 主键约束
);

CREATE TABLE phonetotal (
    id             INT          NOT NULL,
    op_mob_no      VARCHAR(20)  NOT NULL,
    business_type  VARCHAR(50),
    occur_month    INT,
    occur_count    INT          DEFAULT 0,
    occur_balance  DECIMAL(10, 2),
    CONSTRAINT pk_phonetotal PRIMARY KEY (id),
    CONSTRAINT fk_mob FOREIGN KEY (op_mob_no) REFERENCES contact(mob_no)
);
```

**常用约束（Constraint）**：

| 约束 | 说明 |
|---|---|
| `PRIMARY KEY` | 主键，唯一且非空 |
| `NOT NULL` | 该列不允许为 NULL |
| `UNIQUE` | 该列的值在表中唯一 |
| `DEFAULT 值` | 未插入时使用默认值 |
| `FOREIGN KEY ... REFERENCES ...` | 外键，引用另一张表的列 |
| `CHECK (条件)` | 检查约束，限制列的合法值范围 |

## 2.2 修改表结构

```sql
-- 添加列
ALTER TABLE phonetotal ADD COLUMN remark VARCHAR(2000);

-- 修改列类型
ALTER TABLE phonetotal MODIFY COLUMN remark TEXT;

-- 删除列
ALTER TABLE phonetotal DROP COLUMN remark;

-- 重命名表
ALTER TABLE contact RENAME TO contacts;
```

## 2.3 删除表

```sql
DROP TABLE IF EXISTS contact;   -- 若存在则删除，避免报错
TRUNCATE TABLE phonetotal;      -- 清空表中所有数据，但保留表结构（比 DELETE 快）
```

> **DROP vs TRUNCATE vs DELETE**：
> - `DROP TABLE`：删除整张表（含结构和数据）。
> - `TRUNCATE TABLE`：仅清空数据，保留表结构，不可回滚（DDL）。
> - `DELETE FROM`：逐行删除数据，可加 `WHERE`，可回滚（DML）。

## 2.4 创建索引

索引可以显著提升查询性能，但会降低写入速度并占用额外存储空间。

```sql
-- 创建普通索引
CREATE INDEX idx_phonetotal ON phonetotal(occur_month, op_mob_no);

-- 创建唯一索引
CREATE UNIQUE INDEX idx_contact_name ON contact(name);

-- 删除索引
DROP INDEX idx_phonetotal ON phonetotal;
```

# 3. 数据查询语言（DQL）

## 3.1 基本查询

```sql
-- 查询指定列
SELECT mob_no, name FROM contact;

-- 查询所有列（* 表示所有列，生产环境建议明确指定列名）
SELECT * FROM contact;

-- 列别名（AS 可省略）
SELECT mob_no AS 手机号, name AS 姓名 FROM contact;

-- 去除重复行（DISTINCT 作用于 SELECT 后的所有列的组合）
SELECT DISTINCT provider FROM contact;

-- 限制返回行数（MySQL / PostgreSQL）
SELECT * FROM contact LIMIT 10;

-- 跳过前 N 行再取 M 行（分页查询）
SELECT * FROM contact LIMIT 10 OFFSET 20; -- 跳过前 20 行，取第 21-30 行
```

## 3.2 WHERE 条件过滤

`WHERE` 子句用于在数据被分组和聚合**之前**过滤原始行。

```sql
-- 等于 / 不等于
SELECT * FROM contact WHERE provider = '中国移动';
SELECT * FROM contact WHERE provider <> '中国移动'; -- != 等价于 <>

-- 比较运算
SELECT * FROM phonetotal WHERE occur_count > 100;
SELECT * FROM phonetotal WHERE occur_count BETWEEN 50 AND 200; -- 闭区间 [50, 200]

-- 集合匹配（IN / NOT IN）
SELECT * FROM contact WHERE provider IN ('中国移动', '中国联通');
SELECT * FROM contact WHERE provider NOT IN ('中国移动', '中国联通');

-- 模糊匹配（LIKE）
-- % 匹配任意数量字符，_ 匹配单个字符
SELECT * FROM contact WHERE name LIKE '张%';   -- 姓张的人
SELECT * FROM contact WHERE name LIKE '_三';   -- 名字第二个字是"三"

-- NULL 判断（不能用 = NULL，必须用 IS NULL）
SELECT * FROM contact WHERE provider IS NULL;
SELECT * FROM contact WHERE provider IS NOT NULL;

-- 逻辑运算（AND / OR / NOT），AND 优先级高于 OR
SELECT * FROM contact 
WHERE provider = '中国移动' AND name = '小丽';

SELECT * FROM contact
WHERE provider = '中国移动' OR provider = '中国联通';

SELECT * FROM contact
WHERE NOT provider = '中国电信';
```

## 3.3 ORDER BY 排序

`ORDER BY` 作用于查询结果，是 SQL 执行的最后阶段之一。

```sql
-- 升序（ASC，默认值，可省略）
SELECT * FROM contact ORDER BY name ASC;

-- 降序（DESC）
SELECT * FROM phonetotal ORDER BY occur_count DESC;

-- 多字段排序：先按第一个字段，再按第二个字段
SELECT * FROM phonetotal 
ORDER BY occur_count DESC, occur_balance DESC;

-- NULL 值排序（不同数据库行为不同，MySQL 中 NULL 视为最小值）
SELECT * FROM contact ORDER BY provider ASC NULLS LAST;  -- PostgreSQL 语法
```

## 3.4 聚合函数

聚合函数对一组行进行计算，返回单个值。它们通常与 `GROUP BY` 配合使用；若无 `GROUP BY`，则对整个表计算。

| 函数 | 说明 |
|---|---|
| `COUNT(*)` | 统计总行数（含 NULL） |
| `COUNT(列名)` | 统计该列非 NULL 的行数 |
| `COUNT(DISTINCT 列名)` | 统计该列不重复的非 NULL 值数量 |
| `SUM(列名)` | 求和（忽略 NULL） |
| `AVG(列名)` | 求平均值（忽略 NULL） |
| `MAX(列名)` | 最大值 |
| `MIN(列名)` | 最小值 |

```sql
SELECT COUNT(*)                    FROM contact;        -- 总行数
SELECT COUNT(provider)             FROM contact;        -- provider 非 NULL 的行数
SELECT COUNT(DISTINCT provider)    FROM contact;        -- 不同运营商的数量
SELECT SUM(occur_count)            FROM phonetotal;
SELECT AVG(occur_count)            FROM phonetotal;
SELECT MAX(occur_count), MIN(occur_count) FROM phonetotal;
```

## 3.5 GROUP BY 分组

`GROUP BY` 把相同值的行归为一组，再对每组应用聚合函数。

```sql
-- 按运营商统计联系人数量
SELECT provider, COUNT(*) AS 人数
FROM contact
GROUP BY provider;

-- 按运营商和业务类型统计
SELECT c.provider, p.business_type, SUM(p.occur_count) AS 总次数
FROM contact c
JOIN phonetotal p ON c.mob_no = p.op_mob_no
GROUP BY c.provider, p.business_type;
```

> **规则**：`SELECT` 中出现的列，要么是 `GROUP BY` 中的分组列，要么被聚合函数包裹，否则语句不合法（在严格模式下报错）。

## 3.6 HAVING 筛选分组

`HAVING` 在 `GROUP BY` **之后**对分组结果进行过滤，可以引用聚合函数的结果。

```sql
-- 筛选出总次数大于 100 的业务类型
SELECT business_type, SUM(occur_count) AS 总次数
FROM phonetotal
GROUP BY business_type
HAVING SUM(occur_count) > 100;
```

**WHERE 与 HAVING 的核心区别**：

| 子句 | 执行时机 | 能否使用聚合函数 | 典型用途 |
|---|---|---|---|
| `WHERE` | 分组**前**，过滤原始行 | ❌ 不能 | 过滤单行数据 |
| `HAVING` | 分组**后**，过滤分组结果 | ✅ 能 | 过滤聚合统计结果 |

# 4. 多表查询

## 4.1 JOIN 连接查询

`JOIN` 用于根据关联条件将两张或多张表的列合并到同一结果集中。

### 4.1.1 INNER JOIN（内连接）

只返回两张表中**都能匹配**关联条件的行，不满足条件的行被丢弃。

```sql
SELECT c.name, p.business_type, p.occur_count
FROM contact c
INNER JOIN phonetotal p ON c.mob_no = p.op_mob_no;
```

```
contact          phonetotal
┌────────┐       ┌──────────┐
│ 小丽   │ ────→ │ 小丽的行 │  ← 两侧都有，返回
│ Boss   │ ────→ │ Boss的行 │  ← 两侧都有，返回
│ 老豆   │       └──────────┘  ← phonetotal 无对应行，丢弃
└────────┘
```

### 4.1.2 LEFT JOIN（左外连接）

返回**左表所有行**，右表中无匹配的列填充 `NULL`。

```sql
-- 查询所有联系人，包括没有通话记录的
SELECT c.name, p.occur_count
FROM contact c
LEFT JOIN phonetotal p ON c.mob_no = p.op_mob_no;
-- 没有通话记录的联系人，occur_count 列显示为 NULL
```

### 4.1.3 RIGHT JOIN（右外连接）

返回**右表所有行**，左表中无匹配的列填充 `NULL`。

```sql
-- 查询所有通话记录，包括联系人信息已被删除的记录
SELECT c.name, p.op_mob_no, p.occur_count
FROM contact c
RIGHT JOIN phonetotal p ON c.mob_no = p.op_mob_no;
-- 联系人已删除的记录，name 列显示为 NULL
```

> `A RIGHT JOIN B` 等价于将表的顺序调换后写成 `B LEFT JOIN A`，实际开发中更习惯统一使用 `LEFT JOIN`。

### 4.1.4 FULL OUTER JOIN（全外连接）

返回**两张表所有行**，对方无匹配的列填充 `NULL`。MySQL 不直接支持，可用 `LEFT JOIN UNION RIGHT JOIN` 模拟。

```sql
-- PostgreSQL / SQL Server 语法
SELECT c.name, p.op_mob_no, p.occur_count
FROM contact c
FULL OUTER JOIN phonetotal p ON c.mob_no = p.op_mob_no;

-- MySQL 模拟写法
SELECT c.name, p.op_mob_no FROM contact c LEFT  JOIN phonetotal p ON c.mob_no = p.op_mob_no
UNION
SELECT c.name, p.op_mob_no FROM contact c RIGHT JOIN phonetotal p ON c.mob_no = p.op_mob_no;
```

### 4.1.5 CROSS JOIN（交叉连接）

返回两张表的**笛卡尔积**（每行与另一张表每行都组合），结果行数 = 左表行数 × 右表行数。通常需要配合 `WHERE` 限制结果。

```sql
SELECT c.name, b.business_type
FROM contact c
CROSS JOIN (SELECT DISTINCT business_type FROM phonetotal) b;
-- 每个联系人与每种业务类型都组合一次
```

### 4.1.6 自连接（Self Join）

表与自身关联，必须使用别名加以区分。常用于处理层级关系（如员工-上级）。

```sql
-- 假设 employee 表有 id 和 manager_id 列
SELECT e.name AS 员工, m.name AS 上级
FROM employee e
LEFT JOIN employee m ON e.manager_id = m.id;
```

### 4.1.7 JOIN 类型对比

```
左表 A        右表 B
┌───────┐    ┌───────┐
│ 1     │    │ 1     │
│ 2     │    │ 2     │
│ 3     │    │ 4     │ ← B 独有
└───────┘    └───────┘

INNER JOIN：返回 {1, 2}           （交集）
LEFT  JOIN：返回 {1, 2, 3}        （A 全部 + 匹配的 B）
RIGHT JOIN：返回 {1, 2, 4}        （B 全部 + 匹配的 A）
FULL  JOIN：返回 {1, 2, 3, 4}     （并集）
```

## 4.2 子查询

子查询是嵌套在另一个 SQL 语句中的 `SELECT` 语句，可出现在 `WHERE`、`FROM`、`SELECT` 子句中。

### 4.2.1 WHERE 中的子查询

```sql
-- 查询 5 月没有通话记录的联系人
SELECT name
FROM contact
WHERE mob_no NOT IN (
    SELECT DISTINCT op_mob_no
    FROM phonetotal
    WHERE occur_month = 201205
);

-- 查询通话次数超过平均值的记录
SELECT op_mob_no, occur_count
FROM phonetotal
WHERE occur_count > (
    SELECT AVG(occur_count) FROM phonetotal  -- 标量子查询：返回单个值
);
```

### 4.2.2 FROM 中的子查询（派生表）

```sql
-- 先计算每人总次数，再筛选总次数 > 100 的人
SELECT sub.op_mob_no, sub.total
FROM (
    SELECT op_mob_no, SUM(occur_count) AS total
    FROM phonetotal
    GROUP BY op_mob_no
) AS sub                     -- 派生表必须有别名
WHERE sub.total > 100;
```

### 4.2.3 SELECT 中的子查询（标量子查询）

```sql
-- 查询每个联系人的姓名，以及其通话记录总次数
SELECT 
    c.name,
    (SELECT SUM(p.occur_count)
     FROM phonetotal p
     WHERE p.op_mob_no = c.mob_no) AS 总次数
FROM contact c;
```

## 4.3 EXISTS 与 NOT EXISTS

`EXISTS` 检查子查询是否返回至少一行，返回布尔值，不关心子查询返回的具体数据（惯用 `SELECT 1`）。

```sql
-- 查询有通话记录的联系人
SELECT name
FROM contact c
WHERE EXISTS (
    SELECT 1
    FROM phonetotal p
    WHERE p.op_mob_no = c.mob_no
);

-- 查询没有通话记录的联系人
SELECT name
FROM contact c
WHERE NOT EXISTS (
    SELECT 1
    FROM phonetotal p
    WHERE p.op_mob_no = c.mob_no
);
```

**EXISTS vs IN 的选择**：
- `EXISTS`：子查询结果集非常大时性能更好（找到第一行即停止）。
- `IN`：子查询结果集较小时写法更简洁。
- 当子查询可能返回 `NULL` 时，`NOT IN` 会出现意外（整个条件变为 UNKNOWN），此时应优先使用 `NOT EXISTS`。

## 4.4 集合操作

集合操作对两个 `SELECT` 的结果集进行运算，要求两侧列数相同、类型兼容。

```sql
-- UNION：合并两个结果集，自动去除重复行
SELECT mob_no FROM contact
UNION
SELECT op_mob_no FROM phonetotal;

-- UNION ALL：合并两个结果集，保留所有重复行（性能优于 UNION）
SELECT mob_no FROM contact
UNION ALL
SELECT op_mob_no FROM phonetotal;

-- INTERSECT：返回两个结果集的交集（MySQL 不支持，可用 INNER JOIN 替代）
SELECT mob_no FROM contact
INTERSECT
SELECT op_mob_no FROM phonetotal;

-- EXCEPT / MINUS：返回在第一个结果集中但不在第二个中的行
-- （MySQL 不支持，可用 NOT IN 或 NOT EXISTS 替代）
SELECT mob_no FROM contact
EXCEPT
SELECT op_mob_no FROM phonetotal;
```

# 5. 数据操纵语言（DML）

## 5.1 INSERT 插入数据

```sql
-- 插入单行（推荐明确指定列名）
INSERT INTO contact (mob_no, name, provider)
VALUES ('13800138000', '张三', '中国移动');

-- 插入多行
INSERT INTO contact (mob_no, name, provider)
VALUES 
    ('13900139000', '李四', '中国联通'),
    ('13700137000', '王五', '中国电信');

-- 从另一张表复制数据
INSERT INTO contact_backup (mob_no, name, provider)
SELECT mob_no, name, provider FROM contact;
```

## 5.2 UPDATE 更新数据

```sql
-- 更新单列
UPDATE contact
SET name = '李四'
WHERE mob_no = '13800138000';

-- 更新多列
UPDATE phonetotal
SET occur_count = occur_count + 1,
    occur_balance = occur_balance * 1.05
WHERE occur_month = 201205;
```

> **注意**：执行 `UPDATE` 前建议先用 `SELECT` 验证 `WHERE` 条件，避免误更新过多行。省略 `WHERE` 将更新表中所有行。

## 5.3 DELETE 删除数据

```sql
-- 删除满足条件的行
DELETE FROM contact
WHERE mob_no = '13800138000';

-- 删除所有行（可回滚，比 TRUNCATE 慢）
DELETE FROM contact;
```

# 6. 常用函数

## 6.1 字符串函数

```sql
SELECT UPPER(name)                        FROM contact;  -- 转大写
SELECT LOWER(name)                        FROM contact;  -- 转小写
SELECT LENGTH(name)                       FROM contact;  -- 字符串长度
SELECT SUBSTRING(name, 1, 1)              FROM contact;  -- 取第 1 个字符（姓）
SELECT CONCAT(name, '(', provider, ')')   FROM contact;  -- 字符串拼接
SELECT TRIM('  张三  ');                                  -- 去除两端空格
SELECT REPLACE(name, '张', '李')          FROM contact;  -- 替换字符
SELECT LPAD(mob_no, 15, '*')              FROM contact;  -- 左填充到指定长度
```

## 6.2 日期函数

```sql
SELECT NOW();                                 -- 当前日期时间
SELECT CURDATE();                             -- 当前日期（无时间部分）
SELECT YEAR(NOW());                           -- 提取年份
SELECT MONTH(NOW());                          -- 提取月份
SELECT DAY(NOW());                            -- 提取日
SELECT DATE_FORMAT(NOW(), '%Y-%m-%d');        -- 格式化日期（MySQL）
SELECT DATEDIFF('2024-12-31', '2024-01-01'); -- 计算两日期相差天数（MySQL）
SELECT DATE_ADD(NOW(), INTERVAL 7 DAY);       -- 日期加减（MySQL）
```

## 6.3 数值函数

```sql
SELECT ROUND(occur_balance, 2) FROM phonetotal;   -- 四舍五入，保留 2 位小数
SELECT CEIL(4.1);                                  -- 向上取整 → 5
SELECT FLOOR(4.9);                                 -- 向下取整 → 4
SELECT ABS(-10);                                   -- 绝对值 → 10
SELECT MOD(10, 3);                                 -- 取余 → 1
SELECT POWER(2, 10);                               -- 幂运算 → 1024
```

## 6.4 NULL 处理函数

`NULL` 与任何值（包括 `NULL` 自身）进行运算或比较，结果均为 `NULL`，需要特殊处理。

```sql
-- COALESCE：返回参数列表中第一个非 NULL 的值（最通用，SQL 标准）
SELECT COALESCE(provider, '未知运营商') FROM contact;

-- IFNULL：若第一个参数为 NULL 则返回第二个参数（MySQL 专用）
SELECT IFNULL(provider, '未知运营商') FROM contact;

-- NULLIF：若两个参数相等则返回 NULL，否则返回第一个参数（防止除零错误常用）
SELECT occur_count / NULLIF(occur_balance, 0) FROM phonetotal;

-- IS NULL / IS NOT NULL（见 WHERE 章节）
```

## 6.5 条件函数：CASE WHEN

`CASE WHEN` 是 SQL 中的条件表达式，相当于编程语言中的 `if-else`，可出现在 `SELECT`、`WHERE`、`ORDER BY` 等任意位置。

```sql
-- 简单 CASE（等值判断）
SELECT 
    name,
    CASE provider
        WHEN '中国移动' THEN '移动'
        WHEN '中国联通' THEN '联通'
        WHEN '中国电信' THEN '电信'
        ELSE '其他'
    END AS 运营商简称
FROM contact;

-- 搜索 CASE（范围/条件判断，更灵活）
SELECT 
    op_mob_no,
    occur_count,
    CASE
        WHEN occur_count >= 1000 THEN '高频用户'
        WHEN occur_count >= 100  THEN '中频用户'
        ELSE                          '低频用户'
    END AS 用户等级
FROM phonetotal;

-- 结合 SUM 实现行转列（条件聚合）
SELECT
    SUM(CASE WHEN provider = '中国移动' THEN 1 ELSE 0 END) AS 移动用户数,
    SUM(CASE WHEN provider = '中国联通' THEN 1 ELSE 0 END) AS 联通用户数,
    SUM(CASE WHEN provider = '中国电信' THEN 1 ELSE 0 END) AS 电信用户数
FROM contact;
```

# 7. SQL 执行顺序

书写顺序与执行顺序不同，理解执行顺序有助于正确编写复杂查询并理解报错原因。

```sql
-- 书写顺序示例
SELECT   c.provider, SUM(p.occur_count) AS 总次数
FROM     contact c
JOIN     phonetotal p ON c.mob_no = p.op_mob_no
WHERE    p.occur_month = 201205
GROUP BY c.provider
HAVING   SUM(p.occur_count) > 100
ORDER BY 总次数 DESC
LIMIT    10;
```

**实际执行顺序**：

| 步骤 | 子句 | 作用 |
|---|---|---|
| 1 | `FROM` | 确定数据来源表 |
| 2 | `JOIN ... ON ...` | 连接关联表，生成临时结果集 |
| 3 | `WHERE` | 过滤原始行（此时聚合函数尚未计算，不可使用） |
| 4 | `GROUP BY` | 将行按指定列分组 |
| 5 | `HAVING` | 过滤分组（此时可以使用聚合函数） |
| 6 | `SELECT` | 计算并选取输出列（含聚合函数、`CASE WHEN`、别名） |
| 7 | `DISTINCT` | 去除重复行 |
| 8 | `ORDER BY` | 对结果排序（此时可以引用 `SELECT` 中定义的别名） |
| 9 | `LIMIT / OFFSET` | 截取指定数量的结果行 |

**关键推论**：
- `WHERE` 中**不能**使用 `SELECT` 中定义的列别名（别名在第 6 步才产生），也**不能**使用聚合函数（聚合在第 4 步后才执行）。
- `HAVING` 中可以使用聚合函数，也可以引用 `GROUP BY` 中的列。
- `ORDER BY` 可以引用 `SELECT` 中定义的列别名（因为执行顺序在 `SELECT` 之后）。

# 8. 事务管理

事务（Transaction）是一组要么全部执行成功、要么全部回滚的操作，用于保证数据一致性。

```sql
-- 开始事务
START TRANSACTION;  -- 或 BEGIN;

UPDATE contact SET name = '李四' WHERE mob_no = '13800138000';
DELETE FROM phonetotal WHERE op_mob_no = '13800138000';

-- 所有操作均成功，提交
COMMIT;

-- 若中间出错，回滚所有操作
ROLLBACK;
```

事务的四个特性（**ACID**）：

| 特性 | 说明 |
|---|---|
| **原子性（Atomicity）** | 事务中的操作要么全部成功，要么全部回滚 |
| **一致性（Consistency）** | 事务执行前后，数据库从一个合法状态变为另一个合法状态 |
| **隔离性（Isolation）** | 并发事务相互隔离，互不干扰 |
| **持久性（Durability）** | 事务提交后，修改永久保存到磁盘 |
