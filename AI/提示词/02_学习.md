# 1. 学习课程制作

> 适合用于 opencode 或者 claude code

```md
这是一个面向教学的异步 HTTP 服务器框架，我非常想要学习，请你给我提供**学习建议**，保存到 Tutorial 目录下。
```

> 可以把 `面向教学的异步 HTTP 服务器框架` 这部分换成你想学习的项目。

```md
制定一个**课程大纲**，能够用大概 30 节课的内容覆盖所有的知识点。注意：课程内容要能够循序渐进，内容保存到 Tutorial 目录下。
```

然后可以逐步生成每一课的内容，比如：

```md
开始写第一课的详细内容，内容保存到 Tutorial 目录下。
```
