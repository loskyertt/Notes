# 1. 项目经历

> 适用于 OpenCode 或者 Claude Code。

```md
请你查看当前目录下我的整个项目，阅读源文件中的代码实现（3rdparty 是第三方库目录，不需要查看），然后基于该项目生成一份用于求职简历中的项目经历，内容采用 markdown 的格式，放到 resume 目录下进行保存。
要求：
- 使用 STAR 模型，全面展示。
- 项目不是流水账，所以不要写使用xx技能实现了xx功能，这里跟写工作经历类似，是要谈贡献和提效，最好能用一些数据来证明这件事情取得的成果。
- 因此这里只需要写清楚 4 点：
  - 项目背景是什么？
  - 你的职责是什么？
  - 有哪些难点以及你是怎么解决的？
  - 最后的成果是什么？（成果部分用数据或者是用细节去支撑）
- 字数控制在 300-400 之间
```
